# 福克斯家族

## 定位

- 【已确认】子爵家族，领地传统产业为畜牧业，出产肉类和乳制品。
- 【已确认】福克斯家长期为斯托克顿北境提供驻军，并因驻军、贵族圈引荐与五十年的合作形成对斯托克顿家的事实影响力。
- 【已确认】当前阶段的核心目标是夺取斯托克顿领及其狩猎旅游产业，而不只是索取更高佣金。

## 与斯托克顿家相关的三代子爵

| 代际 | 与斯托克顿家的关系 | 状态 |
|---|---|---|
| 第一代 | 接受亚特伍德请求，签署北境驻军合作 | 已故（具体时间待确认） |
| 第二代 | 延续驻军与政治照应 | 四十多岁离奇去世，死因待定 |
| 第三代 | 现任威廉·福克斯，多次提高佣金，并开始吞并计划 | 二十多岁，活跃 |

> “第一代”指本篇驻军合作的代际起点，不必然意味着福克斯子爵家在此之前不存在。

## 当前核心人物

### 威廉·福克斯

- 现任子爵，二十多岁，塞西莉亚的兄长。
- 挥霍无度、贪图享乐，却不应被写成没有政治判断的笨蛋；他准确地看到了驻军依赖、旅游利润和斯托克顿自建武装之间的时间差。
- 他的政治底层逻辑是：与其长期收取佣金，不如在对方完成军事脱钩前夺取整个产业与领地。

### 塞西莉亚·福克斯

- 威廉的妹妹，曾借凯恩伯爵家的学院行动扩大对莉莉安的陷害。
- 她负责把家族级目标转换成可执行的程序陷阱、婚约交易和嫁祸证据，是莉莉安个人层面最直接的施害者。

## 吞并计划的三层结构

1. **先保持依赖**：通过提高佣金和撤军威胁，阻止斯托克顿家把旅游收益顺利转化为独立边防。
2. **再引入婚约**：强迫卢卡斯接受莉莉安，把一位已被污名、孤立无援的“白发魔女”安置进斯托克顿家。
3. **最后制造合法口实**：计划暗杀斯托克顿父子，嫁祸莉莉安，再以“讨伐白发魔女、恢复边境秩序”为名出兵，顺势夺取领地和旅游业。

## 资源与手段

| 资源 | 用法 |
|---|---|
| 北境驻军 | 可通过撤离制造真实安全危机，也为后续出兵提供现成军事基础 |
| 长期合作与人脉 | 了解斯托克顿家的经济、军事与社交弱点 |
| 塞西莉亚的程序操作 | 把半真半假的信息组合成对莉莉安不利的公开叙事 |
| 贵族身份与奢侈消费 | 以旅游客和旧保护者身份正常进入斯托克顿领，掩护观察和施压 |

## 本篇败亡边界

- 【已确认】斯托克顿篇只挫败福克斯家当前的暗杀、嫁祸和吞并方案，不彻底消灭福克斯家，也不完成塞西莉亚的最终败亡。
- 后续必须保留政治缓冲、证据断裂、替罪者或家族庇护中的至少一种，使塞西莉亚仍可在后续篇章回归。

## 待确认

- 福克斯领与斯托克顿领是否直接接壤，及福克斯子爵对斯托克顿男爵是法理上的上级领主，还是凭驻军与人脉形成的事实优势。
- 第二代福克斯子爵离奇去世的真相，以及威廉是否参与或因此受益。
- 福克斯驻军的精确编制、指挥官、对威廉的忠诚程度，以及其中是否存在与斯托克顿领生活五十年后的利益分化。
