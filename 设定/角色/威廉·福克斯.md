# 威廉·福克斯（William Fox）

## 基本卡

- **年龄**：二十多岁。
- **身份**：现任福克斯子爵；福克斯驻军的资源提供者和最高政治受益者；塞西莉亚·福克斯的兄长。
- **核心特质**：挥霍、贪乐、自恋；擅长把别人的历史依赖变成现时权力，不应因奢侈嗜好而被降智。
- **公开形象**：年轻的边境子爵，喜爱狩猎、酒宴和贵族享乐；可以以“五十年的保护者”姿态进入斯托克顿领。
- **真实目标**：在斯托克顿家完成军事脱钩前，夺取斯托克顿领和利润丰厚的狩猎旅游产业。

## 动机链

```text
起因：继位后的奢侈生活需要更多财富；斯托克顿旅游业利润迅速上升
意图：从“每年收取佣金”升级为“取得整个领地与产业”
约束：不能无理由直接吞并男爵领；斯托克顿家正在建立军队和新贵族人脉
手段：撤军威胁 → 强加婚约 → 暗杀父子 → 嫁祸“白发魔女” → 以恢复秩序为名出兵
风险：若计划暴露，福克斯家可能失去驻军合作、政治信用和吞并合法性
```

## 第 006 章表现设计

- 先以狩猎成功和奢侈晚宴展示他的享乐与自我欣赏，再让他用一句平静的“那就把人全部撤回来”暴露真实权力。
- 他知道艾尔伯近年招募骑士、魔法使和民兵，也知道这些人还守不住整条北境。
- 他不需要大声吼叫或详细说破每一层后果；他只需要提到堡垒、长边境、贵族客人的安全和教廷对失地的态度，艾尔伯会自己完成推演。
- 婚约在他口中只被包装成：妹妹塞西莉亚从凯恩家揽下一份人情，要妥善处理一个“稍微有点麻烦的平民”。他不向艾尔伯提学院，也不回答对方关于私生女身份的追问，只强调塞西莉亚已经答应、自己必须把人情领下来，因此只能委屈斯托克顿家。
- 面对艾尔伯以自由恋爱承诺、继承人婚配压力和贵族流言为由拒绝时，他不讨论女孩是否无辜，而把全面撤回北山驻军说成终止两家友好的“象征”，以自己不能失信、不能下不了台为借口完成威胁。

## 与主要人物的关系

- **艾尔伯**：表面是长期合作的贵族与旅游客，实际将他视为尚未脱离控制的弱势领主。
- **卢卡斯**：将其视为经济改革和军事脱钩的真正威胁，因此需要通过婚约与后续暗杀予以控制。
- **塞西莉亚**：妹妹与执行者；两人如何分享信息、是否存在互相利用【待确认】。
- **莉莉安**：计划中的嫁祸容器，而不是他需要了解的人。

## 本篇败亡边界

- 他的当前计划可以被挫败，但福克斯家不在本篇被彻底消灭。
- 即使他本人在本篇遭受政治损失，也不得靠突然认罪、当众失控或所有手下集体背叛等降智方式收束。
