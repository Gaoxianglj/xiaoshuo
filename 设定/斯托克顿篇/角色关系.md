# 斯托克顿篇角色关系

## 关系总览

| 角色 A | 角色 B | 关系类型 | 篇章起点 | 本篇预定变化 |
|---|---|---|---|---|
| 莉莉安 | 卢卡斯 | 被迫婚约 / 安全关系 | 陌生的名义未婚夫妇；莉莉安害怕被丢弃，卢卡斯对“未来记忆”有信息优势 | 双方成为不能轻易拆散的安全关系，默认下一段旅程共同前往 |
| 莉莉安 | 艾尔伯 | 家庭 / 领主与政治风险 | 艾尔伯将她视为福克斯家强加的麻烦 | 从可怜的孩子、可靠的成员，变为不允许外人从家里带走的孩子 |
| 莉莉安 | 萨拉 | 生活管理 / 照料 / 师徒式劳动关系 | 莉莉安试图靠无条件服从换取容身，萨拉首先处理她的伤与生活规则 | 莉莉安可以在萨拉面前接受照顾，不再每次立即偿还 |
| 莉莉安 | 蒂莉 | 友情 / 姐妹式镜像 | 蒂莉不知道白发偏见，无防备地认识莉莉安 | 蒂莉在知道传说后仍根据真实相处选择莉莉安；莉莉安开始主动参与家庭日常 |
| 卢卡斯 | 艾尔伯 | 父子 / 领地合作 | “艾尔伯对外接待、卢卡斯对内管理”，共同推动狩猎旅游和自建武装；艾尔伯曾承诺不让儿子政治联姻，基本信任稳定 | 艾尔伯擅自签婚约并因心疼儿子过劳而延迟一夜告知，裂痕尚未公开但已经形成；最终需共同承担家族和领地选择 |
| 艾尔伯 | 威廉 | 合作 / 债务 / 敌对 | 五十年驻军合作使威廉占据事实强势 | 全面撤军威胁使艾尔伯确认合作已转为吞并，开始以脱离控制为明确目标 |
| 莉莉安 | 塞西莉亚 | 施害 / 创伤 / 对抗 | 塞西莉亚已成功孤立并迫使莉莉安接受婚约 | 塞西莉亚首次意识到莉莉安不再是可被完全孤立的人；最终清算保留到后续篇章 |
| 威廉 | 塞西莉亚 | 兄妹 / 共谋 | 共同服务福克斯家吞并目标；威廉掌握驻军与政治资源，塞西莉亚负责程序陷阱 | 是否存在互相利用、信息保留或责任切割【待卷纲确认】 |

## 核心关系弧线

### 莉莉安 ↔ 卢卡斯

```text
被迫的陌生未婚夫妇
  → 主仆/工作关系作为过渡
  → 可预测的日常与有边界的照顾
  → 在危机中各自试图独自承担
  → 放弃“为你好所以替你决定”，选择互相信任与共同行动
  → 还不是爱情，却已是不可轻易拆散的安全关系
```

### 莉莉安 ↔ 斯托克顿家

```text
被允许进门
  → 用劳动证明自己有资格留下
  → 拥有自己的房间、杯子、座位、私人物品和休息日
  → 失去工作能力/带来政治风险时仍未被赶走
  → 家人在真相未明时仍选择不交出她
  → 她也主动选择回来
```

## 关系写作红线

- 卢卡斯不是斯托克顿家接纳莉莉安的唯一来源；艾尔伯、萨拉和蒂莉都必须以自己的选择完成家庭承认。
- “女仆”关系只是莉莉安理解安全的过渡框架，不得把主仆服从当成爱情甜点或家人认可的最终条件。
- 斯托克顿家对莉莉安的选择必须发生在她无法工作、证据对她不利或庇护她会产生真实代价的时刻，否则无法驳倒她“只有有用才能留下”的错误信念。
