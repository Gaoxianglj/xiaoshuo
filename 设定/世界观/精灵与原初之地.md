# 精灵与原初之地

> 用途：精灵起源、社会结构、对人类干预边界，以及莉莉安升格可能的当前唯一专用口径。  
> 状态：作者确认口径 · 2026-08-10。  
> 覆盖关系：本文件优先于`设定/世界观背景设定合集.md`、`设定/角色关系网络.md`和`设定/小说结构与世界观补完.md`中的旧版精灵说明。

## 一、起源与后续诞生

- 先知艾瑞安创造了最初一批精灵，并赋予它们根本使命：**改造这个世界，使其更适合人类生存**。
- 最初精灵只有极淡的情感，以理性、任务和环境改造为行动核心。艾瑞安确认它们能持续履行使命后，没有继续逐项指挥。
- 艾瑞安建立的是精灵这一生命形式及其在亚空间—现实位面之间的生成结构。后来的精灵并非由艾瑞安逐个创造，而是由世界中既有的游离魔力在亚空间中凝聚、诞生；这不凭空增加世界总魔力。
- 所有灵魂都会进入或经过亚空间。随着具有魔力、能够在亚空间留下更鲜明痕迹的人类增多，亚空间积累的情感痕迹也变得丰富；较晚诞生的精灵因此通常比早期精灵更富感情。
- 情感痕迹只影响新精灵的性情倾向。精灵不是死者转世，不继承某个死者的记忆、人格或身份；“越年轻越感性”是总体趋势，不是决定个体性格的绝对规律。

## 二、生命状态、休息与沉睡

- 精灵是以魔力维持连续自我的精神生命。它们不会自然衰老，也不因时间流逝而自然死亡，但仍可能被足以破坏其能量结构的力量摧毁。
- 精灵没有人类式的肌肉疲劳，却会因漫长任务、单调、精神压力或情感消耗产生厌倦与心理疲劳。
- 短期回到原初之地休息属于常规安排，经长老或负责相关任务的精灵同意并完成工作交接即可。
- 长期沉睡须经长老批准，并先安排任务接替与预定醒来时间。沉睡不是惩罚，也不会自动清除记忆。
- 原初之地的“休息”可以只是停止承担具体工作、无所事事地放松；醒来或离开后，精灵通常继续原有使命或接手新的维护任务。

## 三、社会构成

### 3.1 原初执行体

- 艾瑞安直接创造、至今仍在神赐之地边界或外部持续扩张改造范围的最初精灵，统一称为**原初执行体**。
- 它们情感极淡，近乎机械地执行根本使命，不参与后来形成的长老社会，也不等于正文中负责看守菲莱尔的“年长精灵”。

### 3.2 普通精灵社会

- 后来诞生的精灵形成了以原初之地为中心的松散社会。长老负责协调任务、解释共同原则、处理争议与批准长期休息或沉睡。
- **长老是职务，不是单纯由年龄决定的类别。**新长老由现任长老一致认可后加入。
- 精灵社会长期依靠理性、自觉、共同使命与彼此认可维持，没有人类式完整法典、监狱或固定量刑表。
- 近约两百年诞生的精灵整体更富情感，也更可能在压力下越过旧有默契。长老因此设立**执行者**角色，负责传达决定、教导、劝诫，并在必要时强制中止行动。
- 正文中跟随莉莉安、约束菲莱尔的“年长精灵”，现统一归类为**受长老授权的执行者**；它们不是原初执行体，也不因“年长”天然拥有权力。

### 3.3 处置方式

精灵没有自动触发的契约惩罚。发生越界后，由长老与执行者按事实个案处理，常见方式包括：

1. 解释、教导与劝诫；
2. 暂停或调换任务；
3. 限制与特定对象接触；
4. 限制离开某一区域；
5. 由执行者带回原初之地并在一定时期内监督行动。

限制自由是严重处置，但不等于抹除人格、永久囚禁或记忆清除。执行者也不是全知的；神赐之地广大，未被发现或来不及制止的越界行为客观存在。

## 四、对一般人类的干预边界

- 艾瑞安留下的根本使命以人类生存为目标。此后长老逐渐形成“不主动介入人类政治、司法与社会争端”“尽量不伤害人类”的共同原则。
- 这些原则是社会命令与长期默契，不是写入精灵本体、违反即自动受罚的物理禁制。精灵在事实上做得到杀死人类，且曾出现人类毁掉精灵数十年成果后被直接杀死的个案；是否被发现、制止或处分取决于执行者与长老的实际介入。
- 精灵普遍不喜欢人类，也不愿长期与人类相处。这种疏离与理性自律共同维持了边界，却不能代替明确判断。

| 行为 | 当前边界 | 说明 |
|---|---|---|
| 观察、交谈、传递不受限制的信息 | 通常允许 | 不替人类作出决定，也不直接改变人类制度结果 |
| 履行已经作出的承诺或自身环境维护任务 | 允许 | 仍须受任务范围、第三方安全与长老命令约束 |
| 主动介入人类政治、审判、继承与战争 | 原则上禁止 | 会把精灵变成人类权力斗争的直接参与者 |
| 因私人好恶杀伤、绑架或长期控制人类 | 禁止 | 物理上能够发生，但构成严重越界；不存在“系统自动惩罚” |
| 人类正在毁坏精灵的长期改造成果 | 可先制止与驱离 | 是否能使用致命手段须个案判断；旧案例不构成普遍许可 |
| 眼前出现即时生命危险 | 可作最低限度干预 | 目标是中止当下死亡风险，不顺势替当事人解决后续人生 |

## 五、莉莉安特别协议

### 5.1 特殊身份

- 莉莉安从婴儿时期起长期吸收原初之地纯净、高浓度魔力，身体对魔力的反应已发生普通人类无法复制的不可逆改变。
- 长老在她幼年时仍决定把她按人类看待；部分较年轻、情感丰富的精灵则将她视为“精灵的爱子”——由精灵养大的挚爱孩子。两种判断长期并存。
- 莉莉安儿时寄养家庭的房屋被精灵纵火焚毁，是一次严重、不可逆的主动干预。事件后，长老才为她建立长期特别协议，并派执行者暗中跟随、约束容易因爱护而越界的精灵。

### 5.2 核心原则

特别协议的准确表述是：

> **不得在莉莉安未充分知情且未同意时，为她制造不可逆结果、剥夺她的有效选择，或替她决定人生去向。**

“不要改变命运”只可作为角色的简化说法，不可当作机械、宿命论规则。判断重点不是结果是否有利，而是精灵是否越过莉莉安的主体意愿，替她完成了不可撤回的选择。

### 5.3 请求、同意与例外

- 莉莉安主动请求帮助，是重要的许可条件，但不是无限授权。精灵仍须判断请求是否违反根本使命、长老直接命令、第三方安全与一般不干预原则。
- 莉莉安没有请求时，精灵不得主动替她决定去留、惩罚伤害她的人、破坏他人的住处，或把她带回原初之地。
- 若出现近在眼前的死亡风险，精灵可以先采取最低限度的救命行动；危险解除后，决定权必须立即归还莉莉安。
- “允许被找到”“允许传达某项信息”“请求送到某处”属于可明确表达、可限定范围的同意。未来若由当地精灵给卢卡斯留下寻找莉莉安的有限引导，必须先由莉莉安明确允许自己被找到。

| 行为 | 是否允许 | 正文／后续对应 |
|---|---|---|
| 围在她身边、交谈、陪伴 | 允许 | 日常精灵互动 |
| 她明确请求精灵转告或把她送到某处 | 原则上允许 | 第010章她要求送到南岸 |
| 未经请求，主动降低决斗环境响应门槛 | 越界，须劝诫或加重监督 | 第003章；施法与代价仍由莉莉安承担 |
| 因她受伤而杀死或试图杀死人类 | 严重越界 | 儿时纵火；菲莱尔试图杀死玛琳 |
| 告知她玛琳阴谋 | 信息本身不是绝对禁区 | 若不涉及即时生命危险，须服从当时的接触限制与执行者命令 |
| 在监狱中替她完成越狱 | 禁止 | 不能搬运她、替她选目的地或保证逃脱 |
| 经长老审议后恢复一条可由她自己判断并走出的路线 | 本次个案允许 | 第005章只移除后来施加的障碍，莉莉安自行观察、选择、行动并自首 |
| 强制把她带回原初之地成为精灵 | 禁止 | 菲莱尔只能提出邀请并接受其决定 |

## 六、菲莱尔事件的统一解释

- 第002章中，莉莉安已明确请求菲莱尔：若以后发现问题，要告诉她。菲莱尔答应。因此，“想把玛琳的阴谋告诉莉莉安”本身不是菲莱尔受罚的根本原因。
- 第004章菲莱尔因愤怒试图直接杀死玛琳，执行者必须即时制止。随后对菲莱尔采取接触限制，是对这次严重越界的处置；限制期间，它也因此无法再去警告莉莉安。
- 第005章的越狱机会不是菲莱尔独自钻漏洞。长老与执行者在莉莉安持续受侵害、既有处置已使她完全失去外部援助的情况下发生争论，最后只批准最低限度地恢复选择：不替她开辟目的地，不替她行动，只让一条本可由她自行利用的路线重新成为可能。
- 菲莱尔后来前往斯托克顿领，可以真诚表达更希望莉莉安成为精灵；只要它完整说明代价、让莉莉安自己选择，并在她决定后停止纠缠，就没有违反特别协议。

## 七、莉莉安升格为精灵

- 这条道路只对莉莉安成立：必须有婴儿时期开始的长期原初魔力滋养作为身体前提，普通成年人不能靠进入原初之地复制。
- 条件为莉莉安自愿回归、长老接受，并在原初之地重新开始长期高浓度魔力滋养。
- **转化期至少十年以上。**过程是人类身体逐渐转为稳定的魔力生命结构，记忆、感情、自我认同与人格连续保留，不发生“先死后生成另一个精灵”的身份断裂。
- 完成后她不再自然衰老或患普通人类疾病，但仍可能被足以破坏精灵结构的力量摧毁。
- 她须承担精灵使命、长老秩序与既有承诺；居所、工作、长期休息、离开原初之地和介入人类事务都会受到约束。
- 仍待后续细纲锁定：长老批准的具体表现、转化过程的可见外观、最后可撤回节点，以及菲莱尔在首都承担的具体工作。十年以上的时长不再列为待定。

## 八、斯托克顿篇主题与写作约束

- 原初之地保证莉莉安被接纳，却要求她改变生命形态并承担使命；斯托克顿宅邸无法保证她永不受伤，却允许她离开后按自己的意愿回来。两者都必须写成真实、有价值的归宿选项。
- 不得把升格写成洗脑、情感抹除、隐藏骗局或瞬间仪式；邀请越真诚、美好，莉莉安选择继续做人类才越有重量。
- 不得让卢卡斯用爱情告白或“做人更好”的道理替她决定，也不得让精灵直接解决福克斯家阴谋。
- 莉莉安先拒绝在绝望中作不可逆决定；本幕结尾再以同意旅行、争取重返学院，完成对人类未来的正向选择。
- 卢卡斯认出公开常识中的精灵光点不构成未来记忆泄露。真正触及莉莉安秘密的是：他知道她能与精灵双向沟通，并能从精灵行为判断它们对她的爱护。
