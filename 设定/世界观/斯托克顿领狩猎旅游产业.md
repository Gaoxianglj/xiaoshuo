# 斯托克顿领狩猎旅游产业

> 用途：固定斯托克顿领的经济逻辑、卢卡斯的改革成果，以及福克斯家为何觊觎这片土地。

## 转型前：低利润原料经济

- 【已确认】斯托克顿家原本以木材、渔业和农业为主要收入。
- 【已确认】这些商品在教国内部并不稀缺；斯托克顿领又位于最外围，产品品质、魔力含量和运输条件都不占优，难以售出高价。
- 【已确认】早期为获取木材和扩大耕地，领地曾持续砍伐森林；卢卡斯的计划使砍伐逐步放缓，开始把未被破坏的森林本身视为可长期利用的资产。

## 卢卡斯的转型逻辑

1. **卖体验，而不只是卖原料**：贵族不缺食物和木材，却缺少被教会认可的娱乐。
2. **获得宗教合法性**：狩猎被包装成锤炼武力、魔法、判断和圣战经验的贵族运动，而非腐化心智的纯享乐。
3. **把自然条件组合成产品**：原始森林提供风景和多样猎物，中心湖提供渔猎、垂钓和湖畔度假，别墅、向导、侍从、餐饮与晚宴提供高利润服务。
4. **用服务业弥补原料劣势**：猎物和鱼类本身未必稀缺，但“在边境森林中完成狩猎、在湖畔旁烧烤猎物并与其他贵族饮酒”可以被售卖为稀缺的社交经验。

## 核心服务链

| 环节 | 内容 | 剧情功能 |
|---|---|---|
| 对外宣传 | 艾尔伯向贵族社交圈宣传领地风景、狩猎和湖泊 | 使艾尔伯获得比过去更多横向人脉 |
| 抵达与住宿 | 贵族入住湖边度假别墅 | 展示斯托克顿领的服务能力与新财富 |
| 日间狩猎 | 向导、保镖和侍从组织森林狩猎 | 可同时呈现魔法、阶层和边境地理 |
| 湖上渔猎 | 垂钓、捕鱼与湖畔观景 | 为低烈度日常、对话与关系推进提供场景 |
| 晚间聚会 | 在别墅或湖边烧烤当日猎物，饮酒、晚宴、交谈 | 贵族政治、威胁和交易可以藏在享乐场景中 |
| 定期活动 | 狩猎节、庆典和贵族聚会 | 展示家族实力，同时扩展关系网 |

## 对领地的实际改变

- 【已确认】旅游业带来可观收入，艾尔伯终于有资源招募骑士、魔法使并训练民兵。
- 【已确认】艾尔伯不再完全依赖福克斯子爵引荐才能接触其他贵族，这同时削弱了福克斯家的政治控制。
- 【已确认】旅游利润和潜在军事独立性共同刺激了威廉·福克斯的吞并欲望。

## 经营红线

- 狩猎项目依赖“森林未被过度破坏、野生动物仍足够丰富”，不能同时无限扩大伐木与狩猎规模。
- 旅游业的首要商品是安全且可控的边境体验；战争传闻、路线断绝、哨所失守都会造成比一季营业损失更严重的长期信誉损害。
- 未确认狩猎配额、禁猎期、旅游价格、年接待人数和别墅数量前，正文不使用精确数字。
