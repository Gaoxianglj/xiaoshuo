# 设定目录导航

> 这里是设定层的唯一入口。先查 [设定索引与主档台账](设定索引.md)，再进入对应主题的主档；不要仅凭文件名或旧汇编挑选依据。

## 当前读取原则

- 先通过 [设定索引](设定索引.md) 确认问题属于哪个主题、哪份文件是现行主档。
- 再通过 [章节索引](../追踪/章节索引.md) 选择当前正文、细纲与快照；已发生的章节事实和即时知情边界以追踪与正文证据为准。
- 稳定规则优先读取角色、势力、世界观目录中的专用卡；与专用卡不一致的大型资料不能覆盖专用卡。
- 资料冲突、未锁定名称或未确定参数，按根目录 [AI_RULES.md](../AI_RULES.md) 的信息优先级处理，不在写作时临时补定。

## 设定管理档案

- [设定索引与主档台账](设定索引.md)：主题、唯一主档、交叉索引和新增资料去向。
- [术语与命名表](术语与命名表.md)：规范称呼、别名提醒和内部编号入口。
- [设定变更记录](设定变更记录.md)：会影响后续写作的作者确认与资料主从关系变动。

## 文风资料

- [权威文风基准](文风.md)：人物声线、情感幅度、修辞、节奏及重复机制的唯一规则主档。
- [文风锚点库](文风锚点.md)：可选的具体实例及适用边界，不另设文风门槛。
- `BK/`文风备份与旧评价只供追溯；发生冲突时以作者最新意见和现行主档为准。

## 后续增量写入规则

- 可复用角色写入角色目录中的独立人物卡。
- 可复用势力写入势力目录中的独立档案。
- 跨章节稳定的世界规则写入世界观目录中的主题档案。
- 只服务当前章节的状态、物件、知情和接口写入追踪；尚未选择的方案写入待确认事项或相关大纲。
- 叙述性的总览仍保留在既有大型资料与 Bible；索引、术语表和变更记录只记录入口、称呼和决策摘要，不复制全文。

任何新增内容请标明“已确认／整理或推定／待确认”，并在新增稳定主档后补充 [设定索引](设定索引.md)。
