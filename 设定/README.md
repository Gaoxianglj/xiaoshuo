# 设定目录导航

## 当前读取原则

- 先通过`追踪/章节索引.md`选择当前正文、细纲与快照。
- 稳定规则优先读取`设定/角色/`、`设定/势力/`、`设定/世界观/`中的专用卡。
- 下列三份大型资料保留为历史汇编或候选补完；其中与专用卡不一致的内容不得覆盖专用卡。

## 现有主资料

- `世界观背景设定合集.md`：历史、魔法、政治、社会、地理与宗教的完整汇编。
- `角色关系网络.md`：人物身份、关系、秘密与叙事功能。
- `小说结构与世界观补完.md`：AI 补完方案、结构建议及需要谨慎核对的内容。
- `插画风格.md`：项目基础插画风格、参考图、提示词模板与生成后检查规则。

## 后续增量写入规则

- 可复用角色：`角色/姓名.md`
- 可复用势力：`势力/名称.md`
- 跨章节的世界规则：`世界观/主题.md`
- 总览仅保留在现有三份主资料与 `Bible.md`；不重复复制全文。

任何新增内容请标明“已确认 / 推定 / 待确认”，并遵守根目录 `AI_RULES.md` 的信息优先级。

## 篇章专用入口

- 斯托克顿篇：`斯托克顿篇/README.md`。该入口索引篇章直接使用的人物、家族、地理、驻军、产业和首章细纲，应优先于再次通读大型设定合集。
- 精灵与原初之地：`世界观/精灵与原初之地.md`。该文件是莉莉安升格可能、精灵选择边界与斯托克顿篇原初邀请的当前确认口径。
- 学院内部司法与秘密监狱：`世界观/学院内部司法与秘密监狱.md`。该文件是004—005章秘密关押、越狱隐瞒、秘密搜捕及塞西莉亚知情边界的当前确认口径。
- 复数魔法控制：`世界观/复数魔法控制.md`。该文件记录一般魔法使的单一持续专注边界、无杖复数施法负荷，以及莉莉安在第009章展示精密协同魔法的当前口径。
- 感恩节与斯托克顿秋收宴会：`世界观/感恩节与斯托克顿秋收宴会.md`。该文件记录教堂感恩仪式、斯托克顿两日宴会、宅邸筹备惯例与后续投毒线的连续性边界。
- 国教教义与社会秩序：`世界观/国教教义与社会秩序.md`。该文件记录教廷公开的神降史诗、先知与魔法正统、对无信者／异教者／异端的处置原则，以及阶级和物质差等的教义依据；不得与客观历史暗线混同。
