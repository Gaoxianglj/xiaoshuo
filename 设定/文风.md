# 《无名的书》文风基准（再修订版）

> 用途：写作前必读的核心文风依据。目标是保持全书稳定底色，同时尽量减少生成阶段的规则负荷与模板化反应。
>
> 配套文件：
> - `文风锚点.md`：技法库，按需查阅，非必读。
> - `文风锚点_来源索引.md`：维护专用，不参与常规正文生成。

## 0. 这份文档在解决什么问题

本版不试图用更多规则堵住所有偏移，而是将规则分成三层：

1. **稳定底色**：长期有效，不因单章问题反复推翻；
2. **生成提示**：写作前快速判断人物、情绪和场景，不逐句套规则；
3. **事后监测**：初稿形成后检查高频模板，必要时触发警戒线或红线复核。

基本原则：

- 底色只定义一次，不逐章重新论证；
- 高频问题按“表达机制”监测，不按字面禁词；
- 生成与审校分开，不一边写一边机械计数；
- 规则是为了保护自然表达，不是为了让正文看起来“遵守规则”；
- 一两处个案不应触发整个文风体系重写。

---

## 1. 一句话文风（稳定条款）

**克制、具体、贴近人物，是全书默认底色。**

大多数平常时刻含蓄收敛，情绪通过人物真正注意到的事、动作、物件、语言和留白传达，不必说尽，也不刻意放大。

当人物进入明确的高负荷状态时，表达幅度可以自然打开：句子可以变长、变短、重复、失序，直接心理和感官冲击都可以增加。**打开幅度是一种许可，不是一套升级清单，也不代表强烈情绪必须写得破碎。**

### 1.1 篇幅服从表达

细纲字数、场景预算和章节长度默认只是建议。只有作者明确要求硬性篇幅时，才作为门槛。

- 情节、必要信息和情绪已经充分，就在这里停笔；
- 不为凑长度补旁白、动作、对白或事件；
- 高潮需要充分展开时，也不因旧有日常语速强行压短；
- 修改以确有问题为前提，不设删改比例。

### 1.2 生活不必逐项承担主题任务

生活可以只是生活。

- 一顿饭可以只解决吃饭；
- 一段闲谈可以没有关系突破；
- 一件物品可以只是正在使用的物品；
- 小差错、小抱怨、无关紧要的争论都可以存在。

不要求每个日常场景都完成治愈、成长、象征、伏笔或关系推进。人物越像真实生活中的人，真正承担主题的场景越有力量。

### 1.3 不替读者总结已经成立的意义

场景已经让读者看见的东西，不再由旁白重新定性。

尤其避免连续使用以下方式证明人物体贴、尊重或克制：

- “没有追问”；
- “没有催促”；
- “没有替她决定”；
- “没有把这句话当成……”；
- “这意味着……”；
- “她终于明白……”；
- 在画面、动作或对白之后再补一句解释其伦理意义。

若删去解释后，事实、人物反应和节奏仍成立，优先删去解释。

## 2. 生成前速览卡

每个场景开始前只过一次，不逐句执行。

### 2.1 情绪负荷：1—5

情绪负荷只回答：**这件事对当前人物主观上有多重？**

- **1**：普通生活，没有明显压力；
- **2**：轻微在意、局促、期待或不适；
- **3**：明显压力、冲突、羞耻、担忧、靠近；
- **4**：重大情绪临界点，长期积累正在被撬动；
- **5**：极高负荷，生死、崩溃、重大失去、强烈欲望或决定性情感兑现。

**分数只用于辨认场景重量，不决定句法，不授予任何自动豁免。**

### 2.2 控制状态：稳定 / 松动 / 失守

与情绪负荷独立判断。

- **稳定**：人物仍能按平时方式组织语言、行动和思考；
- **松动**：仍能行动与交流，但开始出现失言、重复、问得过重、逻辑跳跃、礼貌失准、句式变化；
- **失守**：原有控制方式明显崩坏，可能出现哭喊、重复、时间错乱、感官侵入、行动失序或无法继续维持原有思维框架。

示例：负荷5并不等于失守；人物可以在极端痛苦里异常冷静。负荷3也可能短暂失守，例如某个具体触发突然击穿控制。

### 2.3 生成前只问五件事

1. 本场视角是谁？身体和注意力首先落在哪里？
2. 情绪负荷是多少？控制状态是什么？两者为什么？
3. 这一场真正要发生什么变化：事实、选择、关系、误解、压力还是没有变化？
4. 哪一句必须由人物直接说出口？哪些可以让行动、物件或留白自己成立？
5. 是否需要查技法库？不需要就不查；需要时只取原理，不复制示例句法。

## 3. 角色声线

### 莉莉安

轻、委婉、端正；对卢卡斯使用“您”。习惯把善意换算成工作、费用、规则或偿还方式，这是她维持安全感的方法，不是制度癖。

- 紧张时容易说得过分精确；
- 放松后会出现真实停顿、轻反问、没压住的笑；
- 松动时会把问题问得过重，或在说出口后才意识到；
- 失守时可以直接否认、哭喊、追问、失去分类核对能力；
- 爆发后不必立刻恢复端正、道歉或总结自己刚才为何失控。

### 卢卡斯

温和、自然，带一点不高明的幽默。习惯用具体办法照顾人，而不是把保障条款说全。

- 正式领务和谈判可以清楚、精确；
- 面对莉莉安时先是同龄人，再是继承人；
- 不必准确命名她每一层心理防御；
- 可以生气、委屈、嫉妒、迟疑、说错词，也不必立刻修正成最妥帖的伦理答案；
- 重要边界可以说清，但同一份保障不重复宣读。

### 萨拉

实用、利落。纠正和照顾常在同一个动作或事务里完成。用眼前生活事实回应担忧，带熟人式干脆和轻微揶揄，不说咨询式台词。

### 蒂莉

直接、好奇，从最眼前的生活常识出发。善意不需要完整论证，误解和问题也可以很直白。

### 艾尔伯

谈领务清楚利落；谈家人时更容易迟疑、绕开，或先谈工作。可以做出正确选择，也可以因害怕再次替家人决定而隐瞒、拖延或犯错。

### 制度 / 权力人物

语言受身份和利益约束，不统一写成“程序体”。

- 阿尔瓦偏事实核对；
- 奥莉维娅偏行动标准；
- 塞西莉亚擅长把生活细节转写成不利程序语言；
- 威廉更擅长用真实筹码、身份和既有依赖施压，而不是咆哮。

## 4. 高频模板监测

> 本节只在一个自然场景 / 小节初稿形成后执行。**生成过程中不要实时计数。**
>
> 监测对象是“表达机制”，不是关键词。把“没有回答”换成“她沉默着”，如果功能相同，仍属于同一机制。

### 4.1 两层规则

#### 警戒线

触发警戒线后必须检查，但可以自行放行。

检查问题：

- 这些重复是否承担不同功能？
- 是否来自特定人物声线或刻意节奏？
- 删除或替换后是否反而更假？
- 是否只是换词而机制没变？

若检查后认为合理，可直接保留，不需要向作者报告。

#### 红线

触发红线后必须进行第二次独立检查。

若第二次检查仍决定保留，可以放行，但**正文生成完成后必须向作者报告**：

1. 触发位置；
2. 触发项目；
3. 为什么二次检查后仍认为保留优于修改。

若红线触发后已经修改消除，则无需报告。

### 4.2 默认警戒线 / 红线

| 表达机制 | 警戒线 | 红线 |
|---|---|---|
| 作为情绪承接的“没有＋动词”及等效沉默否定机制 | 连续4段出现2次 | 连续5段出现3次，或同一短段落密集出现2次 |
| “停了一下 / 片刻后 / 过了一会儿”等显式停顿机制（含同义替换） | 3段内出现2次 | 5段内出现3次 |
| “手指 / 肩膀 / 目光”等微动作承担情绪收尾 | 连续2个情绪回合使用同类机制 | 连续3个情绪回合，或单场景4次以上 |
| 仅为标识说话人的动作式对白标签 | 连续3个对白回合中2次 | 连续5个对白回合中4次以上 |
| 静物 / 景物镜头作为章尾 | 最近5章达到2次时检查 | 最近5章达到3次 |
| 调查中的“已确认 / 未知 / 不能证明”式归类 | 第二次出现，或约占场景1/4 | 约占场景1/3以上，或相邻两个场景都主要靠此结构推进 |

### 4.3 放行原则

以下情况更容易通过检查，但不是自动豁免：

- 刻意重复本身就是人物行为（喊名字、否认、数数失败）；
- 重复造成情绪累积，而不是替代新的内容；
- 人物处于“松动 / 失守”，语言惯性本身有剧情意义；
- 程序性重复正在表现制度压迫，而不是作者在重复解释；
- 章尾静物是前文长期累积的关键物件，而非惯性收尾。

**任何情绪强度都没有免检权。高潮不是免检区，只是某些重复更可能有充分理由。**

### 4.4 红线报告格式

正文之后追加，保持简短：

> **文风红线报告**<br>
> 位置：第（三）节山坡对话。<br>
> 触发：连续三轮对白均以沉默 / 停顿机制承接。<br>
> 二次检查结论：保留。三次停顿分别承担隐瞒、误解和主动等待，合并或删除会改变关系节奏。

没有保留红线时，不输出这一栏。

## 5. 控制松动与失守时的表达空间

本节是**许可库**，不是必须执行的升级表。

人物控制开始松动或失守时，可以自然使用：

- 连续短句或突然拉长的句子；
- 同一称呼、词语、意象或问题的重复；
- 打断动作，直接进入感官或念头；
- 省略号、破折号、半句中断；
- 时间与因果短暂错乱；
- 记忆与眼前画面同时出现；
- 平时依赖的理性框架失效；
- 说错话以后不能立即修正；
- 情绪外显与叙述语言不一致：人物可以哭喊而叙述异常冷静，也可以表面稳定而内部意识失序。

选择依据不是“分数到了几分”，而是：**这个人物此刻怎样失去、维持或重新夺回控制最真实。**

情绪回落以后，句法可以自然收拢，但不强制用安静物件镜头标记“高潮结束”。

---

## 6. 对白总则

- 日常对白可以不完整、答非所问、被动作打断；
- 人物可以理解错、说错、没说到点上；
- 重要承诺说一次，后续主要靠行动兑现；
- 正式程序场合可以精确，但不同人物仍保留各自声线；
- 配角有自己的疲惫、利益和手头事务，不只负责安慰或推动主角；
- 不为了避免“某某说”而给每句话硬塞一个动作；
- 说话人明确时可裸对白，需要节奏或动作时再加标签。

---

## 7. 维护规则

- 第1节和第3节属于稳定条款，除非作者明确要求，不因单章问题反复重写；
- 新发现的高频毛病优先加入第4节，以“表达机制 + 警戒线 + 红线”描述；
- 不为每次个案新增一条规则；
- 已完成正文不因本文件改版自动需要重写；
- 阈值允许在连续实践数章后微调，但先记录触发频率和误报情况，再调整，不凭单个场景改动；
- 每次修订只记录“日期 + 改动 + 原因”，不保留冗长修订争论。

## 附录：审校专用清单

> 仅用于事后复核，不在逐句生成时套用。

### A. 先看表达是否成立

- 人物注意、感受或选择发生了什么变化？
- 是否为了“克制”删掉了本来必须出现的感受？
- 是否为了“细腻”反复写同一种反应，却没有新内容？
- 生活场景是否被迫承担了不必要的主题任务？
- 画面已经成立后是否又补解释？

### B. 再跑高频模板监测

- 是否触发第4节警戒线？检查后是修改还是自行放行？
- 是否触发红线？若保留，是否已准备正文后的红线报告？
- 是否只是用同义词绕开计数？
- 相邻场景是否重复“否定—停顿—微动作—留白—静物收尾”同一机制？

### C. 人物与场景

- 卢卡斯是否重新变成制度说明书或心理咨询师？
- 莉莉安的端正是否来自处境，而不是作者默认笔调？
- 多人物事故、调查、谈判是否堆成分镜脚本？
- 调查程序是否已经被前文证明过，却又完整展示一次？
- 情绪高峰是否获得了足够表达空间，还是仍被日常句法压平？
- 情绪高峰是否反过来套用了固定“破碎句法模板”？

### D. 章尾

- 事件和情绪是否已经结束？结束就停；
- 是否又惯性补了一个静物 / 景物余韵镜头？
- 删除最后一段是否反而更完整？
- 若静物结尾确实必要，是否触发警戒线或红线？
