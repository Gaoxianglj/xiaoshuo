# 设定索引与主档台账

> 用途：这是全书设定层的总入口，用来回答“某个问题应该读哪份资料、哪份资料是主档、改动后还要同步哪里”。  
> 盘点日期：2026-09-13。它只管理资料关系，不重复设定全文，也不因收录而把提案升级为既定事实。

## 先这样使用

1. 先按本页主题找到唯一主档；同一事实不要在多份文件里来回挑选。
2. 再看主档内部的状态标记，以及根目录 [AI_RULES.md](../AI_RULES.md) 的信息优先级。
3. 若问题是“本章已经发生了什么、谁知道什么、物件现在在哪里”，转查 [追踪](../追踪/)；不要用设定卡替代章节状态。
4. 若问题是“后面准备怎样发生”，转查 [大纲](../大纲/)；大纲中的方案不能倒灌成正文已发生的事实。

## 文件角色

| 标记 | 含义 | 使用边界 |
|---|---|---|
| 【现行专用主档】 | 某主题当前唯一的完整设定入口 | 新增或修正该主题时优先写这里。 |
| 【篇章入口】 | 为某一幕筛选出的按需导航 | 不重复主档全文；跨幕事实仍回到专用主档。 |
| 【状态库】 | 已写事实、当前状态、知情边界或待裁决事项 | 记录故事进行中的变化，不承担恒定世界规则。 |
| 【历史汇编】 | 早期整合资料或方便纵览的存档 | 可作背景参考；与现行专用主档冲突时不覆盖主档。 |
| 【建议／提案】 | 供作者选择、推演或补完的方案 | 未明确确认前不能写成设定事实。 |
| 【证据】 | 已完成正文及对应快照 | 用于核验“实际发生过什么”。 |

发生冲突时不靠本页裁定；以 [AI_RULES.md](../AI_RULES.md) 的信息优先级为准，并把尚未裁定的部分留在 [待确认事项](../追踪/待确认事项.md)。

## 新内容写到哪里

| 新内容类型 | 首要落点 | 同步动作 |
|---|---|---|
| 可复用角色的长期资料 | 角色/姓名 | 在本页人物表补一行；名称有歧义时更新术语表。 |
| 可复用家族、组织或制度性势力 | 势力/名称 | 在本页势力表补一行。 |
| 跨章节稳定的世界规则、地点或制度 | 世界观/主题 | 在本页世界表补一行。 |
| 仅服务某一幕的关系或资料筛选 | 对应篇章目录 | 在篇章入口和本页篇章表建立链接，不复制世界规则全文。 |
| 已写事件的状态、知情或物件去向 | 追踪中的适当主表与章节快照 | 只在确有跨章价值时升级为稳定设定。 |
| 尚未选择的方案或精确参数 | 待确认事项，必要时附在相关大纲 | 明确标记待确认，不能伪装成主档事实。 |
| 作者确认造成的实质性设定变化 | 对应主档 | 在 [设定变更记录](设定变更记录.md) 留一条摘要和影响范围。 |

## 维护纪律

- 一个主题只保留一份完整主档；其他位置只写摘要和链接。
- 新建文件前先搜索本页和现有专用卡，避免按不同称呼重复建档。
- 主档中必须保留“已确认／整理或推定／待确认”的边界；不确定时宁可留在待确认事项。
- 已有大型汇编不强制拆迁。以后只有在某个主题会反复使用、需要持续修改时，才抽成专用主档，并在此处登记其替代关系。
- 每完成五章或一个篇章阶段，结合连续性主表清理一次本页：补新主档、标出已失效的入口、检查待确认项是否已经被作者裁定。
- 术语、别名和内部编号的统一写法见 [术语与命名表](术语与命名表.md)；只收录容易造成检索或称呼歧义的项目，不复制设定解释。
