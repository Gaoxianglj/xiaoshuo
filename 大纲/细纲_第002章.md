# 细纲（第002章）

## 第二章：唯一的友人

- 核心事件：莉莉安逐渐适应学院生活，在玛琳持续而自然的陪伴中第一次拥有近似普通学生的日常；法杖风波、求亲与师长认可推进她在学院中的处境，菲莱尔与艾尔文分别保留无法证实的疑虑。
- 字数目标：约14000字
- 目标情绪：从拘谨与不安，缓慢走向温暖、安心与微弱期待；章末保留一丝不易辨认的不安。
- 章节定位：关系推进 / 低压生活 / 暗线铺垫
- 章首钩子：情绪钩子——下课后有人自然地等莉莉安一起走，她第一次不必独自离开教室。
- 爽点：法杖被嘲笑后得到阿尔瓦公正、专业的肯定；莉莉安的努力逐渐获得师长认可。

### 内容概括

- 起因：入学数周后，莉莉安开始熟悉学院路线与课程，玛琳主动把她带进正常的校园日常。
- 发展：两人在课间、图书馆、食堂与学院散步中加深关系；实践课上的法杖风波让玛琳公开站在莉莉安一边。
- 转折：玛琳提出婚约建议并撮合几位边境贵族子弟，莉莉安仍选择继续学习魔法；艾尔文以闲聊和旧文献试探精灵语。
- 高潮：菲莱尔坦承自己对玛琳只有说不清的异样直觉，莉莉安没有否定它，但也不愿仅凭直觉推开玛琳。
- 结尾：莉莉安获得阿尔瓦与奥莉维娅的认可，学院仍旧排斥她，但她已经有了一张有人等候的桌子；玛琳带来借书证，约她次日继续去图书馆。

### 情节安排

- 主线推进：建立莉莉安在学院中的日常生活与“这里也许能成为新生活”的感觉。
- 辅线推进：艾尔文继续研究精灵语；教授们注意到莉莉安的魔法能力。
- 事件线：校园日常 → 法杖展示 → 婚约建议与求亲 → 艾尔文试探 → 菲莱尔提醒 → 师长认可。
- 感情线 / 关系线：莉莉安对玛琳由警惕观察，转为接受照顾、主动回应，并开始把她纳入自己的日常安排；玛琳的照顾必须真实、自然、可靠，不揭示任务。
- 逻辑线：玛琳持续陪伴 → 莉莉安以小幅回应验证安全 → 公开维护加深信任 → 婚约建议带来短暂希望但不改变莉莉安目标 → 外界认可与友人陪伴共同构成归属错觉。

### 人物关系和出场顺序

- 出场顺序：莉莉安、玛琳、阿尔瓦、同班学生、边境贵族子弟、艾尔文、菲莱尔、奥莉维娅。
- 人物关系变化：莉莉安与玛琳从新近结识 → 能共享沉默与日常、莉莉安开始主动等她；菲莱尔维持保护性警惕但无证据；艾尔文维持试探但不作判断。
- 视角/信息差：正文以莉莉安第三人称限知为主；不进入玛琳内心，不向读者揭示其任务；艾尔文的怀疑只通过问题与停顿呈现。

### 结尾设定和钩子

- 结尾设定：莉莉安尚未完全信任玛琳，但已经开始用行动回应善意，并把共同日常视为理所当然的一部分。
- 章尾钩子：弱情绪钩子——玛琳说“明天见”，莉莉安第一次在分别之后真正期待第二天。
