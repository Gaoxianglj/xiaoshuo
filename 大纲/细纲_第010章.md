## 细纲（第 010 章）

### 第 010 章：将此当作你我初次相遇

- **篇内编号**：斯托克顿篇·第 5 章。
- **标题系统**：与第009章《我愿忘记》连读，组成原定章名《我愿忘记，将此当作你我初次相遇》。标题由未来卢卡斯回望这一阶段：未来记忆让他认出莉莉安，却没有替他认识眼前这个人；他愿意从宅邸与三日同行中亲眼看见的事实开始，将这段相处视作两人的真正初遇。
- **固定开头句**：`湖面点点光亮，他荡起双桨，两人便就此驶向远方。` 必须作为正文标题后的第一句逐字保留。该句先给出本章湖上结尾的未来回望碎片，随后立即回到东村旅店清晨，不补充多年以后、回忆录或全知解释。
- **承接关系**：直接承接第009章结尾。三日公开走访已完成第一日；莉莉安在南镇事故后仍有轻度眩晕、反应迟滞和精神疲劳，颈间新戴的静澜花香囊以幽香帮助她恢复专注。南镇事故已有“救人”与“控制整片湖水”两种版本沿补给路线传到东村。
- **时间跨度**：两日。第二日在东村核查磨坊、旧渠与道路并留宿；第三日前往北村核查干燥棚、柴薪和排水，傍晚与卢卡斯乘轻舟返回宅邸，当夜完成费用与物件收束。
- **核心事件**：东村和北村不再各自发生突发事故，而是完成走访前已有登记的冬前领务。东村村民希望莉莉安以魔法迅速解决水道和停磨问题，卢卡斯选择雇工、停磨并承担调粮成本；北村则由莉莉安给出结构与排水方案、木匠实际施工，两人在不依赖强大魔法的情况下形成工作默契。三日相处使莉莉安无法再用婚约、魔力价值或未来记忆完全解释卢卡斯的善意。湖上精灵出现后，她问出“您为什么一直对我这么好”，卢卡斯坦白未来记忆、核对小巷事件未发生，并明确现实观察比记忆更重。
- **字数目标**：约18000字，细化预算18300字，允许范围18000—19800字。
- **目标情绪**：从事故后的疲惫和被物化的不安，缓慢进入“一个人愿意为我的边界承担现实成本”的困惑；再通过共同工作、用餐、步行和相互照看，让温度变成双向。湖上情绪最高点不是爱情告白，而是两个少年第一次把最难解释的秘密和问题放到彼此面前。
- **章节定位**：关系回收章 + 普通领务推进章 + 核心秘密揭示章。外部压力1—2级，湖上情感烈度4级；不得再安排与南镇同级的动作危机。
- **主视角**：固定开头句后，全文以莉莉安第三人称限知为主。湖上谈话不切入卢卡斯内心；他的动机通过承认、停桨、回答范围和不强求她相信来呈现。
- **章首钩子**：闪前碎片 + 代价承接——固定句给出湖面光路，随即回到东村清晨：莉莉安在卢卡斯的纸夹上看见昨日夜里被划掉的“魔法协助”，旁边改成雇工人数、停磨半日与调粮安排。
- **核心收益**：三日同行将“卢卡斯对她好”从赠送衣物和礼貌照顾，推进为他愿意承担工期、金钱、舆论与选择成本；莉莉安第一次主动追问这份善意。卢卡斯公开未来记忆，V24推进到“小巷冲突未发生”的阶段结论。
- **章尾钩子**：物件回声钩子——莉莉安把新衣挂进衣柜，将带铜灯的小木船放入旧木箱内层。断杖仍在原处，箱盖合上，铜扣没有扣住。她仍不相信必然美好的未来，却开始保存一件与某个人有关、以后也想带走的东西。

## 大纲五检

1. **情绪与模式**：本章交付“善意因持续承担代价而变得无法忽视”。采用现实成本—共同工作—双向照看—秘密交换的关系模式，不靠一次救援、礼物或告白完成信任。
2. **核心冲突**：莉莉安试图用婚约、魔力血统和未来人物价值解释卢卡斯的行为；卢卡斯一次次尊重她在无用、休息或拒绝时仍拥有位置，使这些解释逐渐不够用。
3. **节奏**：东村中速推进并完成成本选择；第二夜放慢；北村以默契和公共分歧继续降速；湖上长谈承担情感峰值；归宅用费用、衣物和木船收束。
4. **伏笔**：推进流言路线记录、三地见证者、本地精灵与湖上光路、静澜花香囊、木船和未扣木箱、未来记忆与小巷偏移、重返学院外层目标。
5. **章节定位与承接**：没有与009相同的事故高潮。读者继续阅读的动力来自关系答案与未来记忆揭示；章末完成一个小而可信的关系进展，为011以后更慢的家庭积累留下空间。

## 内容概括（五段式）

- **起因**：固定开头句闪回湖上结果，正文回到东村清晨。莉莉安发现卢卡斯已把需要她施法的安排改成雇工、停磨和调粮。东村村民听过南镇故事，希望她直接用魔法清渠、抬轴，莉莉安也认为这样最省成本。
- **发展**：卢卡斯坚持先查看旧渠图、轮轴磨损和冬季磨粮需求，再决定以人力开渠、分段停磨和更换构件。莉莉安负责指出水道和受力问题，村民、木匠与雇工执行。她没有使用魔法，问题仍被推进；卢卡斯则实际承担多出的工期、粮食调运和抱怨。第二夜，两人在用餐、整理记录和桥边步行中讨论“一个办法被提出，不等于所有人闭嘴照做”，关系由单向照顾向相互约束移动。
- **转折**：第三日北村的干燥棚问题是预先登记的修缮。莉莉安给出斜撑、拉绳、碎石垫底和坡侧排水顺序，木匠完成工作。镇民亲眼看见她即使不施展强大魔法也能参与生活；同时仍有人坚持南镇事故是表演，或把她的价值归结为魔力血统。莉莉安开始自然替卢卡斯压住记录、递水、要求他休息，卢卡斯也接受这份照看。
- **高潮**：傍晚两人从北岸划船返回。当地精灵靠近，卢卡斯直接认出精灵，使莉莉安追问他为何知道，又在三日事实与血统流言无法相容的困惑中问出“您为什么一直对我这么好”。卢卡斯分轮坦白未来记忆，承认记忆让他认出并最初关注她；小巷核对证明现实从第一环已经偏移。他明确说，记忆没有替他认识她，宅邸与同行中亲眼看见的选择更重。
- **结尾**：卢卡斯提出将来陪莉莉安重返学院的愿望。她只接受他在说自己相信的真话，不把光明未来当成保证。精灵在夜色中照亮水路。返宅后，莉莉安坚持用工资支付衣物和纪念品，卢卡斯象征性收下三枚铜币并记账；她把新衣挂起，将带铜灯的木船收进旧木箱，仍不扣箱锁。

## 情节安排（多线）

- **主线推进**：三日公开走访完成。领民不再只有执行人投放的抽象传说，而拥有南镇事故、东村水道和北村修缮三组可争论的亲眼经验。
- **关系线**：卢卡斯从礼貌照顾推进到主动承担她不施法的现实成本；莉莉安从只接受照顾推进到主动限制卢卡斯过劳、参与双向照看；湖上完成第一次核心秘密交换。
- **领务线**：东村用停磨、雇工和调粮解决旧渠与轮轴问题；北村用木匠、斜撑与排水解决干燥棚问题。卢卡斯亲自记录，莉莉安只协助公开部分。
- **危险暗线**：东村和北村的流言抵达时间继续与补给节点重合；第一批见证者形成，但无法消除更广范围的恐惧。
- **精灵线**：本地精灵第一次在湖上聚集；莉莉安因担心牵连它们保持克制，为后面菲莱尔与原初之地邀请保留情感和规则基础。
- **命运线**：未来记忆第一次由卢卡斯向莉莉安公开；V24从“结果偏移”推进为“首都小巷事件未发生”，真正原因继续隐藏。
- **事件线 / 任务线**：东村核查与人工修缮 → 第二夜关系缓和 → 北村计划修缮与双向默契 → 水路独处 → 精灵出现 → 未来记忆坦白 → 返回宅邸与物件收束。
- **任务卡点**：东村本来要核查并修复磨坊，卡点是村民和莉莉安都把她的魔法视作最低成本方案；卢卡斯拒绝以她的身体支付，把问题改成正常领务成本。该卡点服务关系变化、错误信念松动和治理人物塑造。
- **逻辑线**：南镇施法建立“她很有用”的公共解释 → 卢卡斯在东村拒绝继续利用 → 莉莉安发现魔法之外的判断仍被需要 → 双向照看形成 → 血统与婚约解释不足 → 她主动追问 → 未来记忆与现实认识被区分。

## 人物关系和出场顺序

- **出场顺序**：莉莉安 → 卢卡斯 → 东村旅店人员 → 加文·里德 → 未具名车夫 → 磨坊主一家／村民／木匠 → 补给车与送货人（匿名） → 北村村长／木匠／村民／孩童 → 当地水精灵与微光精灵 → 艾尔伯、萨拉、蒂莉。
- **卢卡斯—莉莉安**：从“她知道他会保护自己”推进到“她主动询问他为何选择保护，并得到一部分真实答案”；仍未确认爱情，也未建立无条件信赖。
- **莉莉安—领民**：从南镇的能力见证推进到东村、北村对她判断与协作方式的见证；支持者仍是少数且理由不同。
- **莉莉安—精灵**：保持亲近与克制并存。她知道精灵爱她，却因菲莱尔受约束的经验主动拉开距离。
- **卢卡斯—未来记忆**：从把记忆当作保护莉莉安的主要起点，推进到主动承认其失效与局限；“忘记”是放下模板，不是丢弃警示信息。
- **视角／信息差**：莉莉安不知道卢卡斯不配得感和坏结局条件；卢卡斯不知道小巷混混缺席的真正原因；精灵不知道未来客观真假；读者只得到表层偏移链，不得提前锁定原卢卡斯身份。

3. 东村磨坊按原计划接受检查。旧渠淤积、轮轴偏磨、冬季磨粮高峰和运输道路逐项呈现。莉莉安先看图、泥线和轮叶受力，提出分段开渠、清淤、换木栅和停磨检修方案【领务推进／能力表演·密1000】。
4. 村民因南镇传闻要求她直接以魔法清渠、抬轴；莉莉安也主动提出这样能省下雇工和停磨损失。卢卡斯说明问题并不迫在眉睫，选择雇人和调粮，面对抱怨时不把决定推给她【选择成本／关系推进·密900】。
5. 人工修缮开始。莉莉安指明开渠顺序、绳索位置和检查点，木匠、磨坊主与雇工操作；加文管理危险区域。魔法没有出现，事情仍在推进。莉莉安第一次在“没有付出身体代价”的情况下被人听取办法【错误信念松动·密1100】。
6. 她再次计算停磨和运输成本，卢卡斯说明调粮、赔水轮、挨抱怨都是领务的一部分；保留并重写“我不是账。”“对，不是。”，让这句话回应南镇血统流言与她的自我计价，而非单纯机灵对白【关系密点·密700】。
7. 第二夜用餐与桥边步行。保留粗麦饼、蜂蜜坚果、先吃完再写、旧渠图、鹅的玩笑和询问后整理披肩等生活动作；减少连续斗嘴，让莉莉安第一次主动按住纸页、要求卢卡斯先吃饭，卢卡斯实际照做【双向照看／情绪冷却·密1200】。
8. 送货人带来“河倒流”“白发小姐托住整艘船”等变形版本。磨坊主和工人纠正实际步骤；卢卡斯发现最早听闻者仍与同一通行节点、盐车或灯油车有关，补记时间。莉莉安看见流言会扩张，也看见事实能留下少量抵抗【伏笔推进·密500】。
9. 第三日北行。马车内不再补新的礼物桥段，而写共同整理公开纸页、分食剩余干粮和路线选择；莉莉安发现卢卡斯指侧墨迹与疲劳，开始留意他的身体，而不只计算自己欠下什么【三日互动递进·密650】。
10. 北村干燥棚、柴薪和排水按登记接受检查。莉莉安判断柱脚受潮、坡水积聚与主梁受力，提出斜撑、拉绳、碎石垫底和挖排水沟的顺序；木匠检查并施工。有人建议她直接托起棚子，卢卡斯与木匠都选择按正常工序完成【领务推进／去重复·密1100】。
11. 镇民反应继续分层：南镇直接受益者的说法传来；北村木匠因亲自施工反驳“棚子自己飞起来”；仍有人坚持事故是男爵家安排的戏。孩童送来酸浆果薯饼，母亲不自在却不阻止【公共见证／情绪回温·密650】。
12. 午饭与记录收束。莉莉安把水杯放到卢卡斯正在写的纸边，要求他停笔喝水；他没有用玩笑推开。两人核对修缮期限时形成自然默契，照顾第一次明确成为双向【关系收益·密600】。
13. 傍晚准备走水路。加文检查船底、桨锁、灯、毯子和雾情，随后与车夫带行李走陆路去南码头等候。卢卡斯不把独处当既定安排，最后再询问莉莉安是否愿意乘船；她自主选择水路【独处条件／选择权·密650】。
14. 轻舟离岸。两人先谈三日里被夸大的故事、真正参与救援和修缮的人；卢卡斯承认自己无法让所有人闭嘴，只能让亲眼经验留下。节奏放慢，用桨声、芦苇、水鸟和逐渐远去的北村承载沉默【湖上过渡·密750】。
15. 水精灵与微光精灵靠近。卢卡斯认出光点是精灵属于神赐之地常识，不引发莉莉安异常；她只以精灵语礼貌回应，不主动召集。卢卡斯观察光点围着她与船沿移动，说“精灵们真的很喜欢你”，又问她为何不回应它们更多。教国研究认为精灵没有感情，也不知道人类能够沟通，莉莉安由此确认他知道自己从未公开的秘密【秘密触发／认知反差·密900】。
16. 在追问前，莉莉安回想三日中的矛盾事实：他在最适合展示魔法时让她停下，为不用她的魔法承担停磨成本，在北村仍询问她的判断；这些行为与“为了魔力血统才订婚”的说法不相合。她最终只问：“您为什么一直对我这么好？”【情感高潮起点·密900】。
17. 卢卡斯分轮坦白未来记忆：幼年起拥有一段像亲历过的未来；白发、淡紫眼睛和已知经历使他最初认出并关注莉莉安；在那段未来里，她像故事中心的人。他承认记忆影响，不说虚假的“完全无关”，也不把她捧成必须符合模板的人【核心秘密揭示·密1800】。
18. 莉莉安以具体问题核对：首都小巷、混混、莱恩。她明确这些事没有发生。卢卡斯只还原小巷未发生导致莱恩、理查德、埃德蒙未进入关系网，玛琳栽赃无人及时拆穿的表层偏移链；划桨、停桨和精灵移动打断解释，避免连续长讲【命运线推进·密1200】。
19. 卢卡斯说明玛琳事件的改变证明记忆中的事件和人物都不能替现实作证；说出接近“那些记忆让我认出了你，却没有替我认识你”的核心表达。他以宅邸和三日同行中亲眼看见的行为为更重依据，并提出将来若她愿意，希望陪她重返学院【标题兑现／关系转折·密1200】。
20. 莉莉安无法相信耀眼未来，只接受卢卡斯主观上没有欺骗。精灵给出有限判断：“他在说自己相信的真话。”夜色加深，精灵为担忧的爱子在湖面铺出光路，兑现固定开头句【克制回应／意象回收·密700】。
21. 返回南码头与宅邸。加文只知道二人晚归，不知道湖上谈话；艾尔伯和萨拉听取三地领务摘要。莉莉安坚持支付衣物与纪念品，卢卡斯收下三枚铜币并记账。她挂起新衣，把带铜灯木船放进旧木箱内层，断杖不动，箱扣仍开着；静澜花香囊仍系在颈间，没有与纪念品一起收起【关系落点／长期物件／章尾钩子·密800】。

## 代价兑现与收益兑现

- **莉莉安的代价**：继续承受流言与被血统化的解释；主动面对卢卡斯知道自己过去这一不安事实；未来记忆揭示没有立即给她安全保证。
- **莉莉安的收益**：亲眼确认自己不使用强大魔法时，判断、陪伴和存在仍被需要；第一次能够直接追问别人善待自己的理由；获得一个可由自己决定是否相信、是否继续靠近的答案。
- **卢卡斯的代价**：承担东村停磨、雇工、调粮与领民抱怨；交出最难解释的未来记忆秘密，并接受莉莉安不相信其光明结论。
- **卢卡斯的收益**：确认小巷冲突未发生，找到现实偏移的第一处表层断点；莉莉安没有退回纯粹工作关系，而是继续与他完成归程。
- **关系收益**：两人从“单向保护与偿还”推进到“能够相互限制过劳、询问动机并保留不同判断”；木船进入旧箱，代表莉莉安开始保存与这段关系有关的以后。
- **后续账目**：公共意见仍然分裂；敌方传播链未锁定；重返学院只是一项外层愿望；卢卡斯的不配得感和坏结局条件继续隐藏。

## 结尾设定和钩子

- **结尾状态**：三日走访结束。第一批直接见证者形成，流言不再能无限垄断解释，却获得“强大、可怕、适合作为魔力血统”的新材料。卢卡斯和莉莉安完成未来记忆的第一次坦白与核对。
- **未解决问题**：执行人身份、流言传播目的、小巷事件消失原因、未来记忆真相、重返学院是否可能、莉莉安能否真正相信自己拥有以后，均保持开放。
- **章尾钩子**：物件回声钩子，期待度中。旧木箱接纳木船却仍未上锁；下一阶段不立即进入投毒，而以更慢的家庭与领地生活证明，她保存的不只是一趟三日旅行。
