## 一、起点事实与本幕不变边界

### 1. 已发生的起点事实

- 莉莉安与卢卡斯尚未启程，也未收拾行李、确定日期或路线；二人只约定共同寻找新法杖、收集学院复核条件，并允许旅途停下、改道、返回或重问精灵。
- 莉莉安仍以人类身份保留原初之地为真实选项；她拒绝的是在最想消失时替未来作不可逆决定，不是拒绝菲莱尔或精灵的爱。
- 莉莉安仍是被正式退学、签过认罪书并放弃复核的当事人；她的旧案、学院秘密监狱、六日秘密搜捕及塞西莉亚的非法问询均尚未在故事内清算。
- 古木主杖仍断裂，普通短杖仍有右偏与迟滞；新法杖只是一项待寻找的目标。
- 卢卡斯的未来记忆已在玛琳事件、首都小巷与斯托克顿危机中出现偏离；他不知道坏结局内容，也没有向莉莉安坦白其不配得感。
- 莉莉安与卢卡斯仍是名义婚约与极深友情，未告白、未改变称呼，也未把同行变成爱情承诺。

### 2. 本幕必须守住的边界

1. **主题只完成“我可以拒绝”**。莉莉安可以恢复愤怒、厌恶、反驳与边界感；“我真正想要什么”以及爱情确认留给重返学院篇。
2. **不让主角解决数十年的征服、失土与战争史**。两人最多阻止一次不可逆灾难、打开一次停火或谈判裂口。
3. **不把海啸写成纯粹正义，也不把海韦尔居民写成应为历史征服自动受罚的人**。失土的历史不公与后续对平民的伤害必须同时成立。
4. **不以“装备升级”替代人物选择**。传承法杖的取得应证明莉莉安有能力使用、也能在应当停止时停止，而非证明她替伯爵赢得战争。
5. **不让卢卡斯靠游戏记忆成为正确答案或战争军师**。他的现实能力仍有价值，但价值不以全知、最强或不可替代为条件。
6. **不让玛琳的原谅线在此幕结案**。她后续回归是莉莉安的长期试炼，不是海韦尔的附属支线。

## 二、核心命题与三条情感主线

### 1. 核心命题

> **拒绝别人替自己做决定，也不因此替别人做决定。**

本幕中的“拒绝”有四个逐层升级的对象：

1. 莉莉安拒绝让白发和旧案决定自己能否进入一座城市；
2. 她拒绝让伯爵以保护港口之名征用自己的魔法；
3. 她拒绝让海啸以故土与复仇之名征用自己的魔法；
4. 她拒绝替所有人完成“谁该获胜、谁该被牺牲”的最终裁决。

卢卡斯的对应命题是：尊重莉莉安的拒绝，不等于先把自己从她的生活中删去。

### 2. 莉莉安：从“暂时藏起”到“决定何时显露”

她在斯托克顿已学会：离开并不必然失去回来的资格。海韦尔要进一步让她明白：理解一个人的理由、甚至同情他的痛苦，并不取消她说“不”的资格。

她的情感并非从创伤直接跃迁为轻快自信，而是依次经过：

```text
愿意出发的谨慎 → 对“普通身份”的陌生松弛
→ 被扣留后的警觉与同情并存 → 明确拒绝被征用
→ 因拒绝造成真实损失后的动摇 → 仍保留边界
→ 能在不替任何阵营裁决的前提下主动施法
```

她最后获得的是“不必为了拒绝而消失”的认识；她仍不知道最终想要什么，也不应在此确认爱情。

### 3. 卢卡斯：从熟悉地的能手到不必有答案的同行者

斯托克顿中的成熟、效率与判断力都是真的：他熟悉领务、人情、道路、账目与自身未来领主的位置。海韦尔不是把这些能力否定为虚假，而是抽走它们可以直接生效的环境。

```text
“我记得任务流程” → 现实偏离后的不安
→ 外来继承人的有限位置 → 莉莉安成为双方意图争夺的核心
→ “我既不知道答案，也无法保护她”的自我贬低
→ 因过度后退伤及关系 → 用具体、普通而必要的工作重新参与
```

他的自卑应主要表现为**退得太远**，而非持续低落、索取安慰或把情绪负担交给莉莉安。幕终他只需第一次承认“我不知道”，并看见莉莉安仍愿意把一项具体事务交给他；不配得感的彻底爆发与回收留在重返学院篇。

### 4. 两人关系：不同意仍可同行

本幕关系线不以暧昧、告白或“彼此唯一”推进，而以三种新经验推进：

- 莉莉安拒绝卢卡斯的一项安排，卢卡斯学习“不替她决定，也不消失”；
- 二人就海啸与港口居民的处境发生真正的价值分歧，仍能在隔日共享情报、共同行动；
- 分处两边时，他们只信任对方已经明确过的底线，不以万能默契取代沟通或知情边界。

幕终可抵达“彼此最重要、最信任的朋友之一”的实际状态，但不将名义婚约转化为爱情关系。

## 三、缇娅、黑发与重返学院的前置功能

### 1. 设定功能

“缇娅”【暂名】是莉莉安在海韦尔使用的短期保护身份；黑发是使这段身份可运作的物理条件。它们不是对白发苦难的轻率解决，也不是让莉莉安从此抹掉原有身份。

染发膏【作者确认的技术口径】由三项缺一不可的条件共同完成：

- 当地材料提供深色颜料、载体与固色媒介；
- 卢卡斯以现代生活经验提出“均匀附着、分层固定、先试色、避免粗糙结块”的工艺思路；他不是凭空制造现代化学品；
- 莉莉安以精细控物与极微弱热度控制，让长发获得均匀而自然的短效着色。

这解释了莉莉安过去即使受白发所苦，也没有一个现成、可靠且安全的办法可用：本地零散材料不足以遮住她过于明亮的白发；她此前也没有资源、试错空间与愿意认真帮她解决问题的人。

### 2. 情感边界

- 这不是“她终于变正常”，而是“今天，她不想先以白发魔女的身份进入一座陌生城市”。
- 卢卡斯只能提出选择和说明风险，不能替她上色或替她决定缇娅是否出现；莉莉安必须亲自同意、参与试色并决定何时使用。
- 染发膏不抹除淡紫眼睛、旧案、法术风格或熟人近看时的识别风险；它只争取一段不先被白发定义的空间。
- 普通小雨不立刻失效；长时间浸泡（淡水或海水）、强力清洗或超过补染周期会破坏固色层。此限制需在情节前段明确，不能到岛上才临时失效。

### 3. 学院接口

缇娅可为后来“重新接近学院”预先创造一道门，但**不能成为莉莉安永久替代的正式学籍**。拟定方向是：

1. 艾尔伯以“受斯托克顿家监护的远房遗孤／受庇护亲属”而非正式收养女儿的方式，为缇娅建立出行与担保位置；
2. 该身份未来可绕开“退学生莉莉安”的自动拒绝，使她获得申请、旁听或临时学习资格的机会；
3. 真正进入重返学院篇后，莉莉安必须由自己决定何时承认“缇娅就是莉莉安”，并以莉莉安的正式身份面对旧案；
4. 判决推翻后，她继续以莉莉安身份学习。缇娅完成的不是取代，而是让她能选择怎样回来。

学院的常规考试准入已确定为“教廷认证的贵族领主出具介绍／担保信”：学院核验信件、印记与出具资格，保存推荐人、公开姓名与责任落点，却不会在无具体争议时主动清查家门的旁支、私生或监护隐情。莉莉安最初以本名入学的银质教廷凭证，则源自阿尔维斯以重返教廷参与秘密项目为筹码，换取一位现任主教签发的特别推荐／准入信；它不含贵族担保责任。详见[学院招生与贵族担保](../设定/世界观/学院招生与贵族担保.md)。

**硬边界：不得将莉莉安正式过继为艾尔伯之女、成为卢卡斯法律意义上的妹妹。**缇娅固定为“由艾尔伯担保监护的远房支脉遗孤”这一公开说法，而非养女或法律上的妹妹。这既符合学院担保制度，也保留伪装被主动揭露后须承担的程序风险；不能以“没人会记得平民家谱”充当万能豁免。

## 四、幕级路线

### 第一段：出发前的“可以试一次”

> **进度（2026-09-18）**：第020章《至此我们踏上旅途》细纲及正文已建立，覆盖本段从莉莉安独自采买归宅、染发试验与短时耐水验证，到二人驾有篷货车离开斯托克顿宅邸的内容。后续细纲从离宅后的行路、落脚或抵达前选择继续；本标记只确认本章已写事件，不把后续幕纲预案记作正文已发生。

**外部事件**：第二幕的北山交接、案件与艾尔伯恢复仍在进行；旅行不能被写成领地已毫无负担。故事发生在斯托克顿的冬季淡季，但仍须等艾尔伯能保留最终领务签署、萨拉稳定宅邸日常与文书收发、加文等骑士按既有职责轮替后，才取得一段可调整的短期出行窗口。两人对外只以旅行度假和维系南方货物采购为由；寻找法杖是对外隐藏的真实目的。第020章出发时由卢卡斯亲自驾车，莉莉安与他两人同行，不安排骑士随行。

**莉莉安的情绪与选择**：她不是被卢卡斯“带去新人生”，而是在知道能停、能回、能先问精灵的前提下主动答应。对黑发试色的迟疑不是虚荣或羞耻，而是第一次认真思考：自己是否有权选择不被所有人立刻认出。

**卢卡斯的情绪与选择**：他仍有熟悉的轻松感——这是自己能准备路线、材料、文书与旅宿的领域；游戏记忆也让他认为法杖线大致可控。他的自信应显得可亲且真实，而非等待被嘲笑的傲慢。

**关系变化**：莉莉安主动提出或明确同意缇娅身份；卢卡斯提供方法但不替她取名、决定妆束或签下她不知情的文书。

### 第二段：海韦尔的日常与“任务”的诱惑

**外部事件**：海韦尔是已确定的北方繁荣海港：狭长海岸攀上山势，桥梁、长阶、平码头与白帆小船并存；冬季较温和，聚集贵族旅客、鱼市、旅店、船铃与外来商旅。它与斯托克顿的旅游旺季互补，五至六日马车路程及既有南方货品采购，使卢卡斯的来访不显突兀。卢卡斯以继承人身份拜会当地伯爵【姓名待定】，公开谈的是旅游与客源互通，私下则试探传承法杖的线索；正式长期承诺仍须由艾尔伯书面背书。详见[海韦尔与海啸](../设定/世界观/海韦尔与海啸.md)。

**莉莉安的情绪与变化**：黑发的缇娅在陌生人群中短暂不被凝视，使她发现热闹未必等于危险。她仍会防备，但开始把注意力放到海洋魔法、船只、潮汐与新的学习对象上。这是重返学院“我仍想学习”的最早正面火苗，不提前变成“我已经知道未来要什么”。

**卢卡斯的情绪与变化**：伯爵提出近似游戏任务的交换——“协助解决海啸，传承法杖可供莉莉安使用”【拟定】。卢卡斯暂时把它理解为“完成条件—取得副杖”，这既合乎他的记忆，也埋下现实会打破这套逻辑的缺口。

**关系变化**：莉莉安不立即承诺法杖交换。她可以问清副作用、条件与自己是否能拒绝，而不是让卢卡斯默认替她接下任务。

### 第三段：有目的的扣留，而非方便的海难

**外部事件**：海啸【拟定】的一个行动小队得知两名年轻的斯托克顿贵族亲属在海韦尔附近活动，意图以他们交换己方被俘者、拖延封锁或争取谈判筹码。扣留发生在可解释的转运空档；一场风暴可使原本快速的转移延长，但不是“刚好失事、刚好被救”的主因。

**限制条件**：卢卡斯与莉莉安不能因“没有护卫”显得无故失职。需另定当地向导、车夫、港口雇员或有限护卫如何被隔开；海啸也必须有可计算的情报来源与交换需求。

**莉莉安的情绪与变化**：她重新进入“被他人决定去处”的恐惧，但不退回学院时期完全服从的状态。她会判断、提问、保护有限的同行者，也会在有余地时说出不同意。

**卢卡斯的情绪与变化**：游戏记忆第一次在眼前失效：原本应当存在的安全路线、任务顺序或敌我关系都不成立。他仍能处理眼前的小事，却不能用记忆保证出口。这是自卑的第一道裂缝，而非一次失败便自我否定。

### 第四段：岛上的人、白发与第一次双向拒绝

**外部事件**：二人处于受限制的扣留状态，而非被温柔地“邀请作客”。海啸的居民区、家庭、伤者与补给困难可被有限看见；行动自由、消息与离岛资格仍受控制。组织上层可不认同行动小队的手段，却不能借此否认扣留已经发生。

**白发节点**：经过长时浸泡（淡水或海水）或强力清洗，染膏的固色层破坏，莉莉安白发重新露出。此事不是“神秘女主掉马”，而是她选择暂时隐藏的物理边界抵达。岛上有人因此把她视作教国的异端象征，也有人因此以为她能成为反攻工具；两种反应都不等于信任。

**莉莉安的情绪与变化**：她看见失土、旧墓地、被抹去的名字与活在岛上的孩子，能理解仇恨从何而来；但她拒绝被要求以自己的力量毁掉港口或杀伤不相识的居民。她第一次把“我理解”与“我不会替你做”连在一起。

**卢卡斯的情绪与变化**：他开始意识到，自己先前试图“拿到法杖再解决问题”的想法已经把莉莉安放进了功能位置。他未必立刻说出完整自卑，但会在具体选择中减少替她安排的冲动。

**关系变化**：莉莉安可拒绝卢卡斯介入一项与自己相关的决定；卢卡斯答应后却退得过远。此处只埋下矛盾，不立刻用温情解决。

### 第五段：归港、真正争吵与“我说的是那一件事”

**外部事件**：二人因交换、临时谈判裂口或海啸上层的有限决定回到港口；不能以无代价逃脱抹掉扣留。伯爵方把他们的见闻理解为要求更快清剿的理由，海啸亦加快反攻准备。二人逐步确认双方的“最后一战”将撞上同一潮汐、风暴或古老海防设施【具体机制待定】，胜负可能转化为吞没两边平民的灾难。

**莉莉安的情绪与变化**：她不接受“因为海啸扣留过我们，所以港口一方当然正确”的结论；也不接受“失去故土，因此后来所有攻击都正当”。她第一次允许自己与卢卡斯在价值判断上不同，而不把分歧自动理解为关系破裂。

**卢卡斯的情绪与变化**：他更本能地看到若战争进入港口，今日生活在这里的水手、商贩与孩子会怎样受伤；他害怕莉莉安再次成为被双方争夺的中心，也开始把“她不需要我”误读为自己该完全退出。

**关系场**：莉莉安指出：“我说的是那一件事，不是让您离开。”这不是爱情安慰，而是一次边界的精确校正。卢卡斯听见后不应突然痊愈，只能开始学习在不代替她决定的前提下留下。

### 第六段：分处两边，但不成为彼此的武器

**外部事件**：为阻止灾难，二人各自进入能实际影响撤离与信息的一侧：卢卡斯留在港口一方处理船只、名单、仓储、民众撤离与有限信息传递；莉莉安在岛屿一侧协助民用撤离、劝阻与潮汐风险判断。她不是海啸的战斗武器，卢卡斯也不是伯爵的战争军师。

**分处的条件**：双方必须已通过多次接触形成最低限度信任；莉莉安留在岛侧应是自主选择而非再次被扣留。岛方与港方为何分别允许他们行动、如何限制其情报、如何建立临时接触窗口，均须在细纲前补足。

**默契的写法**：二人不神奇地猜中彼此全部计划，只依靠此前明确过的底线与有限信号：不把平民当筹码、不用对方作人质、不优先保全军械而牺牲撤离通道。读者看见的是“他们知道对方不会跨过什么”，而非“他们知道对方会怎样赢”。

**卢卡斯的实际价值**：他可以承认“不知道谁该赢”，却仍完成无人替代的普通工作：核对哪艘船还能承人、把名单交给正确的人、在混乱中让一条撤离线持续运作。他重新参与，不靠变成特别的人。

### 第七段：传承法杖与连续拒绝

**外部事件**：伯爵家传承法杖被揭示为高流量导魔器：它能在极短时间倾泻极大量魔力，难点不是能否发出，而是能否停止。莉莉安因极高魔力储备与精密控制具有使用条件，但并不免除精神负荷、物理限制与失控风险。

**四次拒绝**：

1. 拒绝伯爵方以保护港口为理由，要求她实施会造成岛民与非战斗者大规模伤亡的决定性攻击；
2. 拒绝海啸方以失土与复仇为理由，要求她摧毁港口或攻击普通居民；
3. 当卢卡斯因担心法杖代价而想替她事先放弃一种方案时，拒绝他替自己说“不”；他可以劝告，但须完整告知风险；
4. 拒绝战场给出的“海韦尔赢／海啸赢”二选一，不替任何一方完成历史的最终裁决。

**主动行动**：莉莉安在充分知情后选择使用法杖，但用途是打开撤离水道、托住濒毁海堤、暂时隔开舰队或破坏会引发全面追击的关键结构【四选一，细纲前定】。她在最有能力替所有人下结论时，选择只创造“人们还能活着再作选择”的空间。

**真实代价**：拒绝不能自动导向完美结果。应保留一项具体、可见、不可由莉莉安独自挽回的损失——例如旧港一段毁坏、救援船未归或一名已具生活质感的水手／岛民死亡。它不是为了证明她拒绝错误，而是承认她不能以强大魔法免除所有人承担战争后果。

### 第八段：法杖的归属与未完成的和平

**外部事件**：灾难被阻止，战争未被解决。岛上旗帜仍在，港口仍由海韦尔治理；双方保留武装与不信任，但可出现临时停火、俘虏交换、民用航线、补给窗口或首次谈判。

**法杖归属**：伯爵最终交出法杖，不是因为莉莉安替他获胜，而是因她有能力使用、也在应停时停止。法杖成为她的重要副杖；古木主杖仍断裂，不能被这一收获取代或修复。

**莉莉安的情绪落点**：她没有突然知道自己想要怎样的人生，却能清楚说出许多自己不接受的事。她能拒绝，也不再默认拒绝后必须离开所有人。

**卢卡斯的情绪落点**：他仍会怀疑自己是否适合站在莉莉安身边，但已知道她的“不”并不要求他消失；她仍信任他的认真、具体与选择。

**下幕接口**：海洋魔法、新副杖、缇娅身份的实践与学院复核材料，使“重返学院”从洗冤任务转为主动学习与重新面对旧制度的选择。莉莉安尚未以缇娅身份入学，亦未与玛琳和解。

## 五、玛琳线：保留重量，不挤占海韦尔

### 本幕默认方案

玛琳不在海韦尔正式出场，不承担海啸冲突的调停、情报或受害者功能。她已去往的海滨城市**确定不是海韦尔**；不应为了相遇方便而自动合并地点。

这样可避免同一幕同时承载失土战争、法杖考验、身份试验、莉莉安旧友重逢与原谅结算，导致每一条都只被快速处理。

### 可选的极轻预埋

若作者希望海韦尔触碰一次玛琳线，最多采用“莉莉安得到一条可证实但不足以定位的消息，知道玛琳仍活在另一座海滨城市”的形式。莉莉安可以选择不去找她：不是永远拒绝玛琳，而是拒绝在尚无准备时替对方完成和解。此方案必须先解释消息来源，且不使用擦肩相认、偶遇码头等高巧合安排。

### 重返学院篇的回收职责

玛琳应在学院旧案复核中重新拥有自己的主体性：她的真实陈述可协助推翻旧判决，却不能自动换取莉莉安原谅。莉莉安可以承认她说了真话，同时拒绝替她完成自我赦免。这是“拒绝”主题在私人关系中的后续回声，而非海韦尔主线的额外高潮。

### 远期候选：斯托克顿的书记职责

学院篇结束后，玛琳可以申请并经试用进入斯托克顿领的书记／文书岗位。这应来自她自己的稳定选择、可核验的文书能力与持续承担，而不是莉莉安一句原谅后的安置；艾尔伯负责雇佣决定，莉莉安不能被迫替整个家族担保。若成立，它能让玛琳在之后的领地危机中以一次坚定而专业的选择完成自己的救赎，但目前仍是远期方向，不是本幕承诺。

## 六、台词与阵营呈现的使用边界

- “我们终将复仇，正如同那海啸……”这类殉道式语句更适合海啸强硬派或动员场合，不宜直接定义整个组织的最高领导人；否则会抹平其居民、务实派与行动派的分歧。
- “以主之名，赐予尔等葬身神赐之海的慈悲”更适合主战军官、极端贵族或教士，而非必须保护港口居民、最终又承认莉莉安选择的伯爵本人。
- “世界的女儿”目前不是已锁定称号，也会把莉莉安推成替历史发判词的天选者。本幕不使用该称号。她的表达宜具体、有限：理解仇恨，但拒绝替不相识的人去死。
- 卢卡斯关于“野兽”的反问可保留为港口小范围会议中的反战表达；它不是替海啸洗白，而是指出拒绝交谈也是有后果的选择。

### 3. 仍须在细纲前补足的解释

| 项目 | 目前的问题 | 细化前必须补足的内容 |
|---|---|---|
| 缇娅的进入方式 | 担保制度已经成立，但“假名旅行者”怎样转为学院可接纳的身份仍有程序风险。 | 固定信中使用的姓名、她获得的准入类别、何时主动承认莉莉安身份，以及旧案复核如何与新身份问题分开处理。 |
| 伯爵与法杖交接 | 器物的危险机制已定，但持有权与转移会牵涉地方威慑。 | 明确伯爵姓名、家族内部知情者、交接的停战条款、见证者与莉莉安离城后谁承担监督。 |
| 海啸组织 | 基础民生与准政府功能已定，内部权力结构仍空缺。 | 定义居民、武装、强硬派与谈判派如何互相制约；补足俘虏政策、近年行动与港口平民受到的具体伤害。 |
| 扣留与回归 | 若无情报来源、护卫安排、交换目标与释放理由，会显得主角为了看岛而被方便绑架。 | 明确海啸得知行踪的来源、转运空档、有限护卫为何失效、扣留的可计算目标、风暴作用和回归条件。 |
| 两人分处两边 | 若一方刚扣留过二人便任其行动，会削弱可信度；若只是“默契”也会越过知情边界。 | 先建立多轮接触、担保与限制，再安排自主留岛；具体约定信号、信息权限与撤离职责。 |
| 高潮灾难 | 潮汐、风暴、海防与岛屿崩坏若全数叠加，会变成随意升级。 | 只选择一个主灾害机制、一个触发链和一个可施法缺口；逐项写物理限制、人员动作与法杖代价。 |
| 学院接口 | 旧案复核、恢复学籍、试读制度与塞西莉亚何时察觉仍未锁定。 | 在重返学院篇细纲前决定：缇娅的准入类别、学院档案怎样交叉、莉莉安主动显露身份的时机、判决撤销的证据层级。 |
| 卢卡斯的学籍与领务交接 | 冬季短途旅行已有合理窗口，卢卡斯的正式学籍与长期离领仍待确认。 | 不能让他无说明长期离领、又无缝进入学院；需补足后续书记、艾尔伯的恢复程度与其本人学习安排。 |

### 4. 本轮刻意避免的冲突方向

- 不将莉莉安写成“只要勇敢做自己，白发问题就自动消失”；
- 不让染发或缇娅永久取消她的旧案与白发处境；
- 不让伯爵、海啸或卢卡斯替莉莉安决定她是否、何时、怎样使用法杖；
- 不让精灵直接裁定战争、引导卢卡斯找到正确答案，或绕过莉莉安的知情同意；
- 不让卢卡斯以未来记忆揭破海啸、赢得战争或成为唯一军师；
- 不把岛民、港口居民或玛琳变成只服务莉莉安成长的背景工具；
- 不在本幕完成学院清算、玛琳原谅、卢卡斯自卑治愈或爱情告白。

## 八、下一步细化顺序

在建立章节细纲前，先由作者确认或选择以下优先项：

1. 缇娅进入学院时的准确准入类别、文书姓名与主动揭露身份的程序代价；
2. 伯爵姓名、法杖交接条款与海啸的具体组织结构；
3. 扣留、释放、回归与分处两边的具体因果链；
4. 高潮只保留哪一种灾害机制与哪一种法杖行动；
5. 重返学院篇中缇娅如何成为进入学院的门、莉莉安何时主动恢复正式身份；
6. 卢卡斯长期离领与未来学籍安排；玛琳是否在学院篇后通过试用进入斯托克顿的书记岗位。

这些结论确定后，再按场景拆为章节细纲、人物状态账本与相应世界观增量；在此之前，本文件不把任何待定内容当作已发生事实。
