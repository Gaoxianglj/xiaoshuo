## 细纲（第 006 章）

### 第 006 章：在那森林与湖之地

- **篇内编号**：斯托克顿篇·第 1 章。
- **时间锚点**：莉莉安抵达斯托克顿领的数日前；首都刚入秋前后，位于更外围的斯托克顿领仍留有夏末气息。
- **核心事件**：威廉·福克斯借狩猎度假到访，以全面撤回北境驻军相威胁，迫使尚无法独立戍边的艾尔伯签下卢卡斯与莉莉安的婚约。
- **字数目标**：8000 字。
- **目标情绪**：先让读者感受森林湖泊与旅游业的富有生命力，再意识到这份美丽被一支不属于斯托克顿家的军队托住，最终落入“为保住一领人，父亲被迫出卖独子婚姻”的窒息与愧疚；结尾以卢卡斯的过劳和萨拉的无声照料，把政治交易落回这个善良却疲惫的家庭。
- **章节定位**：普通推进章 + 政治暗线冷开场。
- **主视角**：艾尔伯·斯托克顿第三人称限知；章末用明确分隔切入萨拉·约翰逊第三人称限知的短尾声，功能是从旁观者角度呈现卢卡斯的过劳与斯托克顿一家的可惜，不进入熟睡中的卢卡斯内心。
- **开篇引句**：保留原始初稿的卢卡斯主题句“我遗忘了大多数的过去，却记得大多数的未来……”，作为无署名短引或黑色笔记本摘句；本章不立即解释说话者与“未来”的真相。
- **章首钩子**：反差钩子 — 威廉在北山堡垒与原始森林的交界处享受一场精心侍奉的狩猎；他命中猎物时，远处哨塔的换岗号声同时响起，提前把“度假背后的军事权力”放入画面。
- **爽点**：无显性爽点。本章的追读力来自权力反差、婚约交易的不公，以及卢卡斯将如何面对父亲带回的决定。

### 保留的原始骨架

- 保留“森林狩猎 → 湖边晚宴 → 婚约施压 → 艾尔伯归宅 → 安娜遗物触发愧疚 → 花园书屋中的卢卡斯”的空间与情绪骨架。
- 保留“我遗忘了大多数的过去，却记得大多数的未来”这一卢卡斯主题句，但不在政治冷开场中提前解说全部转生真相。
- 保留威廉享受狩猎、喜爱被恭维、大量消费斯托克顿旅游服务的表演。
- 保留布莱克伍德葡萄酒、湖边火光、猎物烧烤和艾尔伯宅邸天花板金丝等可识别物件，但它们必须服务于经济成果、权力压迫和艾尔伯的罪恶感，不作无功能装饰。
- 原稿中的无名女客不进入本章核心事件链；威廉的挥霍与阶层恶意通过他对猎物、侍从、酒宴和驻军的消费方式呈现。

## 大纲五检

1. **情绪与模式**：交付“美丽之地被旧债务提住命脉”的窒息；使用“享乐表层 → 试探 → 权力揭底 → 家庭代价”模式。
2. **核心冲突**：艾尔伯要保住领地和独子的未来，但威廉使用前者迫他牺牲后者。
3. **节奏**：狩猎与晚宴前半段表面舒缓，试探自招募武装开始加速，“全面撤军”后进入高压对话，回宅后收紧为家庭罪恶感。
4. **伏笔**：推进 V03 婚约吞并线；新埋“第二代福克斯子爵离奇死亡”、“福克斯驻军与斯托克领居住关系可能导致忠诚分化”两个未定回收点。
5. **张弛与定位**：本章为政治暗线推进章，不做阴谋爆发；下一章立即转入莉莉安到达与家庭日常的低烈度情感冲击，避免连续政治高压。

## 内容概括（五段式）

- **起因**：威廉第三次来斯托克顿领狩猎度假；他表面享受卢卡斯打造的旅游项目，实际已准备利用驻军依赖迫使艾尔伯接受婚约。
- **发展**：狩猎后的湖边晚宴上，威廉从旅游收入、新结识的贵族谈到斯托克顿近年招募的骑士、魔法使和民兵，艾尔伯试图以提高军费或延后谈判换取空间。
- **转折**：威廉不再谈涨价，而是平静表示可以全面撤回北境驻军；他明确知道斯托克顿的自建武装还守不住整条边境。
- **高潮**：艾尔伯在领民死伤、旅游信誉崩塌、失地与夺爵的具体风险下无路可退；威廉这才提出卢卡斯必须与莉莉安结婚，艾尔伯签下婚约。
- **结尾**：艾尔伯回到宅邸，面对安娜留下的金丝天花板和萨拉的安静照料，承认自己与父亲的两代选择造成了今日困境。他原想立刻叫醒卢卡斯，却想到儿子近来承担领地绝大多数财务、领民事务和物流调度，常在书桌前握笔睡着，最终决定让他多睡一晚。萨拉随后前往花园书屋，为伏案熟睡的卢卡斯盖上毯子、抽走手中的笔；她走出木屋仰望星空，为教国中少见的好领主一家落到这种处境而惋惜。

## 情节安排（多线）

- **主线推进**：完成婚约的斯托克顿一侧成因，让第 005 章中“男爵已签婚约”获得完整历史逻辑。
- **辅线推进**：展示卢卡斯经济改革的成果与副作用；事业越成功，越使福克斯家感到必须尽快下手。
- **事件线 / 任务线**：艾尔伯需要在不触发全面撤军的前提下拒绝婚约；他尝试用金钱、时间与过渡安排谈判，但威廉不接受可让斯托克顿继续成长的方案。
- **任务卡点**：“加价或分阶段接防”的协商被威廉拒绝，功能是信息揭示与选择压力：证明威廉的目标已不是更高佣金，而是阻止斯托克顿独立。
- **感情线 / 关系线**：无显性爱情线；艾尔伯与卢卡斯从彼此信任的父子，进入“父亲为保护领地擅自决定儿子婚姻”的潜在严重裂痕。卢卡斯尚不知情，艾尔伯出于心疼与愧疚把告知推迟到天亮以后。
- **逻辑线**：五十年驻军依赖 → 旅游改革创造脱钩可能 → 威廉判断控制窗口即将关闭 → 用全面撤军逼迫婚约 → 婚约成为后续暗杀嫁祸的入口。

## 人物关系和出场顺序

- **出场顺序**：艾尔伯 → 威廉 → 福克斯驻军/哨塔（集体功能位）→ 旅游侍从与保镖（背景）→ 萨拉 → 卢卡斯。
- **艾尔伯↔威廉**：表面的接待主人与贵客/长期合作者 → 明确的勒索者与被勒索者。
- **艾尔伯↔卢卡斯**：互相信任、共同改革领地 → 艾尔伯已越过儿子签下婚约，却因看见他的过劳而不忍当夜叫醒；裂痕已经形成，卢卡斯仍毫不知情。
- **艾尔伯↔萨拉**：主仆与日常信任 → 萨拉看出男爵带回了沉重麻烦，却不作万能劝解，只接下夜间照料；她对这家人的惋惜来自长期观察，不来自全知阴谋。
- **视角/信息差**：艾尔伯知道驻军依赖与婚约要求，只知道莉莉安是凯恩家想处理的麻烦平民，不知道学院陷害和福克斯家的暗杀嫁祸全貌；威廉知道家族吞并目标，但对塞西莉亚在学院的全部细节知情程度待定；读者根据前一幕已知莉莉安将成为婚约对象，比艾尔伯更清楚她正在承受什么；卢卡斯直到章末仍不知道父亲已经签约。

## 代价兑现 / 收益兑现

- **艾尔伯的收益**：福克斯驻军暂不全面撤离，斯托克领获得继续建立自主边防的缓冲时间。
- **艾尔伯的代价**：他越过卢卡斯本人做出婚姻决定，并把一位完全不知情的女孩卷入家族危机。
- **威廉的收益**：婚约入口成立，塞西莉亚可继续把莉莉安送入斯托克顿家的陷阱。
- **威廉的后续账**：他过早暴露了对斯托克顿自建武装的关注，也让艾尔伯彻底确认“继续依赖福克斯家等于慢性失去领地”。

## 结尾设定和钩子

- **结尾状态**：婚约已由艾尔伯签署；驻军危机被暂时掩住，却未解决；卢卡斯因过劳伏案熟睡，尚不知道父亲替自己答应了婚事；萨拉只看见这家人的疲惫与困境，不知道完整政治阴谋。
- **未解决问题**：艾尔伯将如何向卢卡斯开口；卢卡斯得知父亲违背“不让他政治联姻”的约定后会如何回应；福克斯家为何要为凯恩家一个“稍微有点麻烦的平民”动用驻军筹码。
- **章尾钩子**：信息差与静默情感钩子 — 卢卡斯握笔睡去，尚不知道婚约已经替他签下；萨拉仰望星空，为这家人的命运惋惜。期待度：中强。
- **下一章承接**：下一章需先承接卢卡斯尚未得知婚约这一状态，再以莉莉安抵达、卢卡斯认出她与自己“未来记忆”中关键人物的情感冲击为主，从领主政治转入个人创伤与家庭秩序；具体告知时点在第 007 章细纲中锁定。
