# 细纲（第005章·修订版）

## 第五章：崩毁

- 核心事件：莉莉安被秘密关押后，塞西莉亚与被买通的狱官以“审讯”为名制造饥饿、寒冷、失眠与失序，再用半真半假的信息逐步拆解她对玛琳、师长和自身价值的最后解释。与此同时，玛琳完成交易后退学，带着莉莉安的笔记前往海滨；凯恩家正式免除费尔德家大部分债务、展期余款并出函保障两位姐姐的婚约。正式判决前，茉莉在玛琳原宿舍说明赔偿将于判决生效后通过学院支付；玛琳不留自己去向，只留母亲地址，请茉莉代话让她好好养病、按时吃药。精灵经长老与执行者争论后只恢复最低限度的逃离机会，莉莉安凭自身判断和体力离开学院，用三日返山、在废墟停留一夜，再用两日回到首都。与阿尔维斯生活七年的木屋已经焚毁；她对外始终不透露师傅姓名与经历，也始终无法确认师傅生死。废墟使童年火灾和“都是我的错”的错误归因彻底固化，她进入能行动、能作答却近乎失去自我保护的功能性解离，并主动返回学院自首。学院在她离开后较早确认越狱，为避免“白发魔女逃脱”引发学生恐慌、暴露秘密监狱与看管失败，压制消息并组织小规模秘密搜捕；塞西莉亚认为隔离已足够、主动数日不再探视，又不在学院搜捕知情链中，因此没有察觉。莉莉安第六日主动返回后，学院封存关押与搜捕记录，对外统一为她从未离开。莉莉安在认罪书上承认伤害玛琳，以此将三位师长排除在共犯范围之外。学院正式判处她退学、核定赔偿，并暂扣估价她的财物，赔偿结清前法杖不得领回；师长仅因不合规请假受到轻罚，同时继续申请复核。处罚确定后，塞西莉亚依次拿出财物清单、玛琳母亲的收款地址、斯托克顿男爵已签字的正式婚约和师长们的复核申请，将茉莉无条件代付的安排说成签约才能换来的结果，又夸大拒婚对新晋男爵家的名誉伤害，迫使莉莉安放弃复核并接受与卢卡斯·斯托克顿的婚约。法杖在赔偿到账后归还；莉莉安回湖畔木屋收拾行李时，法杖安静折断。她跪地抱着断杖失控痛哭，门外警务人员不断催促。这场哭泣没有使她好转，只是让麻木彻底失效。首都迎来由秋之精灵带来的第一个秋日时，她仍在急性崩溃中登上前往斯托克顿领的马车，学院篇结束。
- 字数目标：28000—30100字（允许范围26000—31300字）。
- 目标情绪：封闭与失序 → 疼痛后的麻木 → 半真半假带来的认知侵蚀 → 玛琳完成家族责任后的决绝离场 → 越狱时短暂复燃的求生 → 灰烬前最后希望破灭 → 认罪与正式判决 → 私下婚约交易的屈服 → 断杖后麻木破裂、急性崩溃全面外显 → 在崩溃仍未结束时被送往斯托克顿领。
- 章节定位：终幕高潮 / 创伤崩解 / 地图转换 / 强钩子收束。
- 情绪弧线：延迟满足式下坠 + 假胜后崩解。越狱是短暂“假胜”，木屋废墟推动莉莉安主动认罪；正式判决与婚约令她进入麻木，断杖则击穿麻木，让多年没有真正哭过的少女第一次失控痛哭。
- 章首钩子：感官钩子——牢房里的第二份半块面包还在石床靠墙处，送饭口再次打开时，狱官却先收走了水，并问莉莉安是否愿意承认“自愿伤害玛琳”。
- 核心痛点：塞西莉亚不要求莉莉安相信全部谎言，只让她承认足够多的真相：玛琳从一开始带着任务、师长确实因审批受审、阿尔维斯的木屋确实被烧毁。莉莉安越能识破假话，越无法逃开被夹在其中的真实部分。
- 章尾钩子：季节与镜像钩子——秋之精灵从原初之地抵达首都，学院树叶染上第一层金红。莉莉安因力竭而暂时失声，但哭泣与呼吸紊乱仍会被敲门、车轮或断杖触感重新触发。她带着断杖被催促登车，白发没有再遮不是坦然，而是已无力维持防备；车夫递来写着“卢卡斯·斯托克顿”的行程单时，她只把纸反复压在断杖上，没能回答。

## 本章五检

1. **交付情绪与可靠模式**：采用“假胜—更深崩解—主动放弃”的悲剧终幕。牢房不是重复施虐，而是通过时间感丧失、信息污染和善意被归因成伤害层层收窄；越狱先恢复一点行动感，再用木屋废墟击碎最后的归处。
2. **核心冲突**：莉莉安仍有求生与判断能力，却越来越相信自己的存在会让善待她的人付出代价；外部目标从“证明清白”退化为“不要再牵连任何人”。塞西莉亚的目标是把她变成愿意签字、不会反抗斯托克顿安排的可控对象。
3. **节奏安排**：牢房感官压迫约16%；第一次心理攻击约13%；玛琳与茉莉线约11%；持续侵蚀约10%；越狱约12%；返山与废墟约14%；自首、认罪和判决约11%；私下婚约约5%；断杖后的全面崩溃与首个秋日离校约8%。在重压之间用玛琳退场和越狱行动切换叙事动力，压缩废墟中重复的“无法确认”，把终幕最重的情绪空间留给断杖与崩溃本身。
4. **伏笔处理**：回收学院秘密监狱、塞西莉亚“退学不是最终目的”、玛琳笔记、精灵边缘帮助、阿尔维斯木屋与婚约、法杖裂纹；推进福克斯家吞并斯托克顿领、玛琳后期回归、精灵内部裂痕、师长审查余波、断杖修复与莉莉安自我认同重建。
5. **章节张弛**：压力级始终较高，但表现形式轮换：身体感官 → 对话攻防 → 配角关系回收 → 行动逃亡 → 静态废墟 → 制度交易 → 物件崩断。伤害场景不以数量升级，不新增超出总纲的酷刑项目。

## 连续性口径

- 直接承接第四章结尾：莉莉安被扣法杖、关进没有公开登记的秘密监狱；她将面包分成两份，仍反复用“玛琳一定是被逼的”维持认知。
- 莉莉安当前已经能推导伤痕与证词经过策划，但拒绝把玛琳放进主动行为的主语。本章的心理崩解必须从这一状态继续，不能开场就接受“玛琳一直在骗她”。
- 莉莉安隐约察觉师傅身份不寻常，也认为他选择隐居是为了不再与外界产生过多联系。她可以在内心叙事中想起“阿尔维斯”，但不向看守、学院、塞西莉亚或其他外人透露师傅的姓名、身份、过往、研究、具体外貌及师徒生活细节；她在牢中也不会用这些信息换取帮助。
- 塞西莉亚的高明之处是“真相夹谎言”。她说出的可核事实必须来自第四章材料、玛琳/茉莉提供的信息、学院记录或她亲自参与的安排；不能凭空知道莉莉安与阿尔维斯之间未被外人见过的私密细节。
- 肉体折磨保持非猎奇尺度：通过水被收走、饭量变化、寒冷、睡眠打断、伤后动作与时间感崩坏表现。不得详细展示施虐步骤，也不得让伤势严重到与后续长途逃亡失去逻辑。
- 莉莉安仍是受过阿尔维斯多年野外与实战训练的魔法师。她可以虚弱、迟钝、心理崩溃，但越狱时必须会观察门锁、巡逻、路线和体力，不可像毫无能力的普通学生被精灵“搬出去”。
- 精灵只能让机会发生：令锁舌未完全闭合、辉石灯短暂熄灭、空气或小动物制造错误方向、巡逻者恰好离开。推门、避人、选择路线、离城与返山均由莉莉安完成并承担代价。
- 法杖在第四章已被束魔布包裹暂扣。越狱时莉莉安不能随身带法杖；法杖应在她自首并签署退学文书后，由学院返还或放回湖畔木屋，随后才发生断裂。
- 玛琳的退学与离开应发生在莉莉安关押期间。她保留莉莉安的笔记属于未经允许带走，但承担“证明友情并非全假”的情感功能；不能写成莉莉安主动赠送或提前原谅。
- 木屋被焚的真相不在本章及近期剧情揭晓。读者严格跟随莉莉安认知，只知道阿尔维斯生死不明；“师傅是否存活”与“师傅在教廷做什么”作为两条相连的长线伏笔，很久以后共同揭晓。
- 学院篇从春季持续到夏末秋初。莉莉安启程前往斯托克顿领当天，秋之精灵从中心原初之地向外围行进并抵达首都，所到之处季节切换；当天是首都当年的第一个秋日。
- 学院正式程序为：莉莉安签署认罪书，学院判定她伤害玛琳，作出处罚性退学与赔偿裁决。婚约不写入判决，也不是学院安排的离校去处；那是处罚确定后塞西莉亚私下向莉莉安提出的另一项交易。
- 赔偿金的时序固定为：正式判决前，茉莉在玛琳原宿舍承诺待裁决生效后由学院方转付，并要求留地址；玛琳只留母亲地址和“好好养病、按时吃药”的口信；判决后学院再完成转付。原宿舍不出现现金、钱袋或玛琳当日汇款。
- 六日时序锁定为：越狱当夜启程，三日返山，在木屋废墟停留一夜，两日返回首都。去程可借短程货车、以野外经验取水和觅食；回程因明确目标而缩短，但必须兑现脚伤、脱水与发热。学院较早确认牢房无人，因恐慌、秘密监狱暴露与看管失败三重风险，只组织人数有限、不能公开通缉的秘密搜捕。塞西莉亚此前主动留下数日隔离期，不要求每日汇报，也不在搜捕知情链中，因此没有察觉。莉莉安自首后，学院封存关押与搜捕记录并统一对外口径。
- 茉莉代付赔偿是无条件决定，与婚约无因果关系；读者知道，莉莉安不知道。塞西莉亚只能利用这项信息差，不能真正控制或撤销茉莉的付款。
- 赔偿结清前，学院暂扣并估价莉莉安现有财物，法杖列在清单中；茉莉向学院付款、学院转付玛琳母亲后，法杖才具备返还条件。
- 三位师长在轻罚落定后继续为莉莉安申请复核。莉莉安另签放弃复核声明，并以“自愿结婚、离校过安稳生活”为理由切断师长的营救；婚约不交换师长免罚，也不涉及教会司法移送。
- 学院隐瞒莉莉安越狱事实，以免“白发魔女逃脱”引发学生与家长恐慌，并避免外界得知秘密监狱及看管不力。认罪书明确把行动责任归于莉莉安个人，三位师长除不合规批准请假外缺乏其他罪证，最终只受较轻的失职处罚。
- 第五章结束时莉莉安并非“完全没有人格”，但必须处于明显的急性崩溃中。她保护师长、担心斯托克顿家被牵连、保存断杖，是在崩溃中残留的习惯、道德本能与依恋，不是她已经完成情绪宣泄或开始自愈。

## 内容概括（五段式）

- 起因：秘密监狱开始以不留公开记录的方式“审讯”莉莉安。狱官发现肉体和感官折磨无法直接让她认罪，塞西莉亚转而利用玛琳任务、师长审查与她童年“带来厄运”的自我认知。
- 发展：塞西莉亚多次提供半真半假的信息，使莉莉安从“玛琳受胁迫”退到“即便被迫，接近我的起点也带有任务”，再退到“所有帮助我的人都因我受罚”。同期凯恩家正式免除费尔德家大部分债务、展期余款并保障两位姐姐的婚约。茉莉在玛琳原宿舍承诺判决生效后由学院转付赔偿，玛琳只留下母亲的地址与养病口信。她确认债务、姐姐婚约和母亲后续医药都有安排后，认定自己已为家族尽到全部责任，主动离开。
- 转折：精灵在规则允许的边缘制造越狱窗口。莉莉安依靠自身训练逃出学院，并将阿尔维斯的深山木屋当作唯一归处；抵达后发现木屋已焚毁，越狱带来的行动希望被彻底击碎。
- 高潮：莉莉安把木屋毁灭与玛琳、师长、过去养家受难连成同一套“我会带来灾祸”的解释，主动返回学院。此前已经秘密搜捕的学院立即封存相关记录并维持“她从未离开”的公开版本；她签署认罪书承认罪行，把师长从共犯或知情嫌疑中摘出。学院正式判处退学与赔偿，师长只受轻罚。此后塞西莉亚私下提出婚约交易，莉莉安另行接受。
- 结尾：学院归还法杖，莉莉安回湖畔木屋收拾行李。她触碰法杖时，长期透支与失去魔力连接的古木安静折断。多年没有真正哭过的她抱着断杖跪地失控痛哭，门外警务人员仍在催促。哭泣不带来情绪收束，反而让她失去继续维持麻木的能力。首都迎来第一个秋日，她在呼吸紊乱、反应断续与机械服从中保存断杖、被催促登车，崩溃状态直接带入斯托克顿篇。

## 情节安排（多线）

- 主线推进：秘密关押 → 认知崩解 → 精灵创造越狱窗口 → 返回阿尔维斯木屋 → 发现废墟 → 自首 → 学院隐瞒越狱 → 签署认罪书 → 正式判处退学与赔偿 → 私下接受婚约 → 断杖痛哭 → 首个秋日离校。
- 莉莉安人物线：从拒绝命名背叛，退到承认接近起点带有任务；从仍想找师傅求助，退到确信自己会伤害所有亲近者；最后以保护师长为理由放弃自救，但仍保留担心斯托克顿家的道德本能。
- 玛琳线：凯恩家免除大部分债务、展期余款并出函保障两位姐姐婚约。茉莉在原宿舍告知她：赔偿金须等学院正式判决生效后由学院转付，请她留下地址。玛琳只留母亲的地址，并请茉莉代她告诉母亲好好养病、按时吃药。她认定自己已为家族做完能做的一切、不再欠家族，带着莉莉安笔记离开学院，以平民身份前往海滨。她没有赎罪，也没有得到原谅。
- 茉莉线：收到父亲出具的正式减债、展期与促婚书信，把后续处置权交给塞西莉亚；她说“不要太过分”，却没有设置监督或停止条件。她只能在判决前承诺自己将向学院缴付赔偿金，由学院在判决后按玛琳留下的母亲地址转付；这仍是试图用金钱弥补，不会推翻她的陷害责任。
- 塞西莉亚线：从执行凯恩家压制升级为推进福克斯家利益。她通过书信确认兄长已向斯托克顿男爵施压，但正文只揭示“婚约是预先准备的政治安排”，不提前详述全部暗杀步骤，完整吞并计划留给斯托克顿篇展开。
- 师长线：奥莉维娅、阿尔瓦与艾尔文被限制接触莉莉安；审查确实存在，但学院找不到他们参与或间接知晓虐待的证据。莉莉安在认罪书中独自承担罪行后，三人只因不合规请假被定为失职并受较轻处罚。
- 精灵线：菲莱尔与亲近精灵要求行动，受长老授权的执行者把争议带回长老判断；长老最终只批准恢复最低限度的逃离机会。这不是对第四章“不作为”的补偿，而是对“如何在不替莉莉安作决定的前提下终止既有处置造成的极端后果”的个案修正。精灵不直接现身替莉莉安决定去向。
- 阿尔维斯线：莉莉安见到毁坏的木屋，始终无法确认阿尔维斯生死；读者与她拥有完全相同的信息。“师傅生死不明”与“师傅在教廷所做之事”作为长期双伏笔并行，真相很久以后才揭晓。

## 关键场景写作指令

### 秘密监狱与伤害尺度

- 不罗列酷刑，不写可复制的施虐流程。重点写水、光、温度、睡眠、送饭时间与身体后果如何剥夺秩序感。
- 莉莉安承受能力来自童年与阿尔维斯训练，不把“能忍”写成伤害无效；她身体会虚弱，动作会受限，后续逃亡必须兑现代价。
- 狱官不抢反派戏份。通过删记录、避治疗者、服从塞西莉亚和关心晋升表现腐败，不安排长篇身世独白。
- 塞西莉亚发现心理攻击更有效后减少身体伤害，符合“把莉莉安送往斯托克顿领继续利用”的目标。

### 半真半假心理折磨

- 每轮必须包含：一项可核真相 + 一项莉莉安能识破的假细节 + 一个无法靠识破假话逃开的结论。
- 莉莉安不是被几句话“说傻”。她越能找出谎言，越被迫正视真相夹层，认知崩解来自长期隔离、信息缺口与旧创伤共同作用。
- 不用塞西莉亚直接说“你是灾星”作为主要攻击。让她持续提供“某人因你受审/失去选择”的具体材料，由莉莉安自己接回童年认知。
- 塞西莉亚不暴露完整吞并与暗杀方案。她只需要让婚约成立；下卷再通过福克斯子爵与斯托克顿家的冲突揭示更大目的。

### 玛琳退场

- 玛琳的“我配后悔吗”不能写成自我感动。她承认家族压力，也承认实际行动属于自己；不寻求茉莉或叙述者判她无罪。
- 笔记是她未经莉莉安允许带走的情感证物，兼具珍惜与占有的复杂性。后期归还或重逢时再处理其伦理代价。
- 茉莉不能因难受转为暗中救援。她可以核对债务、发现承诺缩水，却仍没有撤回对塞西莉亚的授权。

### 精灵与越狱

- 精灵只改环境概率，不替莉莉安开完所有门、规划路线或屏蔽所有追兵。
- 莉莉安必须先识别诱捕风险、观察巡逻、测试警报，再决定逃跑；这是她仍有行动主体性的关键段。
- 越狱后的目标要单一明确：私下找师傅。她不对外说姓名，也不留下可供追查的路线与身份线索。不能在途中插入无关冲突或新角色支线。
- 返山距离锁定为去程三日、废墟一夜、回程两日。用短程货车、日出日落、换水和鞋损作客观锚点；学院在莉莉安离开后较早确认越狱，只组织小规模秘密搜捕，不公开通缉；她自首后学院封存六日记录，对外维持“从未离开”的统一口径。

### 木屋废墟

- 先让莉莉安专业检查，再让情绪压过判断。没有尸体、火场过于彻底、物品被集中焚烧都应作为日后可回看的异常。
- 本章不确认阿尔维斯死亡，也不让莉莉安找到明确死亡物证。她的误判来自关押造成的耗损、旧创伤与废墟本身，而非看守提前透露信息或作者替她宣布真相。
- 不使用全知旁白揭示“主教清除痕迹”，也不向读者提供超出莉莉安认知的暗示性答案。师傅生死与教廷行动保持长期双悬念，很久以后才揭晓。
- 情绪主要落在修补陶碗、椅腿、批注残页、制杖木屑盒等具体物件，不用长篇抽象哭诉。

### 认罪、正式判决与婚约交易

- 学院必须完成正式程序：认罪书、处罚性退学、赔偿裁决和内部罪名记录。越狱事实因学院看管不力被隐瞒，不进入公开结论。
- 莉莉安在认罪书中把罪行归于个人，以此开脱师长。三位师长只因请假不合规受较轻失职处罚；不能再写成婚约直接换取他们免罚。
- 婚约在正式判决后由塞西莉亚私下提出，与学院无关，也不改变莉莉安已被判退学的事实。学院不关心退学生去处。
- 婚约胁迫固定使用四项具体材料：暂扣财物清单、玛琳母亲收款地址、斯托克顿男爵已签署的正式婚约、三位师长的复核申请。完全删除“移送教会司法”方案。
- 塞西莉亚把茉莉无条件代付造成的后续结果窃取为婚约的交换收益；她说“拒绝会毁掉斯托克顿家”是夸大恐吓，真实代价只是让处境艰难的新晋男爵家蒙羞。
- 莉莉安通过放弃复核声明与“自愿结婚、离校生活”的说辞切断师长营救。婚约不换取师长免罚，不改变学院判决。
- 莉莉安至少问三件事：师长、玛琳、斯托克顿家。认罪和婚约是两次不同签字、两层不同代价。
- 卢卡斯本章不出场；婚约文件仅作为强制关系与换地图钩子。

### 玛琳家族结算与赔偿

- 凯恩家交易必须明确兑现：大部分债务免除、剩余债务展期、出具书信促成并保障两位姐姐婚约。
- 正式判决前，茉莉在玛琳原宿舍只说明赔偿流程并请她留收款地址；现场不交钱。玛琳只留母亲地址，请茉莉代为转告“好好养病，按时吃药”。
- 正式判决生效后，茉莉将赔偿款缴给学院，学院按留存地址转付给玛琳母亲。塞西莉亚对此不悦，但不阻止茉莉在不推翻陷害前提下作出的补偿。
- 玛琳离开前确认家族债务、姐姐婚约和母亲后续医药均有安排，因此认定自己已尽到全部家族责任、不再欠家族，主动离开。这只是她对家族债的结算，不是对莉莉安责任的结案。
- 这不是玛琳获得自由的奖励，而是她以不可逆伤害换来的断裂式结算。

### 法杖与离校

- 断杖原因必须同时满足物理与魔法规则：第三章既有裂纹 + 长期使用与拘束期间失去魔力维系 + 莉莉安精神连接溃散。不能只写“因为心碎所以断”。
- 断裂动作越小越好，不用爆炸、魔力风暴或群体围观；情绪爆发来自断裂之后。
- 莉莉安必须在断杖后跪地痛哭。这是她多年第一次真正失控哭出声，不是“终于允许自己脆弱”的健康释放，而是麻木防线崩溃；门外警务人员的催促与她的失控形成直接对照。
- 莉莉安保存断杖时仍在崩溃中，动作来自多年习惯与依恋残留；它只为后续重建留下物理入口，不代表她在本章已经开始修复。
- 离校路线只回照关键空间，不总结“学院的意义”。首都第一个秋日、哭肿的眼睛、白发不再遮、无人送行、纸压断杖完成收束；其中白发不再遮是无力维持防备，不是身份接纳。

## 代价兑现 / 收益反转

- 莉莉安的力量收益：第三章证明她具备强大实战能力；第五章兑现制度代价——无杖、秘密关押和社会叙事让战力不能直接解决问题。
- 莉莉安的关系收益：第二、三章得到玛琳与三位师长的善意；第五章被塞西莉亚改写成“所有善待者都因她受罚”。
- 精灵的保护逻辑：第四章因菲莱尔试图杀死玛琳而立即制止并限制接触；第五章长老承认这项处置已造成莉莉安完全失去精灵求援渠道的后果，因此批准最低限度恢复选择。争议来自边界解释与责任承担，不写成“冷血老精灵阻止善良精灵救人”。
- 玛琳的交易收益：费尔德家大部分债务被免除，余款展期，两位姐姐婚约获凯恩家书信保障；代价是她失去学院生活与唯一真实友情。她在离校前将未来赔偿款的收款地址指向母亲医药，由此主动切断“还欠家族”的义务认知；赔偿实际转付发生在判决生效后。
- 茉莉的服从收益：完成父亲命令；代价是实际处置权落到塞西莉亚与福克斯家手中，她成为升级计划的默许者。
- 塞西莉亚的程序收益：学院正式判处莉莉安退学后，她又私下完成婚约入口；延迟代价是秘密关押、越狱隐瞒、狱官收买、锁环物证和私人婚约承诺留下可追查痕迹。
- 阿尔维斯的入学交易：他以返回教廷换来莉莉安的机会；反转为她在学院受难时无人能联系他，木屋毁灭又让她长期无法确认他的生死。
- 法杖的长期收益：多年承载师徒关系、施法能力与身份自信；第五章以安静折断兑现长期裂纹和精神脱离，保存断杖则留下未来重建可能。

## 结尾状态与下一卷承接

- 莉莉安：签署认罪书，被学院正式判处退学与赔偿；另与塞西莉亚私下签署婚约。断杖后多年第一次跪地失控痛哭，哭泣没有带来好转，而是使麻木失效。她携带断杖于首都第一个秋日前往斯托克顿领；处于明显的急性崩溃与自责中，坚信自己会连累亲近者，但仍残留保护他人、保存旧物和最低事实判断。
- 玛琳：凯恩家已兑现减债、展期和姐姐婚约保障；在原宿舍将母亲地址留作赔偿收款地址，并托茉莉转告母亲好好养病、按时吃药。她认定自己不再欠家族，退学前往海滨，以平民身份生活；带走莉莉安笔记，后悔与责任并存，未获原谅。赔偿款在她离校后、判决生效时再由学院转付给母亲。
- 菲莱尔及亲近精灵：参与争取并执行最低限度的越狱机会，与执行者在边界解释上出现严重裂痕；未能与莉莉安告别。
- 奥莉维娅 / 阿尔瓦 / 艾尔文：因认罪书与证据不足被排除在虐待参与者之外，只为请假不合规受较轻失职处罚；三人未能送行。
- 茉莉：完成凯恩伯爵命令并正式兑现费尔德家条件；在判决前向玛琳说明学院转付流程，判决后再向学院缴付款项。塞西莉亚虽不悦仍不阻止；这项补偿没有推翻她的加害责任。
- 塞西莉亚：利用学院正式处罚后的空白，私下完成婚约入口，把莉莉安交给福克斯—斯托克顿政治安排；收买狱官、越狱隐瞒与私人交易成为后续风险。
- 阿尔维斯：在莉莉安和读者认知中均生死不明；木屋真相与他在教廷所做之事保持长期双伏笔，直至很久以后揭晓。
- 卢卡斯 / 斯托克顿家：已在福克斯家施压下接受婚约，等待莉莉安抵达；下一卷先从男爵与福克斯子爵的政治压力、再到莉莉安与卢卡斯相见展开。
- 下一阶段首要问题：一个确信自己只会带来灾祸的人，抵达同样被政治结构逼迫的斯托克顿家后，是否还能辨认不以交易为条件的善意。
