## 细纲（第 011 章）

### 第 011 章：希望你会喜欢

- **篇内编号**：斯托克顿篇·第 6 章。
- **章节名**：《希望你会喜欢》。
- **固定开头文字**：“我对料理不算自信，但仍愿这香气，能让你想起家乡。”
- **未来框架**：开头文字由日后的莉莉安说出。那时她与卢卡斯已经远离斯托克顿，身上的重担使两人无法轻易返乡；她仍会抽出时间做自己最拿手的鸡肉炖根菜，希望让卢卡斯想起在宅邸度过的安稳日子。章节名则属于日后卢卡斯的回望，并与后续章节名组成“希望你会喜欢，这不完美的宴会，这不完美的人生”。正文当下不得提前解释这层未来含义。
- **承接关系**：第010章三日公开走访结束后约十余日。莉莉安已继续在宅邸工作一段时间，南镇事故造成的精神疲劳基本恢复；她仍佩戴静澜花香囊，新衣已入柜，带铜灯木船与两截断杖仍在未扣锁的旧木箱中。卢卡斯已向她坦白未来记忆，两人不再回避湖上谈话，但也没有立刻继续追问学院、坏结局或彼此感情。
- **时间跨度**：正文现在时约三日；以工资记录、短杖到货和此前两次练习的短回忆，压缩公开走访后约十余日的生活间隔。第一日处理领务、流言、教堂边界与控物练习，第二日开始宴会食材入宅并完成第一次试菜，第三日由莉莉安试做鸡肉炖根菜收束。章末距离感恩节仪式仍有数日，宴会只进入采购、登记、试菜和人手安排阶段，不正式开场。
- **核心事件**：秋收、税金与冬储核算接近收尾，因各地贵族同样忙于领务而少有来客，艾尔伯重新分担日常账目，使长期过劳的卢卡斯第一次得到少量空闲。卢卡斯继续整理走访后分裂扩张的流言，并回想镇级主教对莉莉安和婚约的有限容忍与明确宗教边界；随后在莉莉安指导下第三次练习控物魔法，因石块失控险些砸向自己而接受自己不擅长持续控物。宅邸转入感恩节宴会筹备，莉莉安不再躲避送货人与外来人员，主动向萨拉提出学习料理。卢卡斯偶然路过厨房、好奇品尝她的第一次试菜；得知他最喜欢鸡肉炖根菜后，她在章末再次练习，并主动带着成品去找他。
- **字数目标**：约15000字，细化预算16500字，允许范围15000—16500字。
- **目标情绪**：在深秋生活逐渐安稳的表面下，让读者同时感到“她正在被纳入这个家的普通日子”与“外部世界仍为她划着界线”。关系温度来自父子共同记账、短杖的分期付款、一次被及时接住的失控、厨房里的真实批评和一份以后还想学的家常菜；阴影来自流言分层、教堂拒绝与即将扩大人员流动的宴会供应。
- **章节定位**：低压生活章 + 关系回收章 + 修炼试错章 + 信息整理章。外部压力1—2级，魔法失控动作烈度2级，厨房关系烈度3级；本章不发生投毒、袭击或宴会现场冲突。
- **主视角**：全章以卢卡斯第三人称限知为主。该视角服务三项不可替代功能：呈现艾尔伯分担领务后他的时间变化；整理外部流言和教堂立场；表现他如何理解自己的地球记忆、魔法短板以及莉莉安在宅邸中的细小变化。不得切入莉莉安内心替她宣布已经信任或把宅邸视为家。
- **文风锚点**：主锚点008-A、008-B，召回厨房、工作安排和家人式正式对白；辅助锚点003-A，保证石块离地、偏移、加速和莉莉安接管时的空间与受力清楚。关系靠近只借008-C“共同做一件小事、把变化留在下一次选择”的方法，不复制山坡、夕阳、烤饼和落叶。
- **章首钩子**：固定未来回望文字之后，用生活反差弱钩子切回当下——艾尔伯主动抽走一叠本应由卢卡斯处理的账册，表演“全年最忙阶段终于松开一点”，不要从纯季节景色或背景说明开场。
- **显性爽点**：无高强度爽点。本章收益是三次低压兑现：艾尔伯实际分担儿子的工作；莉莉安能够制止卢卡斯继续危险练习而不担心关系破裂；她说出“我也想学料理”并为自己记下一道以后想做的菜。
- **核心期待**：感恩节宴会将把教堂、领主家、各家菜肴、临时帮工与外来供应同时聚到一个公开场合。读者看见正常而温暖的筹备秩序，也能意识到这套秩序即将承受尚未显形的外部侵入。
- **章尾钩子**：日常意象／关系兑现钩子，期待度中弱——莉莉安在萨拉教导下做出一小锅鸡肉炖根菜，主动端去花园书房请卢卡斯品尝。卢卡斯给出比第一次更高的评价，在她反复确认后仍诚实承认比萨拉做的差一点；她接受这个答案，也把下一次改进留到以后。感恩节还有数日，厨房外的宴会食材与人手安排仍未完成。

## 大纲五检

1. **情绪与模式**：本章交付“被排斥的边界仍在，但普通生活已经开始给她留下位置”。采用父子分担—流言分层—制度边界—共同试错—厨房学习的低压关系模式，不用突发救援或口头家庭宣言制造温暖。
2. **核心冲突**：莉莉安仍习惯用劳动解释自己为何能留下，外部社会也仍以魔力、血统和政治价值解释她；萨拉只有在她承认“自己想学”后才接纳她进入料理准备，卢卡斯则在无法靠魔法证明能力时接受自身局限。两人的关系都从“必须有用”向“可以有普通偏好和短板”移动一小步。
3. **节奏**：书房与流言为中速信息推进；教堂立场短暂降温；院中练习形成唯一动作峰值；供应入宅与厨房教学逐步回暖；试菜和最喜欢的菜承担情感峰值并以弱钩子收束。外部危机保持潜伏，不抢跑投毒。
4. **伏笔**：推进V26流言路线和四类公众解释；建立感恩节期间的供应、临时帮工、钥匙和接触顺序；建立镇级主教的宗教边界；新增制式短杖长期物件及工资分期；为艾尔伯中毒时卢卡斯使用轻度治疗、萨拉拆解厨房证据链、莉莉安被指拥有接触机会预留条件，但本章不写异常。
5. **章节定位与承接**：010完成秘密交换，011主动降压并把关系落回生活；本章没有高压爽点，但控物失败、教堂排斥与厨房接纳形成情绪折线。章末由“以后想学”推进到莉莉安真正做出鸡肉炖根菜并主动送去，关系获得一次小兑现；尚未拆完的宴会食材继续提供012的阶段目标。

## 内容概括（五段式）

- **起因**：公开走访后约十余日，秋收、税账和冬储核算接近结束。各地贵族忙于自己的领务，没有多少客人来到斯托克顿，艾尔伯将一部分账册从卢卡斯桌上拿走，父子重新分担工作。卢卡斯因此得到近来少有的一段空闲，也看到感恩节仪式与两日宴会已经进入正式筹备。
- **发展**：父子在税账、冬储和流言记录间核对近期领地状态。流言已经从四个固定核心分裂为危险、八卦、功利理性和直接见证四类解释；卢卡斯继续追踪最容易被引导的多数说法。教堂日程使他回想此前向镇级主教询问的结果，并把莉莉安不得进入教堂、但可在仪式后参加宴会的现实边界告诉她。艾尔伯不挑战宗教仪式，却确认领主家的宴会位置不会因此取消。
- **转折**：空闲日下午，卢卡斯进行第三次控物练习。莉莉安使用新制式短杖示范，短杖不趁手但足以保证安全；卢卡斯让石块离地后无法稳定移动，石块突然偏向自己，被莉莉安及时接管。他接受自己不擅长持续控物，停止练习。工资小本上的短杖分期扣款和莉莉安明确叫停他的动作，使这场失败不落成羞辱，而成为两人可以争执、制止和接受边界的一次普通经历。
- **高潮**：宴会食材开始送入宅邸。莉莉安没有再回避送货人，留在萨拉身边清点；卢卡斯对外说明她正在学习贵族礼仪和宅邸运作。面对萨拉一年中最繁忙的采购和备菜，莉莉安主动提出帮助。萨拉先拒绝，直到她说自己也想学习料理，才把她纳入正常工时内的教学。她完成第一小锅根菜炖汤，萨拉给出真实纠正；卢卡斯偶然路过厨房，闻到香气后主动试吃，莉莉安由此问出他最喜欢的菜。
- **结尾**：莉莉安在后续一次学习中按萨拉教导做出鸡肉炖根菜，主动端去花园书房找卢卡斯。卢卡斯给出的评价比第一次明显更好，却在她几次确认后承认仍比萨拉做得差一些。莉莉安没有放弃或道歉，只留下需要继续改的地方。厨房外仍有食材等待登记，感恩节还有数日，宴会尚未开始。

## 情节安排（多线）

- **主线推进**：秋收领务转入收尾，感恩节与斯托克顿两日宴会进入筹备；本章建立仪式、供应、人手与厨房流程，为012公共场合和后续投毒提供公平前置。
- **家庭线**：艾尔伯从主要对外陪客暂时回到父子共同领务；他正常采用莉莉安誊写的公开材料，并确认教堂不能替领主家取消她在宴会中的位置，形成不涉及学院审问的有限信任。
- **关系线**：卢卡斯与莉莉安从010的秘密坦白转入普通相处。她能制止他继续练习，他能接受失败；她询问其饮食偏好，他不以未来记忆、婚约或宏大承诺回答，只交出一个家庭日常中的真实喜好。章末她又将这个答案变成一次主动寻找与分享，不要求卢卡斯用虚假的满分评价回报。
- **修炼线**：锁定卢卡斯“基础瞬时魔法可用、持续控物很差、轻度治疗相对熟练”的能力结构；本章以失败试错完成能力边界，不制造突破。
- **流言线**：固定污名经南镇事故和湖上晚归分裂成四类社会解释。直接见证能纠正细节，却不能替莉莉安担保一生；多数理性派成为后续从接受转向担忧领地损失的主要摇摆人群。
- **教会线**：镇级主教不支持、不背书、不准入教堂，却也不公开反婚约或要求驱逐。教会保持地方共治力量的现实分量，并为012蒂莉在教会学校接触传说、莉莉安被排除于仪式之外作准备。
- **阴谋暗线**：执行人不出场、不新增全知视角。只让读者看见宴会会引入更多供应、临时帮工和人员空档；所有流程此时正常，异常留待后续章发生。
- **事件线／任务线**：艾尔伯分担账目 → 父子核对税账、冬储与流言 → 感恩节日程触发教堂回忆 → 向莉莉安说明仪式边界 → 第三次控物练习与险情 → 宴会食材入宅 → 莉莉安面对外人不再躲避 → 萨拉安排采购和人手 → 莉莉安提出学料理 → 第一次根菜汤与卢卡斯偶然试吃 → 问出最喜欢的菜 → 学做鸡肉炖根菜 → 主动端去花园书房请卢卡斯第二次品尝。
- **任务卡点一**：卢卡斯想学习简单实用的控物魔法，卡在低储量、低持续输出和抽象想象不稳；卡点服务能力边界、关系制止与“允许自己不擅长”的人物变化。删掉后会失去短杖安全功能和二人湖上坦白后的第一场普通互动。
- **任务卡点二**：莉莉安想帮助宴会筹备，萨拉拒绝她继续用额外劳动证明价值；她说出“自己也想学”后，任务从加班改成正常工时内的生活学习。卡点服务核心错误信念松动和厨房关系变化，不能写成萨拉故意刁难。
- **逻辑线**：秋收收尾、来客减少 → 艾尔伯分担领务 → 卢卡斯有空练习并整理流言 → 感恩节把教堂与领主家的不同边界推到眼前 → 控物失败使两人以普通人的短板相处 → 宴会筹备让莉莉安面对外人并进入厨房 → 她第一次以个人愿望而非偿还逻辑学习料理 → 偶然试吃问出偏好 → 她主动把偏好变成第二次练习和一次分享 → 下一章公共节日拥有关系与阴谋两重载荷。

## 人物关系和出场顺序

- **出场顺序**：卢卡斯 → 艾尔伯 → 莉莉安 → 加文·里德（汇报或递交镇上记录）／送货人口头来源 → 镇级主教（短回忆） → 萨拉 → 宴会食材送货人／商贩 → 蒂莉（按教会学校课程表选择在傍晚出现，不占用上课时段）→ 后续将受雇的镇上妇人仅在名单中出现，不提前具名。
- **卢卡斯—艾尔伯**：从“父亲主要对外、儿子独自承担日常领务”恢复为阶段性共同记账；艾尔伯分担工作不是一次性施舍，而是来客减少后的正常领主职责回归。
- **艾尔伯—莉莉安**：从保留观察推进到在普通领务中采用她誊写的公开材料，并在教堂边界问题上确认她仍有参加领主宴会的位置；不称女儿、不撤销警惕、不追问学院。
- **卢卡斯—莉莉安**：从共享核心秘密推进到能够共同承受一次失败和真实评价。莉莉安叫停练习、卢卡斯服从；她主动问最喜欢的菜，他给出普通私人答案。她仍称“您”，两人尚未表白。
- **萨拉—莉莉安**：从女仆长与新雇员推进到生活技能的教导者；萨拉接受的是她的学习愿望，不是无限增加的劳动量。批评切块、火候和盐味时保持真实工作标准。
- **莉莉安—外来人员**：从009前主动避客推进到能够在被注视时继续清点食材；外人态度不统一，她也不主动解释学院经历。
- **卢卡斯—镇级主教**：地方领主继承人与共治宗教领袖之间保持礼貌而清楚的边界。卢卡斯知道对方不会替莉莉安背书，也不把“不公开反对”误认成支持。
- **视角／信息差**：卢卡斯不知道流言执行人的身份，也不知道宴会将成为投毒现场；莉莉安不知道福克斯完整吞并计划、坏结局规则与卢卡斯不配得感；镇级主教只知道公开婚约、学院判决与白发身份，不知道莉莉安无罪及未来记忆；读者只从幕级铺垫意识到供应流程重要，正文不出现反派视角确认。

## 情节细化与字数预算

1. 具体开头文字留空。开场场景从花园书房或主宅书房的账册开始：卢卡斯伸手去取下一叠冬储汇总，艾尔伯先将其抽到自己面前，说明近期没有贵族来访，税账与冬储由自己分担。用纸张位置和父子自然分工表演工作量变化，不先总结“卢卡斯终于闲下来”【生活反差／父子关系·密700】。
2. 父子核对秋收接近尾声后的领务：村镇粮仓、冬储缺口、年度地方税与教国税分开，东村轮轴和北村主梁复查仍按010安排推进。莉莉安送入或交回一份公开表格的誊本，艾尔伯只核对数字、在旁边落笔继续使用，不展开审问【领务推进／有限信任·密850】。
3. 艾尔伯指出各地领主都在忙自己的秋收、税账和冬储，近期狩猎与宴饮客人稀少；卢卡斯原本因旅游客减少担忧收入，随后确认这是正常季节波动。感恩节后的两日宴会采购单进入书房，正式建立本章阶段目标【时间缝合／节日引入·密900】。
4. 加文送来镇上巡逻中的几条代表性说法，或卢卡斯从市场、送货人口中补齐记录。先呈现老人危险派：他们记得或听父辈讲过教国征服，把南仓值守魔法使的专业评价转成“学院也解释不了她为何这么强”，进而怀疑婚约目的【流言分层一／历史恐惧·密850】。
5. 八卦派把北湖独处和晚归三刻钟编成亲热；多数理性派则接受婚约，却猜测莉莉安是大贵族私生女、政治交换或改善后代魔力的安排。卢卡斯对前者无奈，对后者逐句记录，因为这一派人数最多，也最容易从“合理婚约”被引到“男爵家被控制”【流言分层二／调查推进·密900】。

9. 账目中出现制式短杖本周扣款，引出短回忆：南镇事故后卢卡斯托正常商路从伯爵领城市购入普通现代短杖；莉莉安坚持付款，最后按周从工资中扣一小部分。写清它便宜、易上手却不趁手，是安全工具而非断杖替代品【物件引入／费用折中·密900】。

## 代价兑现／收益兑现

- **卢卡斯的代价**：承认自己在持续控物上的天赋和能力边界，放弃用一次成功证明自己；继续承担短杖采购的行政安排与流言监测，但不再独自扛下全部领务。
- **卢卡斯的收益**：艾尔伯实际分担工作；莉莉安把他的安全当成可以直接干预的事；他获得一次不由未来记忆和婚约定义的普通相处。
- **莉莉安的代价**：面对教堂明确拒绝和外来人员的注视；接受制式短杖无法替代旧杖的现实；在不擅长的料理中接受真实批评，而不能用魔法精度替代生活经验。
