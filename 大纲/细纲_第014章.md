## 二、内容概括与情节安排

### 五段式

1. **起因**：夜间护理继续，莉莉安发现自己不能用帮忙换取安心；萨拉仍把热水和饭送进原房间。
2. **发展**：次日宅外来人各有所求。萨拉按记录检查涉事杯，发现它没有清晨主人杯的成对短刻；这只能推翻“签名等于全程未动”的方便解释。
3. **转折**：艾尔伯短醒确认卢卡斯可调度调查、暂不交人。莉莉安知道家族没有赶她走，却见保护正占用有限人手与时间。
4. **高潮**：她把已知的逼婚、流言和移交要求串起来，相信自己离开能暂时拆掉对方索人的借口。她先留证，再收起木船和旧箱；面对短杖与钥匙时，理性动作不再能遮住难过。
5. **结尾**：加文不以嫌疑拘禁她，正常开门，随即报讯。卢卡斯进空房读到说明；门外索人的要求暂时停在核实去向上，新的“逃了”却已经出现。他把钥匙交给萨拉，短杖仍留原处。

### 多线与因果

- 主线：再次被利用的莉莉安尝试阻断伤害，但仍习惯独自决定所有人应当付出的代价。
- 事件线：一夜留护 → 复核杯底 → 父亲短醒授权 → 索人及生计压力 → 陈述交接 → 正常离宅 → 报讯与空房。
- 调查线：真签名不能覆盖运输空档；只打开继续调查的入口。无须靠她留下做诱饵才能继续。
- 关系线：不交人 → 停工仍有饭与房 → 不囚禁。莉莉安收到这些善意，却没有把决定拿来共同商量；家人的担心与后续寻找因此增加。
- 因果：福克斯借既有污名和婚约将危险带进家庭 → 莉莉安观察到嫁祸与索人相连 → 留下事实、主动离开 → 当日移交无法立即兑现 → 对方需核实去向，宅邸短暂缓气，同时出现潜逃口实和寻找负担。
- 不增独立支线：退订、巡逻调度、北山联络均服务于同一场压力；不追加失踪帮工、夜袭或第二次中毒。

### 出场与信息差

- 出场顺序：莉莉安、蒂莉、萨拉 → 卢卡斯、治疗者、艾尔伯 → 加文与宅外匿名来人 → 萨拉转述守物骑士见证的查杯结果 → 艾尔伯短醒 → 莉莉安收拾 → 加文开门 → 卢卡斯和萨拉入空房。
- 守物骑士与留镇骑士分开；治疗者沿用STK-HEAL-013，福克斯联络来人沿用STK-FX-ESC-013，不与STK-OBS-01合并。
- 莉莉安只推断福克斯正在利用她，不能知道真实替杯点、操作者、真杯去向或威廉的具体命令。
- 卢卡斯和萨拉可以得知杯底不合、她留下的陈述和离开事实；不能因箱子不见便知道箱内每件物品。木船随行首先由读者在莉莉安场景看见，卢卡斯可到016见面后确认。

## 四、逐场细化

### （一）热水送到以后【详；1200字】

- **时间／空间**：013末后同夜；二楼南向客房，门口到桌边；莉莉安视角，蒂莉先在门外，萨拉敲门获准后入内。楼下会客厅治疗不间断。
- **目标与心理**：从等坏消息转为勉强接受一个眼前动作；读者感到照护仍在，但不能松懈。
1. 萨拉兑现热水，莉莉安先问艾尔伯；得到“还在照看、今晚不能离人”的有限回答。热水在两人之间落桌，不写虚假保证。【护理承接·密300】
2. 萨拉让她换下沾酒的灰蓝厚裙。她从衣柜取已有自带衣裙；灰蓝裙交萨拉稍后处理，深褐外衣与烟灰披肩留椅背，香囊始终佩戴。换衣时两人退到门外。【衣着与隐私·中250】
3. 她吃一点送来的食物，停下听楼下脚步，想拿托盘下去；蒂莉接过，顺口问明早想吃什么。莉莉安一时答不上来，最后给一个普通回答，不再追问能抵多少工时。【低幅接纳·密400】
4. 莉莉安自行合门，钥匙放桌边可取处；不新增外锁。夜间以换水脚步、灯光与一次询问伤者简短带过，未写整夜安睡或再次突发抢救。【时间过渡·中250】

### （三）杯底少了什么【详；1400字】

- **时间／空间**：上午；萨拉由厨房经后门去花园书房，再回主宅找莉莉安；莉莉安视角，只听有来路的结果和检查经过。
- **场外动作计划**：萨拉带薄册，与原守物骑士核对封纸和昨夜存放状态，记录开封。涉事杯保持直立，由萨拉托稳缓慢抬起，骑士从下方观察底部；全程在承接托盘上方，残液留杯，不翻杯、不倒样、不洗底。若底部看不清，先停止，不能为了剧情强倾；本方案按能看清实施。查看后仍直立固定、重新封存并记见证人，其他初筛留样、壶和残包均不动。治疗者继续护理，不被拉来主持查物。
- **心理**：莉莉安从不敢期待到追问实物，再从“可能有人信我”偏向“他们究竟要借我做什么”。
1. 萨拉返回时先让莉莉安独立复述清晨怎样认主人杯，不先提示缺了哪处；莉莉安说底部两道短刻，明确这是自己的记忆而非对整段运输的见证。【独立回忆·密350】
2. 萨拉才说明涉事杯底没有那对刻痕。用一次简短追问交代余液始终留杯、骑士见证、杯已重新固定；正文不把场外开封过程切成第二套调查报告。【第一裂缝·密400】
