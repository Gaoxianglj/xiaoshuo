# 细纲（第001章）

## 第一章 学院的新生

- 核心事件：莉莉安以首位平民学生身份进入艾瑞安学院，在公开排斥中被推上新生代表讲台，又得到玛琳主动留下的食物、路线图与下一次见面约定。
- 字数目标：14000字
- 目标情绪：不安中的微弱期待。读者先看见莉莉安想退回安全处，再看见她被迫暴露；章末留下“这份善意究竟能否成立”的期待。
- 章节定位：推进／开篇立人设
- 章首钩子：选择困境——录取结果公布日，莉莉安一边系紧遮住白发的兜帽，一边面对老板娘送来的肉汤；她既怕落榜辜负师傅，也怕真的考上。
- 爽点：无显性打脸；阶段收益是艾尔文当场制止攻击、莉莉安的实战第一与异常精灵语被两位院长分别确认。读者获得“她真正的能力远高于周围认知”的期待。

### 内容概括（五段式）

- 起因：莉莉安在首都旅店等到放榜日，带临时凭证独自前往贵族区。
- 发展：白发被高年级学生以魔法掀开，艾尔文解围并告知她已录取、被调剂到魔法学院且必须担任新生代表。
- 转折：湖畔宿舍与精灵给她短暂安全感，艾尔文则从精灵语试卷中看出异常；新生典礼上，魔法学院同班集体离席。
- 高潮：莉莉安仍将演讲稿完整背完，随后在食堂被玛琳主动接近，并第一次得到同龄人的直接维护和邀请。
- 结尾：菲莱尔提出无证据的警告；莉莉安选择再相信一次。第一堂魔法课建立两人的日常节奏，章末转入茉莉房间，揭示排斥背后的家族命令与茉莉的迟疑。

### 情节安排（多线）

- 主线推进：完成莉莉安入学、公开身份、学院孤立、玛琳初识四个开篇基点。
- 辅线推进：艾尔文发现精灵语试卷异常；茉莉受凯恩家命令打压莉莉安。
- 事件线／任务线：旅店出发 → 过桥验证 → 城中冲突 → 马车得知录取 → 入住宿舍 → 新生典礼 → 食堂初识 → 第一堂课。
- 任务卡点：过桥与贵族区拦路均服务于阶级和白发风险；宿舍分配服务于制度性隔离；不得添加无变化的登记流程。
- 感情线／关系线：无显性感情线；莉莉安与玛琳从陌生人变为愿意在之后课程里再次坐到一起的同学，关系仍停在初识与试探，莉莉安与菲莱尔建立亲近但不完全服从其判断的关系。
- 逻辑线：师傅换来考试资格 → 莉莉安参加考试并被录取 → 实战第一使其无法低调 → 新生代表身份触发贵族集体抗议 → 玛琳在孤立后主动接近 → 凯恩家要求继续打压。
- 住所知情边界：玛琳只因在食堂听见接待员提到湖边木屋钥匙而知道莉莉安住址；她后来惊讶的是湖边宿舍多属高年级、这份分配造成了隔离，不是突然发现莉莉安住在湖边。

### 人物关系和出场顺序

- 出场顺序：莉莉安、旅店老板娘、桥头卫兵、两名高年级学生、艾尔文、宿舍接待员、湖中精灵、萨兰、菲莱尔、奥莉维娅、茉莉及同班学生、玛琳、阿尔瓦、茉莉的贴身女仆。
- 人物关系变化：莉莉安与学院从“尚未录取”变为“合法却被排斥的新生”；与艾尔文从陌生变为受过一次解围且被秘密关注；与玛琳从陌生变为接受下一次见面；与菲莱尔从精灵群体中的熟悉感变为认识一个有名字的具体精灵。
- 视角／信息差：主体严格为莉莉安第三人称限知；艾尔文办公室、茉莉房间为功能明确的暗线分节。莉莉安不知道精灵语答卷价值，不知道玛琳带任务接近，也不知道茉莉受父命行动；读者只在章末得知茉莉的家族压力，不揭示玛琳任务。

### 情节细化

1. 老板娘将多放肉的汤推给已系紧兜帽的莉莉安，放榜日的两难通过食物、住宿钱和回程选择外化【章首钩子·密700】。
2. 莉莉安告别旅店，回想首次入城时曾被城门卫兵强制摘帽核验、由此暴露白发并引发街道恐慌；今日穿过平民区后，银项链让原本拦路的贵族区卫兵改口称“大人”，以两次检查的差异交代白发风险与阶级门槛【设定／人物·中500】。
3. 贵族区草地上两名高年级学生拦路搭讪，其中一人以风魔法掀开兜帽；莉莉安先藏起防御术，再主动撤去魔力、报出平民身份【危机／人物塑造·密1400】。
4. 艾尔文的马车停下，他以城内禁用攻击魔法和学院已知身份压住冲突，不替莉莉安作英雄式宣言【危机解除·密700】。
5. 马车中，艾尔文告知录取、调剂与实战第一；新生代表的消息让莉莉安低调计划破产，两人围绕“精灵学院靠背书”形成第一次不完全规整的对话【信息揭示／关系·密1000】。
6. 主楼前分别，莉莉安拒绝继续坐车，独自领取地图和湖畔木屋钥匙；接待员的礼貌与分配结果形成隔离感【制度压力·中550】。
7. 湖边确认无人后，她脱鞋泡脚，与水中精灵说话；精灵按摩过度的生活化互动建立她在人类与精灵面前的差异状态【喘息／人物·中650】。
8. 艾尔文办公室中，萨兰先按现行标准判答卷“乱写”；艾尔文逐字读完后借走试卷并抄录，异常只通过动作与保管方式呈现【伏笔／信息差·密850】。
9. 莉莉安清扫木屋并点亮辉石灯，菲莱尔从窗外进入，自报姓名、承认考试时帮忙并提醒学院不是好地方【关系／伏笔·中650】。
10. 新生典礼前，奥莉维娅确认莉莉安凭实力获代表资格；她上台后四十二名同班学生随茉莉离席，莉莉安靠背稿和姿态维持完成【高潮／制度排斥·密1700】。
11. 后台走廊中，菲莱尔从力量逻辑嘲讽人类；莉莉安只把演讲当作做完一件工作，仍下意识避开同班座位【余波／人物·中550】。
12. 空食堂中玛琳亲自端餐，直说自己来“拉帮结派”；对姓名称呼、座位距离和宿舍安排的交锋让善意落到动作上【初识试探·密1200】。
13. 回木屋后菲莱尔依据贵族处境和气味提出警告，莉莉安承认过去的信任代价，仍决定先相信眼前行为；不把选择写成宣言式主题总结【选择／伏笔·密750】。
14. 数日后的第一堂魔法课，玛琳抱怨厚教材，询问身世时被铃声截断；阿尔瓦以扩声术整顿课堂，并说明免课决斗可向他或奥莉维娅申请、实际主持者由学院按申请人情况安排【校园日常／设定·中1000】。
15. 下课无人挑战，玛琳用不够端正却实用的口吻解释学院圈层；莉莉安只在课业话题上回敬，两人追逐到下一个教室，为第二章开场保留自然的同学来往【关系试探·密700】。
16. 茉莉房间中，牛排、调查纸与女仆口述构成家族命令；茉莉认可莉莉安的训练痕迹，却仍答应执行，停在刀叉与未撤回的命令上【章尾钩子／暗线·密800】。

### 代价兑现／收益兑现

- 代价：莉莉安被公开为首位平民学生与白发“魔女”，低调生活的可能性在入学当天消失；湖畔宿舍使她与同班日常距离被拉开。
- 收益：获得正式学籍、独立宿舍、艾尔文和奥莉维娅的有限保护、玛琳的一次主动靠近；异常魔法与精灵语能力得到读者侧确认。
- 后续账：玛琳为何接近、茉莉会如何执行命令、艾尔文如何研究答卷、菲莱尔为何警惕学院。

### 结尾设定和钩子

- 结尾设定：莉莉安已正式成为魔法学院新生，并与玛琳建立可继续的校园来往；凯恩家打压计划已启动。
- 章尾钩子：信息差／具体物件——茉莉在调查纸旁切开已经冷掉的牛排，答应执行父命；期待度中强。第二章承接阿尔瓦课后，直接进入玛琳与莉莉安的学院日常，不在莉莉安视角提前揭示暗线。
