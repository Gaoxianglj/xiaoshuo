## 一、基本信息与验收契约

- 章名／篇内编号／题记：第020章／第三幕第一章《至此我们踏上旅途》。题记：

  > 若出走足够长久，最爱之处便成了家乡。
  > —《路》

  《路》是神赐之地内的虚构书名与引文，不追溯现实出处。
- 上位路线、作者已确认项、本次细纲拟定项：承接`大纲/幕纲_海韦尔的海啸.md`第一段与“黑发、缇娅”口径。已确认：染发膏须由当地材料、卢卡斯的工艺思路与莉莉安的细微魔法共同完成；它短效、可被长时间浸泡／强洗／补染周期破坏，普通小雨不立即失效。旅途对外只称旅行度假和维系南方货物采购；寻找法杖是对外隐藏的真实目的。卢卡斯亲自驾车，莉莉安与他两人出行，不安排骑士随行。拟定：第019章后再过一段冬日淡季，试染完成、旅行窗口落实。
- 前章承接、时间跨度、核心事件、建议篇幅：承接第019章的共同方向，至第020章冬日清晨出发；建议正文约9000字。莉莉安主动选择以短期黑发身份踏出宅邸，亲自决定带走什么、留下什么，并与卢卡斯开始一段随时可以回头的旅途。
- 目标情绪、章节定位、情绪弧线、章首钩子／小兑现：低压生活＋关系推进＋换幕启程。情绪从“能够独自走进镇子的小心安稳”到“陌生容貌带来的松弛与不安并存”，在雨中确认“可以同行也可以返回”，最后落到清晨车轮离宅的明亮期待。章首钩子为莉莉安独自以未婚妻身份从镇上采买归来；小兑现为试染成功后，她第一次在陌生目光中没有先被白发定义。
- 视角、表达强度与可选参照：莉莉安第三人称限知为主；艾尔伯的事务只由她在场可见的动作、文书和卢卡斯／萨拉的转述呈现。日常保持克制，雨中谈话允许细腻展开，但不写告白、亲密动作或“从此不再害怕”的结论。
- MUST_KEEP：镇民接纳有所提高但并不一致；艾尔伯部分恢复而未痊愈；蒂莉课业和萨拉的宅邸日常；染发全过程的材料、失败、头发来源与萨拉边界；普通小雨测试；莉莉安保留大多数物件和房间；卢卡斯亲自驾有篷货车。
- MUST_CHANGE：作者点子中的“秋末微雨、落叶将尽”调整为冬日细雨与已疏的枝影，以免与幕纲确定的冬季淡季冲突；保留其温柔、试水与同行确认的功能。艾尔伯不恢复到可以全面处理领务，只在治疗者限制下处理少量必须由他确认的事项。
- MUST_NOT：不把黑发写成“终于正常”、永久伪装或旧案解决；不让卢卡斯替莉莉安决定身份、行李、启程或是否离开；不让缇娅的完整文件、学院准入或海韦尔伯爵提前落定；不让艾尔伯／萨拉／蒂莉以宣言式祝福替代日常；不新增告白、称呼变化、婚约变化或对未来的保证。
- DOWNSTREAM_CONSTRAINTS／ACCEPTANCE_TESTS：正文须写清染发只遮住白发，淡紫眼睛、熟人近看与旧案风险仍在；雨只能检验短时耐水，不能推翻浸泡失效限制。出发时明确交代客房钥匙、香囊、短杖、旧木箱、断杖与纸件去向；后续从“离开宅邸、尚在前往海韦尔的路上”继续，不默认已抵港。

## 二、内容概括与情节安排

### 五段式

- 起因：第019章之后，斯托克顿在冬季淡季得到有限恢复。莉莉安独自从镇上采买归宅，日常行动已不再只发生在安全的宅邸内部；艾尔伯也只能在恢复间隙确认少量必要事务，为可取消的短期出行腾出窗口。
- 发展：蒂莉有一点课业进步，萨拉仍按宅邸作息安排莉莉安换衣做事，再让她送茶去仓房。卢卡斯和莉莉安复盘染发膏的材料、失败与最后一缕试发，完成一次谨慎的终试。
- 转折：正式试染与短时耐水测试成功。蒂莉、送货者与艾尔伯的不同反应使莉莉安看到：镇民对她已有更多日常接受，但白发仍是少数人持续恐惧与辨认她的入口；黑发只给她一段不先被看作“白发魔女”的空间。
- 高潮：冬日细雨中，莉莉安主动测试染色的短时耐水。卢卡斯撑伞而来，重申她可随时停下、改道、返宅；莉莉安说会把大部分东西留在这里，希望仍占着那间房，确认同行不是交出退路。
- 结尾：数日后，莉莉安亲手收拣旅行物品、把断杖与大部分私物留在南向客房，带上钥匙、短杖与补过静澜花的香囊。清晨，她登上卢卡斯亲自驾驭的有篷货车，马车沿路离开宅邸，朝海韦尔方向出发。

### 多线

- 主线：莉莉安以黑发和可返回的行李安排，主动迈出进入陌生城市的第一步。
- 事件线：有限领务恢复→试制染发膏→试染与耐水验证→旅行物资与路线窗口落实→离宅启程。
- 关系线：卢卡斯提供方案与风险说明，萨拉守住莉莉安身体与发样的边界；莉莉安亲口确认想保留房间与归途，二人从“共同方向”落到第一次共同上路。
- 背景线：北山仍在分阶段交接，东门修缮与赔付未完；艾尔伯只能签看少量关键事项。它们证明旅行是暂时可行，不证明领地已痊愈。
- 任务卡点：无强行设置的外部卡点。染发的失败与试水承担“选择压力＋设定限制”功能：若没有最后一缕试发、分段试染和小雨验证，正式出行时染色的可信度与失效边界均不足。
- 因果：莉莉安想以不先被白发定义的身份进入陌生城市 → 同意参与艰难的试色并承担有限伪装风险 → 黑发短效成功、旁人的目光产生差异 → 她确认可保留房间与物件 → 有退路地出发，而非被带离。

### 人物出场顺序、关系变化与信息差

- 出场顺序：莉莉安→镇民／店主（均不具名）→艾尔伯、治疗者、卢卡斯、萨拉→蒂莉→仓房中的卢卡斯与染发材料→送货者（不具名）→艾尔伯→冬雨中的卢卡斯→清晨的卢卡斯与马匹。
- 人物关系变化：莉莉安与镇民从“能被接纳但仍易受白发牵动”到“她可独自完成普通采买”；莉莉安与萨拉从被照看的一方延伸为被允许自己选择、但有人守住边界的一方；莉莉安与卢卡斯从约定共同方向到实际启程，仍保留改道、争执与归来。
- 视角／信息差：莉莉安只知道艾尔伯能处理多少、北山和修缮有局部进展，不掌握全部文书；她知道黑发并不抹除眼睛、旧案和熟人风险。读者从幕纲知道海韦尔会带来更大冲突，但本章人物只是在准备旅行；卢卡斯不以未来记忆承诺旅途安全或法杖必得。
- 人物命名：本章不新设具名角色。持有旧染法的老人和送货者均只承担一次性功能，暂以自然称谓出现；若后章需要复用，再依据职责、地域与出场功能命名，避免为一面之缘虚建人物档案。

## 四、逐场细化

### （一）提着采买袋归来【详；850字】

- 时间／地点／出入口／视角／在场人物：冬日午前，斯托克顿镇上至宅邸前门的路；莉莉安第三人称限知。店主、路人仅作无名群像。
- 场景目标、读者情绪与冲突：以可见行动开幕，交付“她已能独自走出去”的轻微惊喜；冲突不是遭遇敌意，而是她仍会注意旁人是否先看头发。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：她带着旅行用的耐穿内衣、针线／药品等少量采买回宅；店主按未婚妻身份正常招呼，一位镇民只让开窄路，不追问她的过去。她不把这一点平常当成大和解，只把包提稳、照原路回家。
- 情节点与选择：采买不购买整套“新身份”衣装，也不公开宣告旅程；可让她按萨拉列的单子买齐物件后，自己额外挑一只小布袋／一卷线，显示她参与安排而非被动领取。
- 关键场景细写重点：镇民的接纳通过结账、让路、简短问候或不再围观体现；仍可留一个避开她目光的人，避免全镇整齐转向。
- 结果、代价、转场及下一场接口：莉莉安带着冷气和纸包进门，听见主宅内有人在处理文书，转入领地恢复的有限镜头。

### （二）仍只够看两页的领务【略中；800字】

- 时间／地点／出入口／视角／在场人物：主宅会客厅／近书桌处；莉莉安进门时见艾尔伯、治疗者、卢卡斯、萨拉。
- 场景目标、读者情绪与冲突：让艾尔伯恢复一点能动性，同时把“能出门”建立在真实分工而非病人痊愈上。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安见艾尔伯坐在软垫里确认一页回函；治疗者在第二页前按住文书。她从断续话语中得知东门赔付仍未齐、北山只完成部分交接，却已有一份允许卢卡斯以继承人身份短期走访、维持采购与递送的回函可发。
- 情节点与选择，所需能力、权限、物件和信息来源：艾尔伯只核实“既有货单与旅居问候可由卢卡斯带去，重大承诺等书面后续”，并在自己的权限内落印；卢卡斯收下文书，不能把它夸大为跨领合约。
- 关键场景细写重点：艾尔伯的疲惫通过停笔、治疗者收走墨水和萨拉换走冷茶呈现；北山两处接防、东门棚顶和旅游询价只作几句背景，不展开案件结论。
- 结果、代价、转场及下一场接口：莉莉安知道旅行窗口确实存在也随时可撤；萨拉看见她衣上凉气，先让她换衣再做事。

### （三）布巾、课本与热茶【略中；650字】

- 时间／地点／出入口／视角／在场人物：午后，厨房、走廊与布料间；莉莉安、萨拉、蒂莉。
- 场景目标、读者情绪与冲突：延续第019章未分完的布巾，以宅邸日常展示蒂莉的进步和萨拉仍在维持秩序。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：蒂莉先拿着拼读练习或简单账目，让莉莉安看出她比从前少错一两处；莉莉安认真指出一处错漏而不夸张称赞。萨拉随后将她从镇上衣物换成室内工作裙，安排一小段能完成的活。
- 情节点与选择，所需能力、权限、物件和信息来源：萨拉包好茶壶与杯子，交给莉莉安，请她去仓房看住忘了休息的卢卡斯；莉莉安接下，不把它当作正式差事或情感暗示。
- 关键场景细写重点：蒂莉的进步只是一道会自己改正的题或一次分错布巾后重分；萨拉的关照通过“先换衣”“茶别洒”实现。
- 结果、代价、转场及下一场接口：莉莉安端茶穿过后院，仓房里的草药气味与加热味引出染发试验。

### （四）不是现成的黑色【详；850字】

- 时间／地点／出入口／视角／在场人物：后院仓房，门开向院中；莉莉安、卢卡斯，稍后萨拉可在门边出现。
- 场景目标、读者情绪与冲突：把染发膏的来历、三方条件与失败成本自然嵌入对话，避免设定说明书。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：卢卡斯对着小碗、布条和最后一缕试发忙得忘了茶；莉莉安先把杯子放到他够得着的地方，明确说他该停一下。看见碗沿结块，她知道这不是轻易成功的东西。
- 情节点与选择，所需能力、权限、物件和信息来源：对话可带出：本地有一种早在此地成为神赐之地前便流传的植物黑染；教国内如今常用的矿物染料不适合直接贴近头皮。两人曾拜访镇上仅存会做旧染的老人，对方交出配方，却仍不信莉莉安，也惧怕魔法。卢卡斯只借此得到材料和老办法，不获得老人的认可。
- 关键场景细写重点：失败须具象但不枚举成实验报告：一次莉莉安加热过快，膏体焦涩；一次热度不匀，试束近根与发尾深浅不同；另有一回固色不成，洗后褪成不自然的灰褐。卢卡斯承认自己最初向莉莉安要头发时想得太简单，萨拉只准剪发尾一点；眼前这缕是反复试验后最后留下的样本。
- 结果、代价、转场及下一场接口：卢卡斯喝完茶，放下“这次一定”的话，改为请莉莉安依步骤完成最后一次试色。

- 时间／地点／出入口／视角／在场人物：仍在仓房，窗下操作台；莉莉安、卢卡斯，萨拉短暂看守。
- 场景目标、读者情绪与冲突：让成功来自合作与谨慎，而不是天赋碾压；把魔法限制和莉莉安的主动同意写清。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安知道一旦用完试束便没有可再确认的头发，仍自己点头。卢卡斯先处理发丝与染膏，报出需要的轻微热度和时长；她只在他请她时以短杖／指尖微控热度，不替他补完工艺判断。
- 情节点与选择，所需能力、权限、物件和信息来源：分层涂覆、隔开、等待、洗净、晾干；萨拉核看头皮附近不能直接接触的材料。最末得到自然的深黑色，不要求在室内灯下立刻断言“永不褪色”。
- 关键场景细写重点：成功的揭示放在干后挪到窗边，不必以欢呼处理；卢卡斯先看见颜色均匀，又问莉莉安头皮是否刺痛、头晕，她自己回答。她不是被两人检查的对象，而是决定下一步“可以试发尾”的人。
- 结果、代价、转场及下一场接口：先在一小束发尾试染，等干透、触水后无明显结块或颜色断层，才允许正式染发。

### （六）漫长的一次正式染发【详；800字】

- 时间／地点／出入口／视角／在场人物：傍晚前的仓房与邻近洗涤处；莉莉安、卢卡斯、萨拉。
- 场景目标、读者情绪与冲突：兑现“不是轻易发明和使用”，同时使莉莉安真正参与改变外观的选择。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安看着发尾那一点成功，仍问一次“若不成怎么办”；卢卡斯答能洗、能剪去受损处、也能不出门，萨拉补上“现在停也可以”。她因此自己坐下。
- 情节点与选择，所需能力、权限、物件和信息来源：萨拉分束、护住衣领与耳侧，卢卡斯按顺序上膏，莉莉安只在每一段需要时校正热度；中途有人手酸、有人要重新梳开结块，过程不能一笔略为“魔法一闪”。
- 关键场景细写重点：写一处几乎要色泽不匀的发束被及时洗开，代替再造一个大失败；最终洗净、擦干与自然风干同样需时间。萨拉替她擦去耳侧染色，不评论“更好看”。
- 结果、代价、转场及下一场接口：三人带着尚未完全干透的发去院中看自然光，蒂莉正从学校回来。

### （七）没有先看头发的目光【详；750字】

- 时间／地点／出入口／视角／在场人物：主宅外院；莉莉安、卢卡斯、萨拉、蒂莉、无名送货者，后有艾尔伯。
- 场景目标、读者情绪与冲突：用差异化旁人反应表现黑发的作用和局限，不作“变美”式肯定。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：蒂莉看见黑发的莉莉安先停住，不敢马上叫人，待听见声音或认出她捏住披肩的习惯才走近。她的迟疑让莉莉安发紧，却又没有受伤，因为蒂莉接着问的是“染好了吗”。
- 情节点与选择，所需能力、权限、物件和信息来源：送货者照常进门送普通货物，见莉莉安后以为宅邸雇了新帮手／新女客，问错对象；萨拉只纠正眼前事务，不要求其解释。莉莉安注意到他的视线先落在她的衣着、手里物件和是否挡路，而不是白发。
- 关键场景细写重点：这一眼不是“所有偏见消失”，只是陌生人不知道该把她放入哪种旧传说。艾尔伯见到后可说：不认识她的人、又不刻意查发根，短时很难认出；随即提醒这只是出门用的办法，不能当作安全凭证。
- 结果、代价、转场及下一场接口：莉莉安既获得了松动，也记住被认不出的失重感。晚些时候下起细雨，她带着这个问题走到院中。

### （八）冬日细雨中的伞【详；1150字】

- 时间／地点／出入口／视角／在场人物：傍晚至入夜前，宅邸外院与树下；莉莉安、卢卡斯。
- 场景目标、读者情绪与冲突：这是本章情感高点。用一次受控的雨水测试，写莉莉安选择旅途而不放弃返回权。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：雨下得不大，莉莉安想亲自核验“沾一点水无碍”究竟意味着什么。她没有站到暴雨里，也不把测试当作自我伤害；她只在檐外停一会儿，看雨线从已疏的枝影间落下。
- 情节点与选择，所需能力、权限、物件和信息来源：卢卡斯拿伞来，先问她是否不舒服，再说明小雨不等于浸水、真正遇到大雨或海水仍须躲避和补染。他提到有篷货车、沿线教堂与驿站，但也说车厢可临时过夜，行李都能带上；这些是退路而非劝她必须走的理由。
- 关键场景细写重点：莉莉安可短暂想起自己过去把宅邸当作唯一安全屋、又曾把离开当成唯一能保护旁人的办法；回忆只落在门、钥匙、被留下的房间这些具体物件上，不延成长段解释。她告诉卢卡斯：大部分东西想留在这里，想先占着那间房。卢卡斯接受这不是半心半意，而是她为自己保留归处；他重申她能随时结束旅程、改道或回来，不把这句话写成浪漫誓言。
- 结果、代价、转场及下一场接口：两人共撑伞回屋。头发只是沾湿表层，颜色未立刻流失；但“补染、强洗、浸水会坏”的限制仍有效。旅行不在当夜仓促开始，转入数日后有条理的准备。

### （九）把能带走的装上车【略中；800字】

- 时间／地点／出入口／视角／在场人物：数日后，前院、仓房外与主宅走廊；莉莉安、卢卡斯、萨拉，必要时无名帮工只搬公共货物。
- 场景目标、读者情绪与冲突：把旅行的公开性和有退路的现实准备落地，避免只有抒情告别。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安看到有篷货车装入南方货品的空筐、备用毯和随行补给；它既可带回酒水等贵族旅居所需的货物，也能在错过落脚处时遮风。她确认自己不是被装进一辆离开用的车。
- 情节点与选择，所需能力、权限、物件和信息来源：卢卡斯依艾尔伯已许可的公开目的准备路引、既有采购货单与少量旅费；萨拉只核对日常衣物、药品和补染所需的少量材料，不代替莉莉安收拾私人物件。马车的夜宿功能只作为风险准备，不把沿途住宿写成绝对保证；两人不带骑士或其他随行者。
- 关键场景细写重点：卢卡斯说明自己将驾车：贵族训练包括骑马，虽不等同于赶车，他已在宅邸和马夫指导下练过路线与控缰；不把他写成一上手便熟练的专业车夫。马夫只负责交代马匹与车辆，保持既有“马夫爷爷”未正面具名的连续性。
- 结果、代价、转场及下一场接口：公共行李已妥，莉莉安回南向客房收自己的小箱，进入真正的选择场。

### （十）仍留在房里的东西【详；800字】

- 时间／地点／出入口／视角／在场人物：清晨前，南向客房；莉莉安独处，卢卡斯只在门外等候。
- 场景目标、读者情绪与冲突：用物件交代她带走与留下的界线，让“家乡”不是抽象结论。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：她把旅行衣物、日常药品和必要纸件放进小箱，又从箱中取回不需随行的物件。想起雨中的话，她决定不以清空房间证明出发的决心。
- 情节点与选择，所需能力、权限、物件和信息来源：她把木船、学院文件与大部分非衣物仍留屋内；两截古木断杖以原有束魔布分开包好，断面保护关系不变，放回旧木箱并确认细绳和双扣。普通制式短杖从桌面取出，以软布包好随身带走；静澜花香囊仍挂颈间，只补入新晒干的静澜花，不换掉它与斯托克顿的来处。客房主钥匙留在她手中。

- 结果、代价、转场及下一场接口：她提起小箱，短杖、钥匙、香囊都在自己可触及的位置，走向院中的马车。
