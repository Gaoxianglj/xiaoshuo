# 第021章细纲

> 状态：【正文已写成，2026-09-18】。第三幕《海韦尔的海啸》第二章；范围从第020章离宅后的旅途，到首次进入海韦尔当日。正文与实际终态见章节索引及021快照；以下保留写前计划，不作额外已发生事实。伯爵拜会、法杖线索和海啸事件不在本章发生。

## 一、基本信息与验收契约

- 章名／篇内编号／题记：全书第021章／本幕第二章《向着山海之间》。与前章标题连读为“至此我们踏上旅途，向着山海之间”。题记照作者原句：

  > 我想他们是骄傲的，骄傲与这繁荣，这山海，我想，这确是值得他们骄傲的。
  > —《克莱尔游记》

  《克莱尔游记》为神赐之地内的虚构书籍；题记是旅行者对城市的感受，不替此地历史与后续冲突作最终评判。
- 上位路线、作者已确认项、本细纲拟定项：承接`大纲/幕纲_海韦尔的海啸.md`第一段末尾和第二段开头、`设定/世界观/海韦尔与海啸.md`。作者本次确认：范围从旅途到初次入城；旅途不作逐日流水账；后半较充分写新鲜体验；本章不拜访伯爵；“缇娅”为已确认名字，开始正式使用；卢卡斯途中向莉莉安介绍城市与记忆中的事，抵达时仍有相当自信，供后来现实与记忆逐渐偏移形成对照。本细纲拟定：约第六日午后从内陆缓坡见城，在当日安顿车马后只作一次短途步行；具体驿站、旅店、街道和桥梁均暂不命名。
- 前章承接、时间跨度、核心事件、建议篇幅：第020章结尾，卢卡斯亲驾一匹马牵引的有篷货车，与莉莉安两人刚离开斯托克顿宅邸。路程沿已规划的驿站／旅宿，约五至六日；选写第一段落脚、一次行车中的谈话与最后一日入城，其余日子用具体变化压缩带过。核心事件是莉莉安亲口选用“缇娅”并在海韦尔第一次以此名被陌生人称呼，两人进入山海相接的城市。建议正文约八千字上下，篇幅服从抵达后的实际体验，不为预算补沿途事故。
- 目标情绪、章节定位、情绪弧线、章首钩子／小兑现：低压探索兼换地图；从离家的新鲜和一点疲乏，经卢卡斯的兴致与可信的引路，抵达初见山海时的开阔，再落到人群中使用新名字的轻微失重与好奇。章首不造险情，以“路上第一次必须自己照看车马、决定夜宿”的实际行程接住前章车轮；小兑现是卢卡斯记忆中的城市轮廓确实出现，而莉莉安看见、在意的生活远比轮廓多。
- 视角、表达强度与可选参照：莉莉安第三人称限知。卢卡斯的自信经他说得出的记忆、指出的路、准备好的现实材料、驾车与安置事务表现；不切入他的内心，也不让他宣讲未来剧情。旅途疏写，初见城市允许感官与互动稍充分，但不写成连续的观光清单或宏大赞词。
- MUST_KEEP：五至六日车程、冬季海韦尔较温和而非盛夏；两人独行，卢卡斯驾车仍是练过的新手；公开事由仅旅行度假和维系南方货物采购，寻杖对外隐藏；黑发短效、紫眼仍在；“缇娅”由莉莉安自己决定并至少在城内一次亲自对陌生人说出。城市的山坡、桥梁、长阶、平缓行车通道、港埠、白帆小船、南方货物与冬季旅客均依已确认地理呈现。
- MUST_NOT：不让卢卡斯把未来记忆当成亲自来过海韦尔的经历；不让记忆准确到当下旅店空房、商价、在任人物或陌生人的决定；不在本章安排明显的剧情失准来急于嘲讽其自信。不能把缇娅写为卢卡斯妹妹、艾尔伯养女或已取得新学籍；不编造已签妥的监护、学院准入、改名文书。不得让莉莉安因黑发便永久安全、旧案消失，也不在第一次入城就替海韦尔的全部居民与历史作结论。伯爵本人、伯爵府接待、法杖交易、海啸行动、玛琳及新的精灵决议不入本章。
- DOWNSTREAM_CONSTRAINTS／ACCEPTANCE_TESTS：记忆只提供卢卡斯见过的片段与对寻杖路径的主观把握；眼前住宿、采购联系人、通行条件来自现时询价、商信、地图或当面问路。记忆中的桥与层叠城景可以在本章得到有限印证，后续仍可在人物、条件、事件上逐渐偏移。缇娅在口头日常中使用即可，不凭一次旅店问名推定正式法律身份成立。章末两人已经入城、安顿、第一次看见港市，但尚未接触伯爵、取得法杖消息或获知海啸情报。

## 二、内容概括与情节安排

### 五段式

- 起因：车离斯托克顿后，两人不得不自己照看马、车与每日落脚。一次平常的驿站停靠让莉莉安发现“有退路地旅行”仍然是实际在往前走，她在私下说出要用的名字“缇娅”。
- 发展：路上大段日子略写，只取一次车上谈话。卢卡斯用自己记得的城景和此行重新问来的路况介绍海韦尔，谈起记忆里这座城与寻找法杖之间的关系；他没有保证结果，却真心觉得自己知道该怎样开始。
- 转折：约第六日从内陆高处接近海韦尔，卢卡斯指出的桥与山海轮廓确实出现。莉莉安先被宽阔海面震住，随后在下坡的车流、仓房和民居中发现这并不只是记忆里的远景，而是有人工作、居住、赶路的地方。
- 高潮：两人把马车安顿在旅店，莉莉安亲自以“缇娅”回答陌生人的称呼。随后步行穿过阶街、桥与店铺；没有人先从白发认出她，她反而有余力看见船、货物、潮水和人们对自己城市的熟悉与骄傲。
- 结尾：从可安全俯瞰港埠的位置望见沿岸来往的小船，她主动提出明日想走近码头，看海与船如何相处。卢卡斯的商业拜访和寻杖打算都留在明日以后；今日只属于第一次来到。

### 多线与因果

- 主线：从“已经离开宅邸”推进到“有名字、有住处地进入陌生城市”。
- 事件线：行车与选择落脚 → 缇娅之名私下确定 → 卢卡斯讲述有限未来记忆与现实准备 → 约第六日见城、入城 → 旅店安置 → 初步步行看港。
- 关系线：卢卡斯愿意把自己所记得的东西讲给莉莉安听，也有少年人初来时的得意；莉莉安并非听安排的观众，会分辨哪些是记忆、哪些是新打听的消息，选择自己使用的名字和想先看的地方。两人仍以“您／你”相称，不因共游直接确认恋情。
- 身份线：私下仍是莉莉安；对陌生人可用“缇娅”。若必须解释同行关系，只用“艾尔伯照看的远亲／受其担保监护的远房支脉遗孤”的既定公开位置，不称妹妹、女儿或当场重述原婚约。旅店日常称呼与以后学院需要的正式担保程序分开。
- 信息差：莉莉安知道卢卡斯有像亲历的未来记忆，也知道其已在首都和斯托克顿偏移；她可听他介绍海韦尔，不须因此相信寻杖必然成功。读者也不能把本章印证的一座桥或一处远景当作整条“任务流程”的可靠证明。
- 因果：他们需要尽量普通地进城 → 莉莉安选用缇娅并以黑发出行 → 卢卡斯的记忆让他敢期待，现实准备令车与人确能入城 → 城市提供既陌生又可参与的日常 → 莉莉安第一次为“想去看看”提出次日的小计划。
- 人物出场顺序与命名：莉莉安、卢卡斯 → 沿途驿站的普通接待者（不具名）→ 海韦尔车流、旅店接待者、街边商贩／水手（均只承担短暂日常功能，不预设复用）。本章唯一正式启用的新名字是莉莉安的化名“缇娅”；不为尚未确定后续戏份的服务角色硬建角色卡。若后章需要稳定的旅店主人或港口联系人，再按实际职责命名，并对重要角色标【待作者确认】及命名理由。

## 四、逐场细化

### （一）第一处落脚与一个名字【略中；约850字】

- 时间／地点／出入口／视角／在场人物：出发当日傍晚至次晨，沿途普通驿站的车棚和客房；莉莉安限知，卢卡斯、临时接待者在场。接续020末尾，不重写离宅告别。
- 场景目标、读者情绪与冲突：旅行确实开始，两人须自己处理马匹、车篷、食水和夜宿，卢卡斯练过驾车但还会慢半拍。没有追兵、强行露宿或驿站歧视事件。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安尚能回想宅邸窗户；下车后发现夜宿不是家中事先准备好的房间。她帮着确认小箱和药包，见卢卡斯先卸缰、喂马，再问次日路况；心神从回望落到眼前行程。
- 情节点与选择、信息来源：两人在私下谈起入城时该怎样介绍她。卢卡斯只问她希望叫什么；莉莉安自己说“缇娅”，不为名字临场编出血缘或来历。旅店暂按卢卡斯订两间房、付普通费用，接待者不必获得她的完整身世；这晚可不强行设置第一次公开叫名。
- 关键写法与转场：用一两件生活动作显示第一次共同上路的笨拙与可行，不展开每个驿站手续。清晨重新装车，行程继续。

### （二）走向海的几日【略中；约850字】

- 时间／地点／出入口／视角／在场人物：第二日至第五日间，选一段同车谈话，其他日子略写；只有两人在车上，偶见过路车、驿站和更密的货运队伍。
- 场景目标、读者情绪与冲突：让卢卡斯介绍海韦尔，也让读者听出他此刻为何有自信。以道路坡势、空气转潮、南货车渐多压缩日序，不能一天一段重复吃饭住宿。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安问海究竟会先从哪里出现。卢卡斯说起记忆里的叠屋、跨街的桥和绕过山坡后打开的海景；还记得这座城与他们寻找的法杖有关，因此认为自己至少知道应从哪里开始。他的路图、商信和已问过的旅宿是现实准备，与未验证的记忆分开。莉莉安听得出他的兴致，也记得他曾坦白未来已经偏移；她没有用怀疑抹掉他的高兴，只说想亲自看看。
- 情节点与选择、信息来源：不泄露完整未来情节、伯爵的具体要求或法杖交接方案。可给卢卡斯一处会在下一场被有限印证的具体画面——桥与第一眼海；别让他预报某个人会出现或某家旅店必然有空房。
- 旅途物件与时长：黑发是短效染色，路上需观察发根、发尾和洗脸后的变化；若确需补染，沿用上一章已有的染膏与分段施法办法，不凭空规定精确补染周期，也不让它毫无照料地自动维持。
- 结果、代价、转场：正常落脚；一匹马与卢卡斯的谨慎车速解释第五或第六日到达，不把路上所有夜晚列出来。转入最后一日的高处路段。

### （三）从高路第一次看见海韦尔【详；约1100字】

- 时间／地点／出入口／视角／在场人物：约第六日午后，海韦尔内陆较缓的入城车道上方；两人在车上，其他车旅只是经过。
- 场景目标、读者情绪与冲突：兑现城市的第一眼。先看见依山升高的屋顶与桥，再经道路转折看见海面、下层平码头和白帆小船；不把整座城一次看尽。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：莉莉安照着卢卡斯前几日所指的方向找，最先只看见屋脊；下一转弯，海从建筑间展出来。她短时失语，随后才注意到岸线不是画里安静的一条边，而在呼吸、移动，船也并非从高处看见的白点那样轻。
- 情节点与选择：卢卡斯认出记忆里的桥，显出一点真切的“我说过吧”的得意。印证仅及城市远景，不延伸为他已知道港口现实与法杖条件。题记的骄傲先由壮观景象得到感受，后面再用人的生活补足。
- 结果、转场：道路仍须顾马顾车，二人不能停车长久眺望；沿可通车的缓坡进入城中。

### （四）让马车走的路【略中；约850字】

- 时间／地点／出入口／视角／在场人物：当日午后，内陆车道至可安置货车的旅店附近；莉莉安、卢卡斯、商贩、挑货人和过往旅客。
- 场景目标、读者情绪与冲突：将远景转成可通行的城市。阶梯给行人，货车走坡道；卢卡斯需要在更密的车流里收缰、让车，不凭记忆穿墙式直达下层码头。
- 入场心情 → 具体触发 → 内心判断 → 外显行动 → 出场心情：山城越来越近，莉莉安想多看，车却不能随意停。她先帮卢卡斯留意一侧空筐与车篷，随后从车流听见不同口音，闻到海风混着湿绳、鱼货、酒桶和烤食的气味。
- 情节点与选择、信息来源：卢卡斯依据此行查得的住处和眼前指路，把车驾向能收马车的旅店；若问路，只问普通行车方向，不让“记忆”代替当下道路。商路繁忙不等于每个人都认识斯托克顿家，也不需要设置不合时宜的盘问危机。
- 结果、转场：马车停妥，进入旅店安置场景。

### （五）第一次有人叫她缇娅【详；约1150字】

- 时间／地点／出入口／视角／在场人物：同日下午，能存车、照料马匹的旅店；莉莉安、卢卡斯和不必命名的店员。
