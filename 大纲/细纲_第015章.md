## 二、内容概括与情节安排

### 五段式

- **起因**：014已经正常开门离宅。莉莉安沿南岸往西走，旧箱迫使她频繁换手，必须先解决饮水与当晚歇脚。
- **发展**：现实问路把她带到旧伐木道，本地精灵在她请求后指到林缘守林棚。它们留下陪伴，她终于能放下箱子，却仍想到宅邸原有的晚饭与房间。
- **转折**：菲莱尔到来，听到她说艾尔伯遇害与自己离开，几乎又要去惩戒人类，随后自己收住。它承认当年并非没有发现，而是先选择杀人，没来告诉她。
- **高潮**：菲莱尔把原初之地交到她面前。她由认真倾听走到追问十年以后，又在明确的使命与离开条件中迟疑；这一次没有人催她证明自己值得留下。
- **结尾**：她没有接受升格，也没有拒绝。视角切到卢卡斯：他在旧伐木道附近看到未散的光点，向它们聚集的方向走去；莉莉安仍保留自己作最后回答的余地。

### 主要因果链

- 提箱步行且去向未定 → 她先问饮水与歇脚处 → 留下普通人能复述的路线 → 离开没有让现实联系完全消失。
- 林缘路陌生 → 她明确请求本地精灵指路 → 自行走到棚屋暂歇 → 陪伴使她不必靠不断赶路压住难过。
- 菲莱尔得知投毒与离宅 → 愤怒逼近旧有选择 → 它自己停下并交代失约 → 莉莉安终于听到一个迟来的真实回答，但伤害并未因此消失。
- 接纳不需自证、未来不再衰老患普通疾病 → 她认真想去 → 十年及职责影响具体的人与去处 → 她无法立即答应，却也不能轻易舍弃这份安稳。
- 莉莉安在精灵仍愿等待时不作答 → 卢卡斯完成必要交接后沿她实际走过的路问询 → 他看见与她有关的光点仍聚在林缘 → 自行进入旧伐木道，016才让两人相见。

**出场顺序**：莉莉安 → 匿名车夫 → 本地精灵 → 菲莱尔 → 卢卡斯。车夫为一次道路见闻者，不赋名、不并入既有搬运者；第七场可由卢卡斯向同一车夫及沿路普通人核问。本地精灵不自动认作010湖中某个个体，不增设长老或执行者现场角色。
