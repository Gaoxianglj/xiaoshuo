## 细纲（第 007 章）

### 第 007 章：命运予我以玩笑

- **篇内编号**：斯托克顿篇·第 2 章。
- **时间锚点**：第 006 章婚约签署约半个月后；秋之精灵已于前些日子抵达斯托克顿领，作物陆续成熟。当天清晨至午后，莉莉安的马车约在正午抵达宅邸。
- **核心事件**：卢卡斯一边处理秋收、税务与领民事务，一边等待素未谋面的平民未婚妻；莉莉安抵达后，他认出她正是“乙女游戏”中的女主角，也确认玛琳事件的固定剧情已经发生偏移，却暂时找不到原因。面对仍能清楚判断现实、却把全部理性用于取消自身权利的莉莉安，他决定先照顾眼前真实的人，再从她愿意说出的部分慢慢了解发生过什么。
- **字数目标**：约 14500—16000 字。素材仍承担卢卡斯人物建立、领地日常、双主角初见与命运线反转，但莉莉安必须在正文前45%内抵达，前半不再把领务与游戏设定各自展开成完整说明段。
- **目标情绪**：以初秋领务的安稳忙碌作短促底色，用明确倒计时把注意力持续拉回即将到来的女孩；在莉莉安跪下、冷静放弃自身权利时急转为错愕与心疼，最后留下“剧情为何偏移”的疑问，以及卢卡斯暂时放下未来、先顾眼前人的选择。
- **章节定位**：普通推进章 + 关系起点章 + 命运线首次显性转折。
- **主视角**：卢卡斯·斯托克顿第三人称限知。萨拉带莉莉安安置客房的部分仍不切换进萨拉或莉莉安内心，只写卢卡斯当场可见的动作，或由萨拉稍后简短回报的事实；莉莉安的创伤原因不在本章被旁白全知解释。
- **固定章首引句**：必须逐字写入，不改字、不润色：

> “这一天终将来临，这一天如此意外，我曾嘲笑命运如齿轮般咬合了每个人的过往未来，如今,我苦笑命运如儿戏般戏虐了每个人的相识相遇……”

- **章首钩子**：神秘独白 + 可见疲惫 — 固定引句之后，不从风景起笔，直接写卢卡斯在书桌前被压麻的手臂、未合上的账册与已经冷掉的温热石中醒来；他昨夜又在花园书房睡着，而今天中午，那个被父亲替他写进婚约的女孩就会抵达。
- **爽点 / 看点**：无传统打脸爽点。本章的核心看点是三重认知变化：卢卡斯以为未婚妻只是凯恩家打压的普通平民 → 他认出莉莉安就是游戏女主 → 他确认固定剧情已经偏移，却不知道偏移从何开始。情感落点不是解谜成功，而是他第一次把黑色笔记本放到一旁，优先面对已经来到眼前的莉莉安。

## 大纲五检

1. **情绪与模式**：交付“安稳日常被命运错位刺穿”的错愕与心疼；采用“日常秩序 → 轻微期待 → 身份揭晓 → 固定剧情崩塌 → 原因留白 → 选择真实的人”模式。
2. **核心冲突**：卢卡斯想把被迫婚约当作一个可以理性承担的现实问题，却发现未婚妻正是本应被剧情保护的女主角，而她已经被那条剧情彻底抛下。
3. **节奏**：清晨过劳与父子早餐回忆只交代婚约代价；游戏固定剧情只先留下最小必要印象。南岸巡视压成一个连续场景，以福克斯货车、蓝边通行签和教堂短讯把倒计时推到门前；莉莉安在正文前45%内抵达。后半把篇幅交给跪地、文件、自我取消、房门与断杖，黑色笔记本段最后补齐偏移链并冷却收束。
4. **伏笔**：显性推进 V04“游戏记忆并非可靠攻略”；显性推进 V08“断杖”；推进 V03“婚约是福克斯阴谋入口”；暗埋“无名混混的真实身份”但不向卢卡斯提供答案，只让他登记剧情偏移与原因未知。
5. **张弛与定位**：第 006 章政治压迫后，前半以领地日常和卢卡斯人物建立喘息；后半不是继续加码外部阴谋，而是把压力转为关系与命运冲击。章尾强钩子指向“卢卡斯如何面对真实莉莉安与失效剧本”，下一章可回落到客房、食物、门锁等低烈度生活安全。

## 内容概括（五段式）

- **起因**：秋收、税务和旅游物流叠在一起，卢卡斯连续多日睡不好；而比公务更令他失眠的，是艾尔伯半个月前在早餐上告知的婚约。父亲讲明威廉以全面撤军相逼，卢卡斯笑着说父亲做得对，却仍为失去自由选择感情的可能而遗憾。
- **发展**：萨拉送来早餐与沿途短讯：莉莉安最早中午抵达，前夜却始终留在马车里。卢卡斯只短暂想起“游戏女主此时本应仍在学院”，便按原计划去南岸处理最急领务。市场、公仓、巡逻和教堂合为一次有倒计时的巡视；秋收过劳可见，福克斯货车的蓝边通行签被顺手记下，但不解释用途。
- **转折**：神父确认莉莉安整夜没有下车，卢卡斯赶在正午前回宅。萨拉整理衣装时，两人短谈他公开多年的异世说法与对“原本卢卡斯”的愧疚；话没有被说透，马车声即打断他们。
- **高潮**：马车抵达。卢卡斯依礼低头伸手，莉莉安没有接，而是下车后跪在石地上。白发、淡紫眼睛和固定立绘般的五官使他认出“游戏女主”；更大的冲击来自她仍能准确区分“学院判决”“本人签署的声明”与“婚约要求”，却逐项放弃自己作为未婚妻、客人与被照顾者的权利。卢卡斯停止未经允许的触碰，与萨拉先把她带入宅邸并安排不会从外反锁的南向客房；安置行李时，两截包裹过的断杖短暂露出。
- **结尾**：莉莉安被安置后，卢卡斯回到花园书房翻开黑色笔记本。他确认游戏中的玛琳栽赃本应被莱恩、理查德与埃德蒙破获，而现实中的莉莉安却已退学、断杖并被送来边境；小巷里的混混没有名字和独立画像，他也没有任何材料能定位偏移原因。卢卡斯只在页边写下“结果已改变，原因不明”，决定以后从莉莉安愿意说出的部分慢慢核验。萨拉来报莉莉安没有动食物、仍在反复检查门锁，他合上写满未来的黑色笔记本，先返回宅邸。

## 情节安排（多线）

- **主线推进**：完成莉莉安正式进入斯托克顿宅邸与双主角第一次见面，建立本卷“被允许进门”的起点。
- **辅线推进 A（领地经营）**：通过秋收、税务、市场访问、外地商贩与巡逻骑士，表演卢卡斯如何把“替原本卢卡斯承担责任”的愧疚转化为长期领务工作，而不是只把它留在自我厌弃里。
- **辅线推进 B（游戏 / 命运）**：首次较完整揭示卢卡斯拥有地球前世与乙女游戏记忆；只确认现实已经偏离固定剧情，不解释偏离原因，使游戏知识从“可靠攻略”降为“待核验旧地图”。
- **事件线 / 任务线**：卢卡斯要在中午前完成当天必要的领务巡视，并赶回宅邸迎接未婚妻；教堂钟声与马车传讯构成明确时间约束，不额外制造拖延障碍。
- **任务卡点**：无人工阻拦型卡点。教堂得知“莉莉安整夜不下车”不是为了拖延返程，而是信息揭示：把“陌生未婚妻”第一次变成一个状态异常、可能害怕封闭人群的具体的人。
- **感情线 / 关系线**：没有爱情升温。卢卡斯从“愿意承担婚约的陌生对象”转为“必须先让她活着、休息，再去理解真实发生了什么”；莉莉安仍把他视为拥有绝对处置权的陌生少爷，没有形成信任。
- **父子线**：艾尔伯擅自签约造成的潜在裂痕没有以争吵爆发；卢卡斯的理解反而使艾尔伯更清楚儿子替自己吞下了什么。父子问题并未解决，父亲全天缺席也使卢卡斯不得不独自承接婚约后果。
- **教会线**：地方神父既负责信仰、税务、教育与传讯，也以合规程序提供未来解除婚约的可能；表现地方教会不是全然恶意机构，但善意仍受制度边界限制。
- **角色可见逻辑线**：游戏中小巷解围 → 莱恩关注女主 → 理查德、埃德蒙被带入关系网 → 玛琳栽赃被破获；现实中莉莉安已退学、断杖并接受婚约 → 至少一处前置条件已经改变，但卢卡斯不知道是哪一处。
- **作者层隐藏逻辑线**：无名混混实为原卢卡斯 → 现有卢卡斯没有成为混混 → 小巷冲突不发生 → 莱恩等人没有提前介入 → 玛琳栽赃成功。此链不得在 007 变成卢卡斯的结论。

## 人物关系和出场顺序

- **现实出场顺序**：卢卡斯 → 回忆中的艾尔伯 → 萨拉 → 南岸城镇领民与外地商贩 → 巡逻骑士 → 地方神父 → 车夫 → 莉莉安。

## 代价兑现 / 收益兑现

- **卢卡斯的收益**：确认未婚妻真实身份，也确认游戏固定剧情已经发生重大偏移；地方教会、市场与领务网络仍正常运转，为后续保护莉莉安和核验信息提供现实基础。
- **卢卡斯的代价**：他的游戏知识失去确定性，只能作为待核验的旧地图；他不能靠一次笔记推演得到答案，也无法继续只以旁观玩家心态看待莉莉安。
- **莉莉安的收益**：被允许进入宅邸，获得南向客房、内锁钥匙、热水、食物与暂不讨论婚约的第一日缓冲；这些只是最低限度安全，不等于她已经相信斯托克顿家。
- **莉莉安的代价**：她必须进入一个完全陌生的家庭；虽然仍能准确判断事实与风险，却主动放弃未婚妻、客人与被照顾者的权利，暴露出她已把“保护别人”的唯一方案理解成尽量抹除自己。
- **艾尔伯的收益与代价**：驻军仍未撤，但他因接待职责缺席了莉莉安抵达，使婚约的第一轮现实后果由卢卡斯独自承接；回宅后仍需面对两个孩子，而不是把签约当作已经解决的问题。
- **萨拉的收益与责任**：她获得建立宅邸安全秩序的实际入口；同时必须在不强迫坦白、不擅自翻检私人物品的前提下处理饮食、洗浴、睡眠与可能的伤势。

## 结尾设定和钩子

- **结尾状态**：莉莉安已进入斯托克顿宅邸，在南向客房保留钥匙与行李，却尚未进食或真正休息；卢卡斯确认她是“游戏女主”，也确认游戏中的保护性固定剧情已经失效，但不知道原因；艾尔伯尚未回宅，蒂莉尚未与莉莉安见面。
- **未解决问题**：莉莉安在学院究竟经历了什么；断杖为何折断；玛琳事件中是谁填补了游戏里不存在的幕后位置；凯恩与塞西莉亚为何把她送进斯托克顿婚约；卢卡斯该不该、又该如何向她解释自己知道的未来；艾尔伯回宅后如何面对她。
- **短期期待**：莉莉安醒来后如何理解“不锁门、免费食物与客房”这些与她预期不符的规则；她会不会立即寻找工作或偿还方式。
- **中期期待**：卢卡斯如何在失效的剧本与真实莉莉安之间重建判断，并调查婚约背后的福克斯计划。
- **长期期待**：所谓游戏记忆为何会偏离；小巷里无名、通用画像的混混究竟是谁；那段记忆究竟是什么。混混身份只列为作者层长期伏笔，本章不让卢卡斯锁定方向。
- **章尾钩子**：回声钩子 + 关系选择 — 章首的卢卡斯相信自己记得大多数未来；章尾的他第一次主动合上写满未来的笔记，转身处理一个笔记无法解释的真实的人。期待度：强。
- **下一章承接**：下一章宜转回莉莉安第三人称限知，以醒来后的陌生客房、从内可锁的门、未经劳动便送来的食物和她对“必须有用”的迫切需求为核心；安排她与萨拉建立最初生活规则，并为蒂莉的无偏见初见留出独立情绪空间，不立刻展开福克斯政治线。
