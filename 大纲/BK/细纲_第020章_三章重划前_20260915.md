## 一、基本信息与验收契约

- **章名**：
- **篇内编号**：斯托克顿篇第十五章（全书内部020）；章名继续暂空。
- **题记**：不新增。
- **时间／跨度**：承019谈判结束后的当夜或次日，经过正式邀请、核验与关键防区交接，章内清楚跨入数周后的恢复期。前段不得把替防当日完成；后段用有标记的场景跳时，不以连续日记掩盖恢复与移交所需时间。
- **核心事件**：艾尔伯在仍受护理的状态下授权公开第008章会面后即已存在的格兰德短期替防准备；斯托克顿以合法邀请、教会驿传留档和公共道路通行把等待在福克斯领外的力量引入关键缺口。威廉可以核验和拖延，却不能再以“今日撤军即必有死伤”迫使领地屈服，最终只能在短期替防窗口下接受分阶段撤军、堡垒／哨所／防线移交的正式约束。数周后，领地与家人都只开始恢复，不写成已无后患。

- **章节定位**：结构危机解除／政治后果／恢复期过门。
- **目标情绪**：先让读者和人物重新看见北山真空的真实可怕，再以一份早已准备、但必须被正确调用的援手打开呼吸空间；胜利不来自谁压倒谁，而来自“不能再被当天的空缺逼着交出一切”。末段的安定带着疲劳、账目、空别墅与仍未被消去的偏见。
- **情绪弧线**：撤军压力下的冷硬窒息 → 旧信与保密的复杂揭示 → 每一步都必须有人承担的谨慎推进 → 替防真正到达关键缺口后的短促松气 → 把临时安全换成漫长移交责任 → 数周后仍有缺口、但终于能够料理生活。
- **章首钩子**：威廉把全面撤军说得像一项体面的合作终止；卢卡斯摊开北山图，看见任何一句强硬回答都填不满那一连串空白。
- **小兑现**：艾尔伯没有因病退出领地的选择，也没有神奇地重新掌控一切；他把早已承担的保密决定交给卢卡斯，并以仍有限的领主权力签出那封必须由斯托克顿发出的邀请。
- **视角与表达强度**：以卢卡斯第三人称限知为主；第一、九、十场可短切莉莉安限知，以恢复中的身体与日常位置承接政治结果。威廉、伊丽莎白和格兰德使者均不切内心。文书段要让人看见纸、时序、道路和岗位，而非长篇制度说明；释放后保留各种不完全的反应。
- **可选文风参照**：P3用于权力压到边线、道路和领民的具体后果；P4用于多人各做一项事时的紧张；R3用于公告后仍分层的民意；R4用于保护落成一份可执行的安排；D2用于数周后房间、饭食与工作重新有了位置。只取功能，不模仿整章。

## 二、内容概括与情节安排

### 五段式

- **起因**：威廉把切割后的合作关系转成全面撤军威胁。北山图、已有哨所与斯托克顿现有力量的空白让卢卡斯无法用气势回答；艾尔伯在病中确认，自己不能再把第008章后的准备只留在个人保密里。
- **发展**：艾尔伯以可追溯的格兰德待命文书、教会驿传留档与病中授权，向卢卡斯说明短期替防的存在与边界。卢卡斯据此核清：援军尚未越境，只有一封由斯托克顿合法权力发出的邀请能使它成为援手，而非新的越界力量。
- **转折**：正式邀请进入教会文书和公共道路体系。福克斯利用核验、安全与补给理由拖延，试图把“能否今日填缺”重新变成斯托克顿的软肋；但每一次拖延都留下可查时序，无法长期公开封死所有道路。等待多日的格兰德使者与队伍因此在文书抵达后才启程。
- **高潮**：格兰德短期替防真正到达并接住若干关键缺口，威廉失去立即撤军即可制造灾难的筹码。双方不庆祝胜负，而将争执收束到阶段、设施、责任和过渡期间的正式文书；福克斯只能接受不再能当天抽空防线的分阶段撤军与移交框架。
- **结尾**：数周过去，艾尔伯仅恢复到短坐办事，卢卡斯仍在修缮、账目和交接之间奔走。有限公告与东门后的生活让民意、旅游和家内位置各自松动一点。莉莉安重新坐回有人吃饭、有人算账、也有人仍会避开她的日常里；出口存在，却仍是一条要自己走完的路。

### 多线

- **主线／边防线**：撤军威胁真实成立 → 知情者解除保密 → 合法邀请和公共通行 → 短期替防进入关键缺口 → 分阶段撤军／移交框架成立。
- **权力线**：艾尔伯从单独负担旧日决定，转为在病中将可执行的权力交给卢卡斯；卢卡斯不替父亲越权，而是让每一个签署、转递、核验和交接都有来源。
- **福克斯线**：威廉保住上层可否认性，却失去把执行人和即时撤军都当作无代价手段的空间；他仍能在日后移交中制造摩擦，不能被写成彻底失败或失势。
- **调查／公开认知线**：执行人的直接行为从内部记录进入有限公告；这只压缩谣言的独占叙事，不封死上层证据断口，也不统一人群态度。
- **恢复线**：莉莉安先停工恢复、再接触低强度日常；艾尔伯逐步坐起；东门修缮和旅游询问并行，饭食、钥匙、房间和可被分配的时间重建“仍可住下”的现实。

### 因果链

019切割执行人但威廉重提撤军 → 北山真空不能靠调查胜利填补 → 艾尔伯不能再独自压住第008章后的格兰德准备 → 可追溯待命文书与病中授权使卢卡斯获得正当调用路径 → 正式邀请经教会留档进入公共道路体系 → 福克斯可延缓却不能长期公开阻断 → 格兰德力量在邀请后才抵达关键缺口 → “立即撤军＝即时死伤”的威胁失效 → 双方被迫把冲突转为分阶段撤军、设施与防线移交 → 数周恢复证明这只是开始承担自主边防的时间，不是结局。

## 四、逐场细化

### （一）地图上填不上的空白【详；1500字】

- **场景目标与冲突**：把019的政治小胜立刻放回真实防务容量，证明威廉的威胁不是一句可被勇气击退的话。
- **即时变化**：卢卡斯先想把切割文书当成压住威廉的筹码；北山图与岗位汇报却让他看见，即使不计福克斯的私心，斯托克顿也没有足够人手接住全部缺口。艾尔伯想坐起看图，被治疗者按回限制。
- **情节点**：
  1. 威廉的全面撤军意向／合作终止说法以已留的文书或转述摆在图旁【承019·中180】。
  2. 图上只标已有堡垒、哨所、巡防方向与需要承接的空白，不补人数、堡名或精确军制【边防事实·详300】。

  5. 艾尔伯听到“今天”与“空缺”后要求萨拉去取他一直未交出的封套【钩子·中220】。
  6. 治疗者限定谈话时长，迫使艾尔伯不能用长篇解释逃避关键决定【病情连续·中180】。

- **结果／接口**：地图留下，空缺未经粉饰；艾尔伯决定解除一部分保密，进入旧文书的揭示。

- **场景目标与冲突**：让格兰德替防不是惊喜底牌，而是艾尔伯早已承担、现在必须向卢卡斯说明的政治选择；同时划清它能做和不能做什么。
- **即时变化**：卢卡斯先以为父亲只是又留了一个未经商量的安排，随日期、驿传留档和“尚未越境”的内容才理解这不是代替他决定今日，而是为今日留下尚可选择的时间。艾尔伯必须承认自己既害怕失去儿子，也害怕把领地交给另一家。
- **情节点**：

### （三）谁签下这封邀请【详；1500字】

- **时间／地点／视角／在场**：同日稍后；主宅护理处与书房外可办事的桌面，卢卡斯限知；艾尔伯、萨拉、治疗者、卢卡斯，必要时加文短入。

### （四）道路必须留下一笔【中详；1350字】

- **情节点**：
