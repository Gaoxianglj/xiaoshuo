## 细纲（第 009 章）

### 第 009 章：我愿忘记

- **篇内编号**：斯托克顿篇·第 4 章。
- **标题系统**：与第010章《将此当作你我初次相遇》连读，保留原定完整句“我愿忘记，将此当作你我初次相遇”。本章的“忘记”不是抹除卢卡斯的未来记忆，而是他开始主动停止用记忆中的“女主角模板”替眼前的莉莉安作判断；他把宅邸里亲眼看见的选择、工作边界和真实反应放到更重的位置。完整含义在第010章湖上谈话中兑现。
- **承接关系**：承接第008章约三至五日后。莉莉安已在宅邸工作满一周左右，领到第一笔按实际工时结算的工资；临时帮工与送货人已有时间把“宅邸里没有见到未婚妻”的见闻带回南镇。
- **时间跨度**：约两日。第一日发现流言、商议与征得莉莉安同意；第二日清晨出发，完成南镇公开亮相、冬储核查和码头事故，傍晚抵达东村旅店。
- **核心事件**：福克斯执行人利用驻军补给与外围商队的流动，在南镇、东村和北村投放“平民、白发魔女、首都伤人、被赶出”四个稳定要素。卢卡斯征得莉莉安同意后带她进行三日公开走访。第一日在南镇核查冬粮和码头转运时发生真实事故，莉莉安在无杖状态下同时维持水流、风压和土石受力三种魔法，为镇民争取撤离与固定船只的时间。她救下人和冬粮，却也让镇民第一次直观看见她远超一般魔法使的精密控制，公共评价由单一传言分裂成感激、功利性认可和更深的恐惧。
- **字数目标**：约17000字，细化预算17800字，允许范围17000—18700字。
- **目标情绪**：从“被陌生人用传言定义”的不安，进入事故中清晰、紧迫的能力释放；救援结束后不做单纯扬眉吐气，而让同一场善举同时生出感激、物化与恐惧。章末回落为疲惫中的安稳，使读者明确感觉到：莉莉安虽然被看见了，却还没有真正被认识。
- **章节定位**：普通推进章 + 中段高压能力展示 + 公共矛盾升级章。外部压力由2级升至4级，事故结束后回落到2级；感情线不在本章完成转折，只积累第010章追问所需的现实证据。
- **主视角**：开篇至作出走访决定使用卢卡斯第三人称限知；抵达南镇、莉莉安下车公开亮相后切为莉莉安第三人称限知，并保持到章末。不得切入执行人或陌生补给人员的内心。
- **章首钩子**：认知反差钩子——卢卡斯在花园书房看见莉莉安将误混入公开回执的格兰德封蜡信原样挑出，并让蒂莉自己找到账目错位；随后他在南镇听见镇民用完全相反的词描述她。开篇不再用“第一、第二、第三”列举证据，而让两三个动作自然发生在同一段工作里。
- **核心收益**：莉莉安第一次在学院之外、面对普通人的真实危险使用强大魔法；她得到第一批不会被传言轻易抹去的直接见证者。卢卡斯则获得流言地点与驻军补给／外围商队路线重合的第一组书面记录。
- **章尾钩子**：变形流言钩子——两人抵达东村当晚，南镇事故已经被传成两种互相冲突的故事：“白发小姐救了码头”和“白发魔女徒手控制整片湖水”。一辆带驻军通行签的补给车比他们更早把后一种说法带到东村；卢卡斯在纸夹上记下抵达时间，随后划去翌日安排中可能要求莉莉安再次施法的一项，改记为雇工与停磨半日。

## 大纲五检

1. **情绪与模式**：本章交付“力量被看见后，理解与恐惧同时增长”。采用公共污名—真实工作—突发事故—能力释放—社会认知分裂的结构，不采用单纯打脸后集体改观。
2. **核心冲突**：卢卡斯需要让领民看到莉莉安本人，却不能把她当成澄清流言或展示武力的工具；事故迫使她真正使用能力，也迫使卢卡斯在政治收益与她的身体边界之间作选择。
3. **节奏**：宅邸与公开介绍中速铺压；冬储核查先建立空间、人物和受力条件；码头事故快速升压；救援后用镇民分层反应冷却；购物、赶路和夜宿只做恢复与关系积累。
4. **伏笔**：推进福克斯补给／联络网络、执行人观察莉莉安能力边界、第一批公共见证者、斯托克顿家魔力短板被舆论利用；不提前埋具体毒物或厨房手法。
5. **章节定位与承接**：本章拥有明确动作峰值，第010章则降低外部事故密度、提高关系和坦白比重。009解决“她能否被看见”，010继续追问“被看见是否等于被认识”。

## 内容概括（五段式）

- **起因**：卢卡斯在宅邸日常中继续积累对莉莉安的现实判断，随后在南镇听见高度同质的白发魔女流言。他记录最早听闻地点，发现它们与近几日抵达的酒、盐和驻军外围补给车路线重合。艾尔伯同意公开走访，却提醒卢卡斯：若只展示她的魔法，领民可能得到的不是安心，而是“男爵家藏着更危险武器”的印象。
- **发展**：卢卡斯向莉莉安说明三日领务路线、住宿、人手与拒绝权。她同意以未婚妻身份同行。抵达南镇后，卢卡斯不替她证明清白，只请领民观察三日内真实发生的事。两人依原计划核查冬粮、仓房与码头转运，莉莉安从重复编号、临时堆放和绳色混用中提出木牌与补签办法；卢卡斯同时发现一批外围承运人员使用与其他村落相同的流言措辞。
- **转折**：冬粮卸载时，受潮的系船桩被突然拔松，粮船横转，吊架重物摆向人群，栈桥支点同时开裂。普通值守魔法使只能维持一处支点。莉莉安判断三个危险会互相扩大，在没有法杖的情况下接连建立水流、风压和土石控制，并将其同时维持。
- **高潮**：三组魔法只把局势稳定到人类能够行动。加文撤人，卢卡斯组织船工换绳、下锚和卸载；当人已离开危险区、船工接住局面后，卢卡斯拒绝让莉莉安继续保护剩余财物，要求她立刻停止。她付出明显精神与身体代价，却没有昏迷。镇民随后以完全不同的方式解释同一场救援：有人道谢，有人议论婚约为了魔力血统，有人因她无杖同时施法而更加害怕。
- **结尾**：午饭、买衣和挑纪念品让紧绷逐渐松开。卢卡斯不替莉莉安回答吃什么、穿什么，也不把救援变成宣传。赶往东村途中，她试图计算因自己停手造成的损失，卢卡斯把人员、工期和调粮写入自己的责任。夜里，南镇事故的两种版本随一辆带驻军通行签的补给车先一步抵达东村。卢卡斯记录时间并修改第二日安排，莉莉安从门边看见纸上被划掉的“魔法协助”。

## 情节安排（多线）

- **主线推进**：莉莉安进入领地公共视野；执行人的流言首次遭遇直接经验，却借她真正强大的能力获得更危险的新版本。
- **危险暗线**：卢卡斯把流言地点与补给／承运路线第一次并列记录；敌方外围人员获得莉莉安“无杖、复数施法、持续时间有限、施法后感官迟滞”的观察信息。
- **领务线**：南镇冬储核查是原定任务。事故之后仍需追责腐朽系船桩、吊架检查和转仓标识，避免救援把治理问题一笔带过。
- **能力线**：先用账目、现场痕迹和流程判断解决日常问题，再在真正危机中使用复数魔法；魔法展示强调精密协同、物理限制和明确代价。
- **关系线**：公开牵手下车仍是身份表演；事故后卢卡斯主动放弃继续展示她、承担财物与工期成本，第一次为第010章“为什么对我这么好”提供不能被婚约礼仪完全解释的证据。
- **事件线 / 任务线**：发现流言 → 征得同意 → 公开亮相 → 冬储核查 → 码头事故 → 协作救援 → 态度分裂 → 赶往东村 → 新流言先一步抵达。
- **任务卡点**：卢卡斯原本只需完成冬储核查，卡点是突发事故将莉莉安从“可观察的未婚妻”变成“所有人都必须依赖的强大魔法使”；该卡点兑现能力、公共分歧、关系选择和敌方观察四项功能，事故结束后以设施追责和路线记录收束。
- **逻辑线**：标准化流言迫使公开回应 → 原定领务提供真实接触场景 → 真实事故迫使莉莉安施法 → 救人建立见证者，同时强化对其力量的恐惧 → 变形流言沿同一补给网络扩散。

## 人物关系和出场顺序

- **出场顺序**：卢卡斯 → 莉莉安 → 蒂莉 → 南镇临时帮工／送货人 → 艾尔伯 → 萨拉 → 加文·里德 → 未具名车夫 → 南镇镇民与仓房人员 → 南仓值守魔法使（匿名） → 外围补给人员（匿名） → 布店与手工摊人员 → 东村旅店人员。
- **卢卡斯—莉莉安**：从“共同应对关于婚约的公共问题”推进到“卢卡斯在她最有政治利用价值的时刻仍保护其停止施法的权利”；尚未完成信任或爱情确认。
- **莉莉安—镇民**：从纯粹传说变成拥有直接见证者的人；同时被一部分人进一步物化为血统资源、被另一部分人升级为真实威胁。
- **卢卡斯—领民**：他不要求领民因自己一句话相信莉莉安，也不借事故强迫全镇表态；继续以领务责任和公开记录维持权威。
- **视角／信息差**：读者可通过路线重合判断有人推动流言，但不知道执行人是谁；卢卡斯只形成怀疑，没有证据；莉莉安主要感受到舆论和卢卡斯的选择，不知道敌方正在记录她的能力边界。

## 情节细化与字数预算

1. 卢卡斯在花园书房处理公开回执；莉莉安挑出不属于权限范围的格兰德封蜡信，又让蒂莉自行发现数字错位。她遇见陌生帮工时换路，却不逃避应交的公开记录。未来记忆中的“开朗女主角”与眼前少女形成反差，卢卡斯不作结论，只把绿封信收回抽屉【现实观察·密900】。
2. 卢卡斯前往南镇核查仓门、冬粮与灯油清单，听见不同摊位重复同样四个流言要素。他询问最早来源，得到酒车、盐车和带通行签的承运车等答案，并在旧账页上记录地点与时间【流言起压／伏笔推进·密1200】。
3. 艾尔伯、萨拉与卢卡斯讨论回应。艾尔伯同意公开、可观察比闭门否认可靠，却提醒“展示魔法”可能把莉莉安变成更危险的武器；萨拉确认临时帮工确实没见过她，说明流言拥有可被利用的现实土壤【决策压力·密1000】。
4. 卢卡斯向莉莉安提出三日同行，交代南镇、东村、北村的原定领务、两夜住宿、加文和车夫随行，以及她可以拒绝。莉莉安担忧开支、名声和魔法需求，最终主动摘下兜帽同意；工资、食宿和同行义务仍分开处理【选择建立·密1000】。
5. 次日清晨出发。车内只安排三日走访所需互动：卢卡斯把路线纸交给莉莉安，允许她对停留和住宿提出意见；她选择不戴兜帽，却仍保留靠窗、可随时退回车内的位置。加文不清场，只处理车轮和人群安全【三日互动起点·铺垫750】。
6. 南镇公开亮相。卢卡斯介绍莉莉安是自己的未婚妻，不替她宣布无罪；面对“为何是她”，他把斯托克顿家的选择责任留在自己身上。莉莉安承受目光，并第一次以自己的名字而非“白发魔女”被公开称呼【公共冲突·密1200】。
7. 一行依原定任务进入南仓与码头，核查冬粮数量、潮损、转仓回执、吊架检查记录。莉莉安发现重复编号、临时堆放与绳色混用，提出补签和转仓木牌；卢卡斯则从承运标记、通行签和重复措辞中记下第一组补给路线关联。匿名外围人员在人群边缘观察【领务表演／危险伏笔·密1500】。
8. 卸粮前建立事故空间：满载平底船、主系船桩、备用绳、吊架摆动范围、栈桥裂口、仓门和撤离方向都清楚出现。值守魔法使只维持仓侧一个防潮／加固法术，提前显示普通施法者的专注边界【危机铺垫·密900】。
9. 系船桩拔松、船身横转、吊绳受侧向拉力崩断，粮袋摆向人群，栈桥支点开裂。加文先撤孩子和断绳附近人员；卢卡斯判断先救人、再稳船；值守魔法使明确只能顾住一处【危机触发·密1000】。
10. 莉莉安无杖建立三组魔法：水流沿船体反向推压，风压减慢粮袋摆落，土石／受力控制托住栈桥裂口。三者随船、绳和人群位置不断调整；句子与动作保持清楚，避免抽象描写。她只发出必要指令，让人类动作接上魔法创造的窗口【能力高潮·密2400】。
11. 船工换绳、下锚，仓工卸下危险货物，加文确认人员撤离。人员安全后仍有粮袋和一段吊架可继续挽救，莉莉安准备维持，卢卡斯却要求停止并接过后续损失。她出现眩晕、思考迟滞和距离误判，魔力本身仍充足；他不公开称赞，不许围观者要求追加演示，只把她带离断绳范围，让她坐下并减少周围声音与询问【代价兑现／关系推进·密1500】。
12. 救援余波形成三层声音：受救者与家属生硬道谢；有人议论斯托克顿家魔力弱、婚约是为改善后代；另有人因无杖复数施法产生“若她想伤人”的恐惧。匿名外围人员在事故记录完成前离场。卢卡斯让码头继续登记腐木、检查责任和修缮期限【认知分裂／伏笔·密1400】。
13. 午饭、布店、药草摊、手工摊与短暂同行作为事故后的恢复段。饮食只保留少量必要动作，不再反复用热水和点心表现照顾。药草摊主取出以淡紫静澜花制成的香囊，说明其幽香能帮助过度专注后的思绪恢复平稳；卢卡斯买下并交给莉莉安，她自行把细绳戴到颈间。随后保留灰蓝衣物、披肩、枫叶书签和带铜灯木船。血统流言在街角再次出现，使这些照顾无法被她简单当成浪漫【三日互动／长期物件建立·密1800】。
14. 马车赶往东村。莉莉安试图询问因她停止施法造成的粮食与修缮损失，卢卡斯将其写入领务责任。抵达旅店后，二人检查房门与住宿边界；带驻军通行签的补给车已把夸张版本传来。卢卡斯记下时间，修改次日磨坊安排，章末让莉莉安看见被划掉的“魔法协助”【承接第010章／章尾钩子·密1250】。

## 代价兑现与收益兑现

- **莉莉安的代价**：公开承受学院污名；无杖维持复数魔法造成明确精神和身体负荷；强大能力成为敌方可利用的新恐惧材料。
- **莉莉安的收益**：获得第一批能说出“我亲眼看见”的见证者；第一次体验魔法不仅能导致伤害或被学院评判，也能在普通人的劳动中争取时间。
- **卢卡斯的代价**：承担设施损失、停工、修缮和公开保护莉莉安的政治成本；主动放弃继续利用事故改善舆论的机会。
- **卢卡斯的收益**：取得流言地点、时间与补给路线的第一组关联记录，也更准确地认识莉莉安的能力边界。
- **后续账目**：南镇码头仍需换系船桩、检修吊架、统一转仓标识；公共意见没有解决，敌方已得到更具体的能力情报。

## 结尾设定和钩子

- **结尾状态**：三日走访完成第一日。莉莉安被南镇看见，却被分裂成“救命的人”“有用的妻子”和“更危险的魔女”三种版本。她与卢卡斯之间新增一项无法完全按婚约解释的事实：他在她最有用时让她停下，并愿意承担剩余成本。
- **未解决问题**：流言背后的推动者未知；补给路线关联只是怀疑；莉莉安不知道卢卡斯为何不继续利用她的魔法；东村和北村仍未走访。
- **章尾钩子**：信息变形 + 关系动作钩子，期待度中强。夸张流言先于二人抵达东村，而卢卡斯在纸上主动删去第二日的魔法需求。第010章由“他愿意为这道删除承担什么”继续。
