# 第012章原版剧情重写方案（Astra 试写）

## 验收契约

- `MUST_KEEP`：完整保留原版 012 的七段故事结构、事件顺序、角色决策、信息揭示与章尾文件异常；山坡谈话必须保留北山防务、威廉以撤军逼婚、卢卡斯承认隐瞒、莉莉安援引未来记忆并讲述“先被给予位置、后来又失去”的经历，以及她主动决定赴宴。
- `MUST_CHANGE`：正文措辞、动作组织、对白节奏与景物嵌入全部重新书写；增强细小动作对情绪的承载，使对话更像人物当场说出的话。
- `MUST_NOT`：不改正式正文；不改细纲与任何追踪文件；不新增超出原版 012 的关键事实；不提前解释三封信的幕后来源；不把临时帮工围裙的迟签与退订信强行并案。
- `TARGET_EFFECT`：前半段交付“熟悉日常里生出一道缝”的不安；山坡交付坦白后的疼痛与有限靠近；宴会交付不整齐但真实的接纳；章尾将温度收回到冷静、具体的风险记录。
- `CHARACTER_EMOTION_LOAD`：蒂莉由课堂疑惧转向以具体行动作答；莉莉安由等待别人安排转向自己决定出席；卢卡斯由替她筛选事实转向承认错误并把选择还给她；三人的变化均落在可见动作、对白和物件上，不写越过当前关系阶段的亲密。
- `STYLE_ANCHORS`：项目既定 008-C、006-A；另保留上一份 Astra 试写中已获作者认可的细节动作、自然对白与景物嵌入方法，但不沿用其改编剧情。
- `DOWNSTREAM_CONSTRAINTS`：叶包腌鱼最终留在书房窗边；宴后共七组取消、两组推迟；三封信只记录共同论证方式；第三名临时帮工赶倒数第二辆空车离开，围裙归还签名晚于离岗；次日长桌仍需继续使用。
- `ACCEPTANCE_TESTS`：单独文件位于 `试写/`，文件名以 `_Astra试写` 结尾；七个分节；双视角边界与原版一致，末节切卢卡斯；关键物件、门锁、工时与人员进出链闭合；无未关闭 S1—S3；正式正文哈希不变。

## 场景细纲

1. 蒂莉在节前最后一堂课上读到白发魔女，孩子们将教典形象套到莉莉安身上；她回宅邸时在厨房门口本能退了半步，最终与莉莉安一起叠缩坏的桌布。
2. 宴会物资逐日挤满厨房；萨拉在节前夜划掉莉莉安上午的工作，确认宴会末钟后她不再当帮工；蒂莉替她检查披肩与头发。
3. 感恩节清晨，卢卡斯带莉莉安去南山吃早餐；他从北山防务谈到逼婚真相，承认隐瞒；莉莉安说出她为何依赖可核算的工作关系，最终拒绝由别人代为解释，决定赴宴。
4. 莉莉安回宅后完成最后半日工作，交还钥匙和围裙，换装赴镇；工作物资、家庭菜品与教堂圣酒保持分流；第三名帮工的围裙暂未即时登记。
5. 教堂仪式结束，艾尔伯在主街正式介绍莉莉安；掌声与议论同时出现，卢卡斯让她与自己并肩走入席间。
6. 两人逐桌问候：仓管、磨坊与木匠以工作事实回应她；保守者保持距离；商人和向导带来退订消息；蒂莉用同一把夹子取食，以孩子能做到的方式表态；莉莉安最终在领主桌坐下。
7. 卢卡斯宴后核对退订、三封信和器皿登记；不把尚无证据的线索强行合并。围裙签名的迟误被圈起，窗边留下未吃的叶包腌鱼，街上传来为次日重新摆桌的声音。

## 写作边界

- 课堂神父只约束孩子的行为，不替莉莉安公开洗清嫌疑。
- 山坡谈话不写成完美互相治愈；卢卡斯只能承认、澄清责任与提供选择，不能消除真实损失。
- 宴席各桌反应必须混杂，同一群体也不整齐。
- 围裙登记异常只标为“晚记”，不推断操作者与目的。
