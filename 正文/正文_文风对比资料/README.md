## 本目录用途

本目录保存**文风对比与原始剧情参考**文件，不自动等于当前定稿正文，也不自动等于正向文风样本。

- 当前唯一正向文风底稿：`正文/正文MD/学院魔女_第一章_学院的新生.md`（新001，作者确认）。
- 作者2026-08-15确认：002—011最新进度原始版本作为**原始剧情参考**，旧版正文的整体故事走向获得认可；后续重写与新写可从中核对剧情、人物和事件顺序。
- 重写或新写时，文风必须遵守 `设定/文风.md` 与 `设定/文风锚点.md`，不得整章模仿本目录文件的段落切分、双否定排比、高频句式与解释习惯。
- 002—011当前内容基准路径已由 `追踪/章节索引.md` 指向本目录。

## 使用红线

1. 只取剧情、人物、事件顺序与锚点中注明的技法；不搬旧稿句式。

3. 本目录新增、替换文件时，同步更新本 README 与 `追踪/章节索引.md`。
4. 目前及之后无需生成 DOCX；本目录只维护 Markdown。
