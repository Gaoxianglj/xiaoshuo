# 连续性追踪使用说明

> 用途：补足 `追踪/伏笔.md`、`追踪/角色状态.md` 与 `追踪/时间线.md` 未覆盖的细粒度事实，防止次要人物、地点陈设、关键物件、知情边界与紧密时间线在跨章写作中无说明变化。

## 1. 与现有追踪文件的分工

- `追踪/伏笔.md`：未来需要推进或回收的叙事线索。
- `追踪/角色状态.md`：主要角色的身份、关系、能力与公众形象。
- `追踪/时间线.md`：事件发生顺序与时间跨度。
- `追踪/章节索引.md`：确定每章当前正文、细纲、快照与文风资格；选择文件时先查此表。
- 本目录：可复用次要人物、地点结构、陈设状态、关键物件流转，以及每章新增或改变的可核对事实。

同一信息只在最适合的文件中维护完整版本。其他文件需要时只写摘要与链接，避免多个副本互相漂移。

## 2. 需要记录什么

满足以下任意一项就进入连续性追踪：

- 次要人物有可辨认身份、稳定职责、独特动作或说话方式，并可能再次出现；
- 地点结构会影响人物站位、出入口、隐私、安全或行动路线；
- 物件会跨章存在，或涉及所有权、权限、秘密、伤势、关系照应；
- 一个细节如果改变，读者会合理追问“什么时候变的”；
- 信息涉及人物的知情边界，后续写错会造成越权知情。

一般不进入主表：一次性餐点、随手使用的普通杯碟、没有辨认特征的路人、无后续功能的临时杂物。它们可保留在章节快照中，不必长期升级。

## 3. 事实状态标签

- `【正文确认】`：正文明确写出。
- `【追踪确认】`：作者已经确认并写入追踪，但正文可能只作含蓄表现。
- `【合理变化】`：与前文不同，但正文交代了移动、替换或时间流逝。
- `【状态未写明】`：物件去向、人物身份或变化过程没有交代；后文不得自行补全。
- `【身份未定】`：两个相似称呼可能指同一人，也可能不是；没有证据时不得合并。
- `【待作者确认】`：会实质改变后续写法，需要作者裁决。

“没有写明”不等于“没有发生”。一致性检查只能指出空缺，不能替作者创造答案。

## 4. 内部编号

内部编号只用于项目文件，不进入正文。

- 次要人物：学院线使用`ACA-职责或地点-序号`，斯托克顿线使用`STK-职责或地点-序号`，例如`ACA-PRISON-01`、`STK-GRD-01`。
- 地点：`LOC-区域-名称`，例如 `LOC-EST-SOUTH-GUEST`。
- 关键物件：`OBJ-持有人或类别-名称`，例如 `OBJ-LIL-BROKEN-WAND`。

匿名人物复用时先核对编号。正文仍可继续使用“护卫”“仓管”“磨坊主”等自然称呼；但已确认空缺的职位不得仅为方便而临时补人。

## 5. 写新章前：连续性载荷

细纲完成、正文开始前，按 `模板_连续性载荷.md` 生成内部载荷。步骤如下：

1. 从细纲提取本章所有人物、地点、物件、伤势、服装、时间与知情事项。
2. 查 `次要人物.md`、`地点与陈设.md`、`关键物件.md`。
3. 读取最近一个相关 `章节快照/第XXX章.md`；必要时再用 `rg` 回看正文原句。
4. 对未具名人物作出“复用既有人物 / 新人物 / 身份未定”之一的明确选择。
5. 将“不知道就会写错”的信息整理为主线程本轮写作载荷；不拆分给其他 Agent。

连续性载荷是写作输入，不进入正文。若没有新章细纲，不提前建立带结论的载荷。

## 6. 写完后：先做逻辑与时空校验

正文完成后，先按`模板_完稿逻辑校验.md`建立或更新`完稿校验/第XXX章.md`，再建立章节快照。校验必须从实际落盘正文重新提取逐场景状态，至少覆盖：

- 时间先后、昼夜、季节、停留和路程耗时；
- 人物进入、离开、站位、门槛、门锁、楼梯与可见范围；
- 物件来源、持有人、位置、可触及性、开合、损坏和消耗状态；
- 人物姿势、双手占用、负重、伤势与能力代价；
- 知情边界、权限、动作因果和前后章接口。

相邻句也要检查动作前提。例如人物仍在门外，就不能在没有进门动作的情况下拿起屋内钥匙；物件已经收进上锁容器，也不能无过渡地出现在另一人手中。发现S1—S3必须先修改正文并复验，不能用追踪文件替正文补动作。正文哈希变化后，旧校验结论失效。

## 7. 校验通过后：章节快照

每章正文完成后，按 `模板_章节快照.md` 建立快照，只记录本章新增与变化：

- 新增或再次出现的次要人物；
- 人物声线、习惯、职责、知情范围与最后位置；
- 地点固定结构和本章结束时的陈设变化；
- 物件获得、移动、损坏、借出、归还或去向未明；
- 服装、伤势、季节、日期、行程与公开认知；
- 可自然回照、但并非必须回照的动作或物件。

快照完成后，再把真正会跨章复用的项目增量写入三张主表。不要把整章摘要复制进主表。

## 8. 两类检查必须分开

### 硬连续性

- 人物身份、外貌、职责、位置、年龄与关系是否冲突；
- 人物是否知道了不该知道的事；
- 地点结构是否无说明改变；
- 物件是否无说明消失、复原、换手或回到旧位置；
- 伤势、衣着、天气和时间跨度是否接得上。

### 柔性照应

- 当前场景是否自然碰到前文已有动作、物件或话语；
- 是否存在一次不费力的关系回照机会；
- 是否已经重复使用同一照应，反而显得刻意。

柔性照应属于 S4 提醒，不是错误。不得为了“有照应”强行搬出旧物或复述前情。

## 9. 严重度

- `S1`：明确硬矛盾，例如已毁物件无说明恢复、同一人物同时出现在两地。
- `S2`：人物声线、知情边界、职责或时间因果明显漂移。
- `S3`：陈设、服装、伤势、物件位置等细节无说明变化。
- `S4`：身份待定、状态未写明、可选照应或未来写作风险。

## 10. 维护原则

- 正文是已经发生之事的第一证据；作者明确确认可补充正文没有直说的状态。
- 行号会随改稿变化。正文回炉后，应更新对应快照中的来源位置。
- 匿名人物不得因为职责相近自动合并；同一岗位可以由不同人承担。
- 陈设允许变化，但变化必须符合时间和人物行动。连续性不是把房间永久冻结。
- 每完成五章或一个阶段，清理一次主表：一次性人物留在快照，重复出场者保留在主表。
