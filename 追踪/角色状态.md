# 角色状态快照

> 时间点：学院篇·第一幕结束。

## 第二章重写版阶段快照（春季至初夏，待作者确认）

- 莉莉安：开始适应学院路线与课程；仍警惕他人善意，但已接受玛琳的陪伴并主动约定同行；拒绝数次求亲，坚持继续学习魔法；获得免课考核资格。
- 玛琳：在莉莉安面前表现为自然、可靠且真诚的朋友；陪伴学习、分享食物、公开维护她，并接受她拒绝婚约的选择。正文不揭示任务或内心。
- 菲莱尔：对玛琳有无法具体说明的异样直觉，承认可能判断失误；莉莉安答应留意，但不据此推开玛琳。
- 艾尔文：通过偶遇与古老精灵语文献继续试探；仍无证据，也未作明确判断或逼问。
- 阿尔瓦 / 奥莉维娅：认可莉莉安的基础与控制力，给予免课考核资格。

## 第三章重写版阶段快照（夏季学期，待作者审阅）

- 莉莉安：通过奥莉维娅主持的免课决斗，获得基础课程免修与图书馆地下一层权限；在极限压力与浅伤刺激下进入阿尔维斯训练出的生死模式，无意识与精灵协同，叫停后才强行退出。她知道精灵曾降低环境响应门槛，拒绝把异常攻击当作可独立复现的个人技巧。奥莉维娅提出未来推荐其进入教廷直属魔法使团，莉莉安尚未找到“为何学习、将魔法用在哪里”的自主答案。她明知费尔德家与凯恩家存在债务关系及代请假的程序风险，仍以具体相处事实选择相信玛琳，邀请其入住并留下三位师长的程序记录。她已把玛琳纳入“家”，尚不知道其任务。
- 玛琳：已入住湖畔宿舍，与莉莉安共享饮食、笔记、缺口杯与脆弱时刻；在雨夜真实倾诉家庭债务、贵族体面与作为第三女的无力，隐去任务。莉莉安给过她“可以先告诉我”的坦白机会，她没有抓住。她对莉莉安的友情、依恋、恐惧和愧疚均真实；读者已知她受凯恩家胁迫，并刚得知塞西莉亚把计划扩大到地下室、锁链、持续伤痕和囚禁证词。
- 菲莱尔：承认决斗时精灵为莉莉安“推开门”，说明帮助越多、年长精灵约束越重；玛琳同住后停在窗外，因尚无可说明的证据而没有揭露她。
- 奥莉维娅：正式认可莉莉安的控制力与实战素养，亲眼见到她从学院考核切换为生死决斗；判断她需要重新学习如何退出战斗。提出未来推荐其参加教廷直属魔法使团选拔，但不替她决定魔法用途；同意玛琳请假并要求书面记录。
- 阿尔瓦：同意玛琳请假，提醒莉莉安不要因自认有责任而承担全部程序。
- 艾尔文：明确向莉莉安说明无本人陈述、家信和医疗记录的程序风险，以及费尔德家依赖凯恩家担保和借款的债务关系；没有玛琳参与阴谋的证据，仍予以放行，并提醒“相信她”和“替她承担所有后果”不同。
- 茉莉·凯恩：认可莉莉安的实力，知道自己短期无法达到；不因私人仇恨推动事件，而是服从凯恩伯爵意志。她把具体统筹交给主动请缨的塞西莉亚，在看到计划升级后提出异议，却最终没有否决，仍需承担默许责任。
- 塞西莉亚·福克斯：真正的具体策划者；已将玛琳伤痕、地下室、锁链、三位师长的程序记录与证人陈述组合成系统性陷害。她借执行计划换取凯恩伯爵人情，并暗示“退学并非最终目的”；已注意到玛琳可能动摇。

## 第四章重写版阶段快照（两周假期结束前后，待作者审阅）

- 莉莉安：在明知费尔德家债务风险和请假程序风险的情况下，仍相信玛琳会澄清事实并主动配合返屋调查。面对地窖伤痕与证词，她先试图治疗玛琳，随后持续把玛琳的行为解释为受胁迫；没有反抗暂扣法杖与关押。现被送入学院秘密监狱，尚未承认“背叛”，也无法联系菲莱尔。
- 玛琳：亲手分阶段制造伤痕、布置地窖、扣上锁环并完成半真半假的指控。她多次得到坦白与退出机会，仍因家族债务压力继续执行；在证词中没有把“你可以先告诉我”改写成威胁，并暴露一次看向塞西莉亚的短暂停顿，但没有翻供。
- 菲莱尔：已确认玛琳陷害事实；试图阻止并警告莉莉安时，被决斗后加重的精灵约束强制拖离木屋。亲近精灵也被隔离，与年长精灵的裂痕加深。
- 奥莉维娅 / 阿尔瓦 / 艾尔文：赶到现场后分别要求独立验伤、代理教师与单独询问，并指出债务胁迫风险；三人因请假审批记录成为利益相关者，被暂时排除出后续调查。
- 茉莉·凯恩：亲眼看见莉莉安被送往秘密监狱，承认费尔德家的债“会得到处理”，却无法说明具体保障，也没有叫停押送。
- 塞西莉亚·福克斯：通过公开举报、封闭提问、证据转义与审批者利益冲突完成现场叙事控制；已将莉莉安送入缺乏公开记录的秘密关押体系。

## 第五章重写版阶段快照（夏末至首个秋日，待作者审阅）

- 莉莉安：在秘密关押与半真半假信息侵蚀中逐步接受“玛琳接近的起点带有任务”，但仍能识破假细节并维护事实措辞；依靠精灵制造的最低限度机会自行越狱，以三日返山、废墟一夜、两日回程完成六日往返。木屋焚毁且师傅生死不明使童年火灾与“都是我的错”固化，她进入功能性解离后主动自首。她对外不透露师傅姓名、身份、经历、研究与住所细节。她签认罪书保护三位师长，又在塞西莉亚的信息操纵下放弃复核、接受与卢卡斯的私人婚约；法杖折断后多年第一次跪地失控痛哭，麻木被击穿，章末仍处于急性崩溃和反复触发状态。
- 玛琳：确认凯恩家正式兑现大部分减债、余款展期与两位姐姐婚约保障；在原宿舍不留自己的去向，只将母亲地址留作学院赔偿转付地址，并托茉莉转告母亲好好养病、按时吃药。她因此认定自己已尽完家族责任；未经莉莉安允许带走共用笔记，退学前往海滨。后悔、责任与占有同时存在，未获原谅；赔偿款在判决生效后再由学院转付给母亲。
- 菲莱尔：与亲近精灵迫使年长精灵允许“移除人为障碍”，只通过锁舌、辉石与环境声制造越狱窗口；未直接救援，也未能与莉莉安告别。
- 奥莉维娅 / 阿尔瓦 / 艾尔文：因莉莉安认罪及证据不足，被排除在伤害行为的共犯或知情责任之外，分别承担短期停职、书面警告与审批权限暂停、提交说明留档等较轻失职处罚。
- 茉莉：完成父命并默许塞西莉亚升级计划；正式判决前已无条件决定代付，在玛琳原宿舍说明学院转付赔偿的流程，判决后按原计划缴款，仍未撤销陷害或婚约安排。
- 塞西莉亚：完成心理侵蚀与私人婚约交易；借财物清单、收款地址、男爵已签婚约和师长复核申请窃取茉莉付款的因果。她没有及时识破看守的六日假报告；收买狱官、学院封存记录及婚约文件留下后续可追查痕迹。
