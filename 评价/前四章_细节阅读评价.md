## 阅读范围

- 第一章：`正文/第一章_学院的新生.docx`（当前正式定稿）
- 第二章：`正文/第二章_唯一的友人_重写版.md`

本评价以普通读者的连续阅读感受为主，编辑判断为辅。重点观察：是否需要回读、说话人能否辨认、场景或视角切换是否醒目、情绪是否顺畅、同类段落是否重复。

## 一、最先需要处理的问题

### 1. 第一章开头较慢，真正的故事钩子出现得偏晚

- severity: S2
  category: structure
  location: 第一章（一）开头至旅店早餐段
  evidence: “晨曦，刚刚升起的太阳……”之后连续描写阳光、起床、早餐和饮食感想，直到进城看榜后才出现白发身份带来的正面冲突。
  issue: 作为普通读者，我能读出文风和世界气氛，但前几页还不知道“这一章最值得关注的危险是什么”。第一章后面的桥区盘查、兜帽被掀、全班离场都很有效，反而衬得最开头进入主线较慢。
  fix: 不必删除旅店生活感，但可压缩晨光拟人和早餐内心说明，尽早让“今天放榜”“首位平民”“白发不能暴露”三个信息同时出现。

### 2. 第一章存在未明确标记的视角越界

- severity: S2
  category: structure
  location: 第一章（三），马车进入学院一段
  evidence: “在艾尔文眼中，与其说这里是学术的殿堂，不如说是权力的角斗场……”
  issue: 前文一直贴着莉莉安的感知，读到这里会突然进入艾尔文的判断；段落结束后又立即回到莉莉安。普通读者未必会明确说出“视角错误”，但会感觉叙述者突然知道了莉莉安不知道的东西。
  fix: 若坚持莉莉安限知，把这段改成她从艾尔文的言行中能观察到的内容；若确实需要艾尔文视角，应以分节作为清楚的视角切换。

### 3. 第一章的文风与后三章重写版存在明显代差

- severity: S2
  category: prose
  location: 第一章多处；对照第二至第四章
  evidence: 第一章常见“缓缓”“微微”“宛如”“些许”等修饰，并有较长的解释性设定段；第二至第四章更多用杯子、面包、笔记、动作和停顿承载情绪。
  issue: 连读时像从一版较早的轻小说稿，突然进入一版更成熟、克制的重写稿。人物还是同一批人物，但叙述声音不像同一本书。
  fix: 第一章后续若精修，优先统一句子密度、减少解释尾巴、保留最有效的物件与动作；不需要改变第一章事件结构。

### 4. 第三章从“第一次伤害”切到第二次、第三次，时间推进略显突然

- severity: S3
  category: structure
  location: `正文/第三章_决斗与暗流_重写版.md:785`
  evidence: “第二次是一本被水从内部浸透的课本。”随后 `:807` 又直接进入“第三次发生在去食堂的楼梯上”。
  issue: 读者能理解这是连续事件的 montage，但“第一次”并没有被显式命名，随后突然用“第二次”，需要回想上一场是不是第一次；三个事件之间究竟隔了几天也不够清楚。
  fix: 在第一起伤害结束处补一个简短的时间锚，或把“第二次”改为“几天后”；第三次同理，让升级节奏可被感知。

### 5. 第四章中后段程序问答很有压迫感，但持续太久后出现重复效应

- severity: S2
  category: structure
  location: `正文/第四章_背叛_重写版.md:761` 至 `:1465`
  evidence: 从主楼前初问、路上记录、木屋登记到地窖陈述，反复出现“提出事实—塞西莉亚换一种程序解释—记录官落笔”的循环。
  issue: 前几次非常有效，读者会真切感到“真实被重新命名”；次数太多后，惊惧感逐渐变成对流程的预判。我在地窖中段已经能猜到每一项生活细节都会被转义，后续问答的新增冲击下降。
  fix: 保留最致命的五到七个证据转义节点，压缩作用相同的追问；把篇幅留给玛琳的停顿、莉莉安认知的裂缝或师长被剥夺发言权的关键节点。

### 6. 第四章反复给玛琳“最后一次坦白机会”，边际效果逐渐降低

- severity: S3
  category: character
  location: `正文/第四章_背叛_重写版.md:91`、`:233`、`:345`、`:611`、`:691`
  evidence: “现在说也来得及”“有人在逼你吗”“如果里面是会害你的东西呢”“你真的不需要告诉我什么吗”“她甚至可以等莉莉安回来……”
  issue: 这些机会能证明玛琳不是一时误入，而是一次次继续选择；但写得过密后，读者会感到作者在反复加码证明她“确实有机会”，削弱自然生活的质感。
  fix: 保留性质不同的三次：一次主动坦白机会、一次物证差点暴露、一次已经进入地窖后的退出机会。其余合并或缩短。

## 二、对话辨识度与说话人

### 总体判断

两人对话大多能分清，尤其莉莉安与玛琳：莉莉安短、直、认真，常把玩笑当事实；玛琳更会绕、会打趣，也更主动填补沉默。艾尔文的懒散试探、阿尔瓦的规则意识、奥莉维娅的精确判断，也都有基本区分度。

真正需要注意的不是普遍性的“谁在说”，而是以下局部：

### 7. 第一章湖边的单边对话会让读者短暂以为漏了一句

- severity: S3
  category: prose
  location: 第一章（四）湖边，莉莉安连续说“嗯？我吗？”“嗯，住在那个木屋……”
  evidence: 对话对象的声音完全不呈现，直到后文才解释她在与精灵交谈。
  issue: 这是可以成立的神秘感，但第一句出现时读者还没有稳定建立“精灵能直接和她交流”的规则，容易回看上一段确认是否漏读。
  fix: 在第一句前加一个极轻的感官提示，如湖面光点靠近、脑海里响起细碎回应；不必直接替精灵写台词。

### 8. 第一章精灵首次正式出场时，说话人要到下一段才完全确认

- severity: S3
  category: prose
  location: 第一章（六）“莉莉安有必要低调吗？”
  evidence: 台词先出现，下一段才写“精灵从窗户飞进”。
  issue: 读者能在一行后确认，但由于场景刚从艾尔文办公室切回木屋，这句最初一瞬可能被误认作另一个已在房间的人。
  fix: 把“精灵从窗户飞进”的动作提前半句，或在台词中直接带出菲莱尔特有的动作。

### 9. 第四章程序角色的声线后半段趋同

- severity: S3
  category: character
  location: `正文/第四章_背叛_重写版.md:1491` 至 `:1637`
  evidence: 塞西莉亚、记录官、警务人员都使用冷静、完整、制度化的回答，例如“需要先回避”“正式讯问开始后可以申请”“决定由校务安全条例作出”。
  issue: 人物功能不同，但语言都像同一套制度在说话。带有标签时不至于分不清；连续去掉标签后，仅凭台词较难辨认。
  fix: 让记录官更机械地复述条文，警务人员更短、更命令式，塞西莉亚则保持礼貌、主动重构问题。三种权力声音可以更分明。

### 10. 有三处破折号打断依赖标点表达，格式上与当前重写稿规则不一致

- severity: S3
  category: format
  location: `正文/第二章_唯一的友人_重写版.md:451`、`:459`、`:649`
  evidence: “你们——”“可他们——”“那为什么——”
  issue: 读感本身清楚，但与当前项目避免使用破折号硬造停顿的规则不一致。
  fix: 若是被打断，用对方动作或下一句直接截断；若是自行停住，用短句和动作承接。

## 三、场景切换与时间切换

### 11. 第一章（四）到（五）的空间和视角切换清楚，但“切得很远”

- severity: S4
  category: structure
  location: 第一章（五）开头，转入艾尔文办公室
  evidence: 上一节还在湖边与精灵互动，下一节直接由萨兰递交试卷。
  issue: 分节标记足以让我注意到切换，因此不算看漏；但第一次从莉莉安切到他人视角，若章节版式里的“（五）”不醒目，读者会慢半拍。
  fix: 保证正式排版中分节标志醒目；第一句继续保留“院长”“试卷”等强定位词即可。

### 12. 第一章（十一）的茉莉场景定位稍晚

- severity: S3
  category: structure
  location: 第一章（十一）开头
  evidence: 先出现“接下来汇报有关莉莉安的情报”“女仆站立在侧”，之后才由“茉莉·凯恩用刀分割桌上的牛排”确认场景主人。
  issue: 这里不是完全看不懂，而是开头两句会让人先猜说话人，第三句才确认。
  fix: 首句即带出茉莉或凯恩家的空间特征，让读者无需暂存身份谜题。

### 13. 第三章（九）切到玛琳视角非常关键，分节有效，但最好强化一次“视角许可”

- severity: S4
  category: structure
  location: `正文/第三章_决斗与暗流_重写版.md:1419`
  evidence: “夜里，玛琳说要回原宿舍取选修作业。”随后跟随玛琳进入茉莉休息室，并直接呈现她的认知。
  issue: 我注意到了切换，也能理解其功能；但它是前三章第一次大规模向读者公开莉莉安不知道的真相，属于全书阅读契约的重要变化。
  fix: 保持独立分节；正式排版可用更醒目的空场或小标题。无需加解释性旁白。

### 14. 第四章（三）切入菲莱尔视角比第三章的玛琳切换更自然

- severity: S4
  category: structure
  location: `正文/第四章_背叛_重写版.md:413`
  evidence: 开头直接写“菲莱尔已经六天没有进过木屋”，随即交代其活动范围与约束。
  issue: 这里定位清楚，没有让我错过场景切换，是可供其他切换参考的写法。
  fix: 无需修改。

## 四、局部流畅度与重复

### 15. 第二章友情建立可信，但“陪伴—食物—占座—等候”意象出现较密

- severity: S3
  category: structure
  location: `正文/第二章_唯一的友人_重写版.md:47` 至 `:263`，以及 `:903` 至章末
  evidence: 苹果酥、温水、分食、预留座位、等午饭、白花；后段又有陪图书馆、取树叶、带去吃饭、面包、借阅证和“明天见”。
  issue: 这些细节大多好看，也确实让背叛成立。问题不是某一场差，而是连续累积后，部分细节承担同一种功能：证明玛琳愿意陪她、照顾她。
  fix: 不建议大砍日常；可删或合并一到两个功能重复的吃食/等待片段，把最有回照价值的白花、缺口杯、半块面包、预留座位留下。

### 16. 第二章求婚者段落的第三位人物几乎没有名字与外形锚点

- severity: S3
  category: character
  location: `正文/第二章_唯一的友人_重写版.md:679`
  evidence: “第三个人曾跟随叔父在骑士团生活，说话很有分寸……”
  issue: 前两位有名字和具体领地意象，第三位反而带来最有分量的“可以等她毕业”，却像概述中的功能人物。读者容易记住台词，记不住是谁说的。
  fix: 给一个最小辨识锚点即可：名字、徽章、说话习惯三者选一，无需扩写支线。

### 17. 第三章决斗动作清楚，但中段“可致伤方案”列举略多

- severity: S3
  category: prose
  location: `正文/第三章_决斗与暗流_重写版.md:335` 至 `:387`
  evidence: 膝弯、眼睛、握杖手、肺部依次成为可攻击窗口，并逐项解释后果。
  issue: 这段很好地说明莉莉安不是不会赢，而是不会在“比赛规则”中赢。不过连续列举四次后，读者已经理解机制，第四次的解释收益下降，决斗速度也被分析拖慢。
  fix: 保留两个最有代表性的窗口，再用一句概括其余被她主动拆除的杀伤路径。

### 18. 第三章奥莉维娅关于“魔法用在哪里”的谈话略接近主题说明

- severity: S3
  category: prose
  location: `正文/第三章_决斗与暗流_重写版.md:955` 至 `:1021`
  evidence: “不是你准备把它用在哪里”“不要让教廷、学院，或者你的师傅替你决定”等。
  issue: 主题重要，奥莉维娅的立场也成立；但这段连续给出完整、正确、成熟的回答，略有“作者借权威人物点题”的感觉。
  fix: 保留问题与奥莉维娅自身经历，少替莉莉安总结；让莉莉安之后的选择继续回答这个问题。

### 19. 第四章前半大量短段营造紧张，但局部出现“剪辑稿感”

- severity: S3
  category: prose
  location: `正文/第四章_背叛_重写版.md:123` 至 `:325`
  evidence: 多个一两句的短段连续出现，例如“第一天……”“第二处……”“当晚……”“第二天……”并夹入短动作。
  issue: 紧迫和隐瞒感是有效的；连续过久后，段落之间的空气感减少，像快速切过一组计划执行镜头。
  fix: 不要机械合段。只需在最重要的两三个节点延长完整的感官—选择—后果链，其余维持短镜头即可。

### 20. 第四章牢房结尾情绪准确，但“她一定是被逼的”重复三次稍显用力

- severity: S4
  category: prose
  location: `正文/第四章_背叛_重写版.md:1879` 至 `:1893`
  evidence: 同一句完整出现三次。
  issue: 重复本身符合创伤式自我说服；第三次的功能与前两次基本相同，部分读者会感到作者在替情绪加粗。
  fix: 可保留两次，第三次改用身体动作或被她拒绝回想的具体画面收束；若作者偏爱咒语式章尾，也可原样保留。

## 五、明确的优点（建议保留）

1. 缺口杯、白花、半块面包、胡萝卜汤不是装饰，而是在第四章被重新解释，形成了很强的情感回照。
2. 莉莉安与玛琳的对话声线大部分时候很好分。莉莉安的认真与玛琳的机灵让日常段落有生命力。
3. 第三章决斗的核心矛盾很独特：莉莉安不是力量不足，而是只受过生死训练，不会安全结束战斗。
4. 塞西莉亚最有效的地方不是“恶毒”，而是她能把真实事实放进另一套解释框架；反派能力与主题一致。
5. 玛琳没有被写成突然翻脸。她的真情、怯懦、债务压力和一次次继续行动同时存在，背叛因此真正伤人。
6. 师长们不是无能，而是每个人能做的事都被其曾经签下的程序反过来限制，这一点比简单的“学院黑暗”更有说服力。

## 六、建议的修订优先级

1. 优先统一第一章与重写版的文风、视角纪律和开头速度。
2. 压缩第四章功能重复的程序问答与坦白机会，但不要削弱关键证据转义。
3. 压缩第三章决斗中重复的杀伤路径解释，并给伤害升级段更清楚的时间锚。
4. 最后处理破折号、短段密度、第三位求婚者锚点等局部问题。
