## 二、信息边界

### 正文必须出现

1. 莉莉安与玛琳的日常友情逐步成立：同桌、图书馆、食物、散步、舞步、白花。
2. 玛琳由“装出来的棋子”转为“真正的朋友”的转折：一场当众羞辱。
3. 玛琳带给莉莉安的食物多来自食堂帮忙所得后厨份例，不是她花钱买的贵族餐食。
4. 古木法杖被嘲笑后，由阿尔瓦确认其工艺与价值。
5. 三名求亲者先后出现，莉莉安全部拒绝；玛琳作为介绍人，态度一次比一次复杂。
6. 艾尔文以旧文献试探精灵语；莉莉安装傻。艾尔文出身名门却不喜贵族精算，尊重她的选择，但本章不揭其家族与院长职位来源。
7. 菲莱尔对玛琳只有无证据的警惕；莉莉安与他约定：发现证据要先告诉她，不要伤害玛琳。
8. 阿尔瓦给予免课资格；奥莉维娅锁定一周后考核并要她带法杖。

### 正文不得出现

1. 玛琳是茉莉安插的棋子，以及她最初对莉莉安没有好感。
2. 玛琳在接受任务后仍定期向茉莉或凯恩家汇报。
3. 三次求亲由茉莉安排、玛琳负责接触撮合。
4. 艾尔文的家族背景、夜里听精灵语的习惯、精灵语真实造诣。
5. 阿尔维斯的姓名、身份、去向和莉莉安的精灵语能力来源。
6. 塞西莉亚、福克斯家、斯托克顿家、游戏主线、秘密监狱等后续内容。

## 四、分节细纲

### 第一节 同桌与食物（约2200字）

1. **延续约定**：玛琳在第一次课堂坐到莉莉安旁边。她的关心一开始过于周全，像把“成为朋友”当成一门需要满分的课。
2. **后厨份例**：莉莉安不再去昂贵食堂，玛琳开始带三明治、苹果酥和汤来。食物上贴着后厨的习惯：多给、不精致、有时冷掉。玛琳的借口一次比一次蹩脚。
3. **图书馆**：两人形成固定位置。玛琳坐不住，却会替莉莉安占座、压书页、推来温水。莉莉安从“允许她坐在旁边”变为“开始等她”。
4. **微小的真实**：一次玛琳说错莉莉安惯用的笔尖方向，又很快自己纠正。莉莉安第一次觉得，这个人好像真的在看她，而不是在背她的资料。
5. **节拍落点**：莉莉安多倒了一杯水，没有递过去，只放在两人中间。

### 第二节 当众羞辱与真正转变（约3000字）

1. **事件地点**：中央花园或宿舍区外的社交回廊。几名贵族学生认出玛琳的旧衣、改过的袖口，当众点破费尔德家欠债。
2. **玛琳的反应**：她先笑着圆场，越圆越糟；手指绞住袖口，眼圈发红，却没有立场发火。
3. **莉莉安站出来**：莉莉安本可走开。她走到玛琳身边，没有动手，只把羞辱者的话一句句问回去：衣服改没改，与成绩和为人有什么关系；费尔德家的账，又凭什么在这里被一个学生审判。
4. **朋友**：莉莉安当众把玛琳称为自己的朋友，并带她离开。她没有回头。
5. **玛琳的转变**：玛琳第一次没有用玩笑盖过去。她问“你为什么要管我”，莉莉安答“因为你在发抖”。从此玛琳的好不再只是熟练。
6. **节拍落点**：玛琳在没人的地方哭了。她没有让莉莉安看见。

### 第三节 白花与舞步（约2200字）

1. **白花**：玛琳送来一束路边的白花。莉莉安用墨水瓶养在木屋。她不问花语，只问明天它会不会蔫。
2. **缺口杯**：木屋只有一只杯子。莉莉安从杂货铺买来第二只，杯沿有缺口，便宜。玛琳第一次来时，莉莉安把缺口转朝自己。
3. **钟楼后舞步**：玛琳教莉莉安四步舞。莉莉安总踩错方向，第三次踩到玛琳鞋尖。玛琳笑着重新数拍。这是莉莉安第一次在学院做“没有用处”的事。
4. **夜路**：玛琳回宿舍，莉莉安送到主路。两人谁也没说明天还来。
5. **节拍落点**：木屋桌上多了一只带缺口的杯子。

### 第四节 法杖（约2600字）

1. **嘲笑**：实践课上，莉莉安的古木长杖被拿来与宝石短杖比较。学生们笑它粗糙、过时。
2. **玛琳维护**：玛琳从人群后挤到前面，说杖不是首饰。她其实不懂工艺，只是相信莉莉安。
3. **阿尔瓦鉴定**：阿尔瓦止住笑，确认古木年限、手工回路和收刀工艺，并说这种工艺在场无人能复现。
4. **莉莉安的过去**：莉莉安第一次说“这是我和师傅做的”。她不提姓名、地点和过程。
5. **玛琳记住**：玛琳看见莉莉安重新握住法杖时手指发白，记下“法杖对她很重要”。
6. **节拍落点**：下课后，玛琳弯腰捡起杖套的绳子，没有多问。

### 第五节 三次求亲（约2800字）

1. **玛琳提出**：玛琳说贵族女生毕业前会订婚，莉莉安可以见见，不好就拒绝。
2. **第一人**：边境男爵长子，介绍果园与蜂蜜。莉莉安问婚后能否继续上课，对方答可请家庭教师。她拒绝。
3. **第二人**：北方子爵之子，介绍河流、道路与温泉。玛琳对温泉动心，被莉莉安提醒“今天不是你来见”。莉莉安仍拒绝。
4. **第三人**：旧骑士家庭，胸前别银叶，说可以等她毕业。莉莉安沉默后说“不用等我”。
5. **玛琳的复杂**：她劝得很用力，又在莉莉安拒绝后明显松气。正文不解释，只写反差。
6. **节拍落点**：莉莉安把三份拒绝都说得温和。玛琳说：“那就不走。”

### 第六节 艾尔文与菲莱尔（约2400字）

1. **艾尔文偶遇**：艾尔文以晒太阳、喝酒、抱怨学院破败的方式出现，顺手用旧文献里的词试探莉莉安。莉莉安装傻，不接。
2. **艾尔文的态度**：他看出莉莉安不愿谈，不再逼问，只说“野蔷薇快开了，路不归我管”。他不像贵族那样精算，也不像教师那样训话。
3. **菲莱尔的警惕**：菲莱尔说玛琳身上有“水底突然泛起的冷”。它拿不出证据。
4. **约定**：莉莉安认真请求：如果以后发现什么，先告诉我；不要伤害她。菲莱尔不情愿地答应。
5. **节拍落点**：菲莱尔把光收成米粒大小，落在棋子旁。

### 第七节 免课资格（约2000字）

1. **阿尔瓦认可**：阿尔瓦在作业上写“基础课可免修，书单另附”，并说免课要考核，不是奖励。
2. **奥莉维娅锁日期**：一周后考核，带法杖。她不给范围，只说“不要松懈”。
3. **玛琳陪练**：玛琳替莉莉安递水、计时、念规则。她自己法术一般，却坚持到场。
4. **章末**：莉莉安发现自己开始期待考核时有人在结界外。她没说这是朋友。
5. **节拍落点**：“一周后，带你的法杖来。”她把书单折好，玛琳还站在门口。

## 五、人物状态与情绪曲线

- 莉莉安：从“接受一个人坐在旁边”走到“开始等待”；仍不定义友情，但行动已经先于语言。
- 玛琳：从棋子转为真心；对莉莉安越好，对任务的恐惧越深。本章只写表面矛盾，不揭底。
- 菲莱尔：醋意与警惕混合，但没有证据；约定成为第六章悔悟的核心钩子。
- 艾尔文：试探、让路、不越界。
- 阿尔瓦、奥莉维娅：给出认可与标准。
