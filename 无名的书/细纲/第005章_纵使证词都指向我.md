# 第005章 纵使证词都指向我 细纲

> 状态：与第001—007细纲同时建立，用于连贯性核对。不是正文。

## 一、写前锁定

- 章名：纵使证词都指向我
- 时间：夏末；两周假期后半至返课当日，从伪证执行到莉莉安入狱
- 主视角：莉莉安第三人称限知；玛琳、菲莱尔各一次短视角
- 目标字数：1.8万—2.2万字
- 档案题记：公开举报记录，或地窖勘查清单

## 二、信息边界

### 正文必须出现

1. 玛琳按任务页分数日制造伤痕并布置地窖；上层仍保留白花、两只杯子和两人共同生活痕迹。
2. 玛琳多次得到坦白和退出的机会，仍选择执行；每一次选择都由她自己完成。
3. 菲莱尔看见伪证，愤怒中真正试图杀死玛琳，被监视者阻止并限制接触。
4. 塞西莉亚公开举报，以请假记录、住宿登记、钥匙数量和地窖图纸构成程序压力。
5. 莉莉安因相信现场和玛琳会解释，主动带调查人员回木屋。
6. 地窖揭发时，莉莉安第一反应仍是治疗；玛琳说“别碰我”。
7. 证词用真实经历做骨架；玛琳把莉莉安因晚归而担心、轻微生气的那场戏，曲解成“被强制要求按时回来”。
8. 三位师长因签署过请假记录而被排除；莉莉安交出法杖，被送入秘密监狱。

### 正文不得出现

1. 塞西莉亚如何买通后续狱官；本章只写程序闭环。
2. 菲莱尔与执行者、长老的完整审议过程；只写他攻击被阻止、被带离。
3. 阿尔维斯的姓名、身份和木屋结局。
4. 越狱、婚约、斯托克顿领和福克斯家完整图谋。
5. 玛琳是否会在未来翻供；本章不暗示后续立场。

> 处置：由校务官、警备人员和记录官同赴现场查验。

## 四、分节细纲

### 第一节 任务页与早餐（约2600字）

1. **醒来**：玛琳醒来时，缺口杯已经被莉莉安洗净，杯沿转到不会硌到她的一边。杯底压着任务页。
2. **备用钥匙**：莉莉安看见玛琳把备用钥匙忘在桌边，重新放进她手里，说假期结束后也不必搬走。
3. **最后一次机会**：玛琳几次想开口，最终只问：“如果我晚一点回来，你还会留灯吗？”莉莉安说会。
4. **任务页**：莉莉安离开后，玛琳展开任务页。上面只有日期、位置、伤痕颜色和“会被谁看见”，没有解释。她把纸折得越来越小。
5. **节拍落点**：她把任务页压在枕头下，又把枕头翻过来。

### 第二节 伤痕与地窖（约4800字）

1. **第一道伤**：细绳压在她让莉莉安补过的袖口下。她数着时间，听见门外风声，吓得松手。
2. **被察觉**：莉莉安看见她拿汤匙时发抖，问“疼吗”。玛琳把手藏到桌下，说抄笔记太久。
3. **第二道伤**：她用粗糙木板制造肩背擦伤，痛到干呕。清洗地面时，她看见两人影子并排落在窗上，不敢抬头。
4. **第三道伤与家信**：家信说债期提前，担保人询问。玛琳把信折得过小，纸边割破指尖。莉莉安想用恢复魔法，玛琳拒绝，因为新伤会被看出时间层次。
5. **地窖布置**：玛琳移开冬储空箱，调暗辉石灯，放好锁链，把地窖钥匙推到够不到的位置。上层白花和杯子没有动。
6. **节拍落点**：她站在地窖第七级台阶上，很久没有迈下去。

### 第三节 菲莱尔失控（约2600字）

1. **菲莱尔短视角**：多日不进木屋的菲莱尔停在窗外，透过没拉严的窗帘看见最后一道伤、锁链和任务页。
2. **攻击**：菲莱尔真正对玛琳出手，光和热压向窗内。玛琳哭着说“对不起”，菲莱尔只停了一瞬。
3. **阻止**：一直监视菲莱尔的执行者拦下攻击，把它带离。阻止是必要的，但结果是莉莉安失去了唯一可能及时警告她的人。
4. **约定落空**：菲莱尔被限制接触，无法履行“发现证据先告诉莉莉安”的约定。他在树林边挣扎、咒骂，最终被带走。
5. **节拍落点**：莉莉安当夜只觉得窗外比平时安静，没有看见一点光。

### 第四节 公开举报（约3000字）

1. **返课日**：玛琳没有出现在教室。莉莉安替她收讲义，发现今天窗外没有任何精灵光点。
2. **教学楼前**：塞西莉亚带警务、记录官和数名见证学生等候。茉莉站在远处廊柱旁，不发言。
3. **宣读举报**：塞西莉亚清楚念出举报内容，语调平静。周围学生反应不一，但都让开了路。
4. **请假记录**：校务官出示莉莉安代办请假的三份记录，指出学院从未收到玛琳本人说明。
5. **无假选择**：塞西莉亚问莉莉安是否愿意配合前往住所。拒绝会立即成为阻碍调查；同意则由她带路。莉莉安说：“好。玛琳会告诉你们。”
6. **节拍落点**：前往木屋的路上，莉莉安想起艾尔文的警告，也想起锅里还留着汤。

### 第五节 木屋与地窖（约3600字）

1. **上层现场**：冷掉的汤、卷边白花、两套餐具、并排笔记。莉莉安有一瞬间松气，以为这些能替她解释。
2. **证据转义**：塞西莉亚逐项让人记录：两套餐具证明长期同住；莉莉安是登记住户；玛琳的课本和衣物证明她没回家；治疗材料证明莉莉安处理过伤势。
3. **钥匙**：记录官询问钥匙数量。莉莉安承认把备用钥匙交给玛琳，却无法当场出示；钥匙在地窖内。
4. **地窖门开**：湿土和铁锈味盖过汤味。莉莉安看见锁链和伤痕分层的玛琳。
5. **第一反应是治疗**：莉莉安指间亮起治疗光。玛琳后退说“别碰我”。莉莉安立刻停在台阶上。
6. **证词**：玛琳确认莉莉安主动邀她同住、代办请假。接着把“你晚归我会担心”和那次轻微生气，说成莉莉安强迫她按时回来，否则就到处找她。
7. **曲解核心**：莉莉安说“我当时只是怕你出事”。记录官写下的却是“当事人承认曾因受害者晚归而发怒并等候”。
8. **玛琳没有说出约定**：她没按任务页说出“你可以先告诉我”，在链环里收紧手指。
9. **节拍落点**：莉莉安问：“谁逼你的？”玛琳低下头，没有回答。

### 第六节 收押（约2600字）

1. **三位师长赶到**：奥莉维娅要求独立验伤、封存现场；阿尔瓦说莉莉安不会做这种事；艾尔文要求单独询问玛琳。塞西莉亚立刻指出三人都签过请假记录，属于利益相关方。
2. **程序排除**：莉莉安看见所有可能替她说话的人，都因为曾经帮她而失去资格。
3. **交杖**：莉莉安主动把法杖横放在掌心。杖被包进束魔布，她第一次觉得身边少了什么。
4. **秘密监狱**：押送路线远离教学区，经过没有标记的楼梯和从外开启的门。莉莉安没有公开姓名登记。
5. **半块面包**：牢房里，她把面包分成两份，一份放到空的一边，像玛琳还在。
6. **节拍落点**：黑暗中，她低声说：“她一定是被逼的。”

## 五、人物状态与情绪曲线

- 莉莉安：从相信现场到被证词反写，始终拒绝把玛琳直接命名为背叛者。
- 玛琳：亲手完成伪证，保留了一处没有说出口的核心私语；真实悔恨与责任并存。
- 菲莱尔：愤怒失控，被阻止后错失警告窗口。
- 三位师长：善意真实，却因程序利益冲突全部失效。
- 塞西莉亚：全程礼貌、克制，只问封闭式问题。
