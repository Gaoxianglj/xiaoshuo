# 第001章 我自远方而来 细纲

> 状态：章大纲已确认方向，本细纲供后续正文写作与审查使用。不是正文。

## 一、写前锁定

- 章名：我自远方而来
- 时间：故事开始年春末，入学前后数日
- 跨度：约三至五日，不写死具体日期
- 主视角：莉莉安第三人称限知
- 短视角：第六节末尾切茉莉一次，只写她读信与收信，不揭示玛琳
- 目标字数：1.2万—1.5万字
- 档案题记：教典“不祥之白”条文摘录，或入学名册残页

## 二、信息边界

### 正文必须出现

1. 春末教国的社会切面：播种、税册、农车、教廷人员、贵族车马。
2. 白发被教典与民间视为不祥；不同身份者对此反应不同。
3. 临时入学项链是全体考生共有的准考证式凭证，到校注册后统一交回。
4. 学院食堂是昂贵的西餐厅式点餐制，贵族学生很少去；玛琳在食堂帮忙。
5. 开学典礼上，茉莉统一安排了全班离席；包括玛琳在内共四十三人，离席整齐、沉默、无一人掉队。
6. 玛琳主动接近，态度过分熟练；莉莉安感到温暖，也隐约觉得哪里不对。
7. 艾尔文懒散、爱酒、帮人不热情；奥莉维娅偏行动和标准；菲莱尔与莉莉安是旧识，在学院重逢。
8. 莉莉安获得两把正门铜钥匙（其中一把备用）和一把地窖银钥匙。

### 正文不得出现

1. 玛琳是茉莉安插的棋子；玛琳最初对莉莉安没有好感。
2. 凯恩伯爵信件中不得出现玛琳的名字或任务安排。
3. 艾尔文的家族背景、院长职位来源、夜里去树林听精灵语的习惯，以及他对精灵语的高深造诣。
4. 莉莉安幼年在原初之地的完整经历、她能听懂精灵语的原因。
5. 阿尔维斯的姓名、身份、去向、研究或师徒生活细节。
6. 卢卡斯·斯托克顿、游戏主线、福克斯家后续图谋。
7. 学院秘密监狱、地窖的后续用途、越狱路线。本章只让莉莉安自然记住学院主要路线，不点破用途。

## 三、档案题记建议

> 见那白发的女人，她自深渊而来，冠冕上染着血。她的右手握着毁灭的杖，左手泼洒着硫磺与怒火。城门倾倒，城墙化为焦土，城中一切有气息的，尽都归于虚无。她站立在尸首堆砌的高山上，脚下流淌着罪人的血河。她向天举手，冷眼看那哀号遍地，却不施一分怜悯。凡有生命的，在她面前都如被践踏的葡萄，汁水流尽。祸哉！这城必成为荒凉，沦为野狗与飞鸟的居所。因为审判的时刻已到，再无一个义人得以存活。
> ——《圣典·灾异之书》

## 四、分节细纲

### 第一节 放榜日：从旅店到对岸（约2200字）

**场景任务**：写出莉莉安已经考完试、在旅店等待数日的状态，并借她去河对岸看榜的路线，让读者看见教国社会如何运转，同时带出白发成为公共事件的记忆。

1. **旅店清晨**：莉莉安已经在首都小旅店住了数日。她合上账本，数出房钱；若考中，钱要撑到学院第一笔补贴；若落榜，还要留出回家的路费。她愿意先看见老板娘少算的铜子，不过度换算成交易。
2. **等待放榜的街景**：春末，街道上农车、运种袋的平板车、教廷税吏和贵族车马混行。她戴上兜帽，沿已经走熟的路去河岸。
3. **城门记忆**：走过渡口前，她想起数日前初入城时被要求摘帽，卫兵看见她的头发后叫来同伴，周围的小贩和妇人纷纷后退。这段只作短回忆，不占现在时。
4. **过桥**：以临时入学项链通过石桥。桥头两个卫兵一冷一客气；项链上的学院纹章使放行速度加快。桥下河水把她的影子揉碎又拼起。
5. **北岸**：过河后街面安静，行人的目光不直接落过来，谈话声却在她经过时停顿。她朝放榜处走，没有再回头看南岸。
6. **节拍落点**：她重新系紧兜帽，像把一件会伤人的东西重新收好。

### 第二节 途中（约2000字）

**场景任务**：让莉莉安被“看见”，并借艾尔文之口把入学结果和新生代表身份交给读者。

1. **贵族区**：街道更宽，墙后有花园。园丁推车经过，车轮碾散她鞋底带来的泥印。
2. **草地冲突**：两名高年级学生拦路。风魔法掀开兜帽。白发暴露后，对方从玩笑转为恐惧，火球在掌心成形。
3. **莉莉安的选择**：她有七种拆解火球的方法，手已抬到一半，却松开。她选择不反击，不是因为软弱，而是因为一旦动手，“白发魔女”的罪名就有了新的证据。
4. **艾尔文出现**：一辆马车停在路边。棕发男人像刚睡醒，领口松着，用两句不冷不热的话让学生离开。他帮人没有热情，也不接受感谢。
5. **马车告知**：艾尔文告知她已被魔法学院录取，还是新生代表。莉莉安最关心两件事：精灵语试卷是否退档；典礼是否必须上台。前者得到“试卷存档”的答案；后者得到“可以拒绝，但代价会追着院长”的回答。她选择上台。
6. **节拍落点**：马车驶入林荫道。她把演讲稿的事压在心里，先记住了从校门到主楼的路线。

### 第三节 注册（约2200字）

**场景任务**：完成“临时凭证交回—正式新生身份确立—被隔离到湖畔木屋”的三步程序。

1. **主楼与队伍**：新生按家族、随从和行李分成不同等待方式。莉莉安独自排在队里，前后空出一段。
2. **注册台**：交回临时入学项链。接待员确认姓名、学院、宿舍。莉莉安拿到宿舍地图和钥匙。
3. **钥匙细节**：两把正门铜钥匙，形状相同，其中一把登记为备用；另有一把地窖银钥匙。莉莉安把三把钥匙分开放好，没有多问备用钥匙为何存在。
4. **前往木屋**：从主楼到湖岸，经过图书馆、食堂侧门、训练场外沿和两处不起眼的侧门。莉莉安自然记路，不点破这些路线以后会救她。
5. **木屋**：只有一个门。屋内旧、偏、有尘味。她打扫、开窗、铺床，没有清点出口，只确认门闩能扣紧。
6. **地窖**：银钥匙打开楼梯下的小门，只推开一条缝。潮湿凉气涌出。她重新锁好，没有下去。
7. **节拍落点**：天黑后她坐在唯一一张椅子上，把钥匙在灯下一字排开。铜钥匙两把，银钥匙一把。

### 第四节 湖与精灵（约1800字）

**场景任务**：让莉莉安第一次在学院里放松，同时写出她与菲莱尔的旧日重逢。

1. **湖边**：傍晚，莉莉安脱鞋浸脚。水很凉，她没有缩回。
2. **菲莱尔出场**：光点从水底浮起，绕着她转。菲莱尔叫出她的名字，语气亲昵又嘲讽，像多年未见却不肯承认想念。
3. **旧识重逢**：对话透出两人幼年相识，但不说“原初之地”四个字，也不解释分离。菲莱尔只说“我还以为你早被哪座城关起来了”。
4. **学院与家世**：菲莱尔指出学院只看姓氏和家族。莉莉安说：“我只要能上课。”菲莱尔嘲笑她，又落在她膝上。
5. **守夜**：夜里菲莱尔没有走，把光收成米粒大小，停在窗台旧棋子上。莉莉安没有赶它，也没有说谢。
6. **节拍落点**：她睡着前，最后一眼看见的不是天花板，而是窗台上一小点蓝光。

### 第五节 典礼（约2600字）

**场景任务**：写“被组织起来的排斥”。全章最重要的制度画面：包括玛琳在内的四十三人整齐离席。

1. **后台**：典礼前，奥莉维娅第一次出现，短发、语速快、说话像下命令。她告诉莉莉安：名字是成绩合议出来的，没人能划掉；如果有人为难，记下时间、地点和原话。
2. **上台**：礼堂很大，魔法学院四十三把椅子在右侧。莉莉安走上台，没有兜帽。
3. **四十三人离席**：没有起哄，没有拖沓。紫发女生先站起，包括玛琳在内的其余四十二人像排练过一样同时离席，从侧门列队离开。椅背弹回的声音断断续续。这种整齐比混乱更冷。
4. **四十三人全部离席**：右侧座位全部空掉，没有一个新生留下。莉莉安扫过那排空椅，记住了这种整齐。
5. **演讲**：莉莉安把讲稿念完。她看的是讲台上的一道木纹，声音从紧到稳。台下其他学院的人很安静。
6. **下台**：奥莉维娅在后台等她，没有安慰，只重复“记下来”。莉莉安把演讲稿折好，指节发白。
7. **节拍落点**：四十三人离席后，她的第一反应不是愤怒，而是“这样反而更简单”。

### 第六节 食堂与来信（约2500字）

**场景任务**：建立食堂这一小型制度空间，并让玛琳完成第一次接近；章末把凯恩家的命令推到台前，但不揭示棋子。

1. **空荡的食堂**：典礼后，其他学院的新生大多去参加社交聚会。食堂几乎没有客人。这里像西餐厅：侍者送冰水、毛巾、菜单；菜肴来自教国各地，价格昂贵。
2. **点餐**：莉莉安只点最便宜的面包汤。侍者态度不冷不热。她看菜单时，已经决定以后不再来。
3. **玛琳接近**：蓝发女生端着两个餐盘过来，说食堂人手不够，她来帮忙。她先坦白自己刚才也随众人离席，并解释：原以为听茉莉的话，就能拿到进入那个社交圈的请柬；直到最后也没有人邀请她，她知道自己进不去，所以来找莉莉安彼此依靠。她的动作太熟练，笑容太准确，还替莉莉安多拿了一份炖菜。莉莉安感到温暖，也觉得哪里不对。
4. **对话**：玛琳自报姓名，又重复了一遍“请柬”的说法：大家都走了，她若不跟着走，往后更不会有人邀请她；直到最后也没有人给她请柬。她知道自己进不去那个社交圈，所以来找莉莉安彼此依靠。莉莉安没有揭穿这个理由里的矛盾。
5. **约定**：玛琳说“下次上课，我还能坐你旁边吗”，又补了一句不锁死日子。莉莉安点头。
6. **回木屋**：菲莱尔说玛琳“气味不好”。莉莉安说：“我现在只看见她端来一盘炖菜。先信这个。”
7. **茉莉短视角**：房间里，茉莉拆开凯恩伯爵的信。信里只说：平民进入学院会破坏规矩，凯恩家不能沉默。信中没有提到玛琳。茉莉把信折进抽屉，又把成绩单压在上面。
8. **节拍落点**：窗外有夜鸟叫。茉莉没有回信，只把灯芯按短。

## 五、人物状态与情绪曲线

- 莉莉安：从“证明自己无害”到“被学院接纳”，再到“被四十三人同时排除”；对玛琳愿意先看善意，但保留一点说不清的警惕。全章不哭、不怒，情绪主要外化为系兜帽、看木纹、排钥匙等动作。
- 玛琳：任务在身，但正文不写。她的过度体贴是真假掺半的表演，读者可以感到“好得太熟练”。
- 菲莱尔：重逢的喜悦与对人类的嘲弄并置；对玛琳只有直觉。
- 茉莉：收到父命，不恨莉莉安，但服从。她事前统一了包括玛琳在内的全班四十三人，使典礼离席整齐如训练。
- 奥莉维娅：只给行动方法，不给安慰。
- 艾尔文：懒散、不热情、精准。

## 六、关键物件与伏笔

- 临时入学项链：进校凭证；注册时交回，后续不再出现。
- 兜帽与系带：本章至少三次出现，作为隐藏与暴露之间的动作线。
- 三把钥匙：两把正门铜钥匙（含备用）、一把地窖银钥匙。备用钥匙后续交玛琳；地窖钥匙后续服务第五章。
- 演讲稿：典礼后被折起。可留到后续章节做对照，不强行回收。
- 菜单：昂贵食堂的视觉证据；莉莉安此后不再来。
- 凯恩家来信：章末进入，但不提玛琳。
