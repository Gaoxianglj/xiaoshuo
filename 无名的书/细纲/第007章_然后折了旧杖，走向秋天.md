# 第007章 然后折了旧杖，走向秋天 细纲

> 状态：与第001—007细纲同时建立，用于连贯性核对。不是正文。

## 一、写前锁定

- 章名：然后折了旧杖，走向秋天
- 时间：夏末最后数日至当年第一个秋日；正式判决、退学、婚约、断杖、登车
- 主视角：莉莉安第三人称限知；玛琳或茉莉短视角一次
- 目标字数：1.5万—1.8万字
- 档案题记：学院处分决定摘要，或婚约文书残页

## 二、信息边界

### 正文必须出现

1. 莉莉安正式认罪，学院判处退学与赔偿；三位师长只以请假不合规受轻罚。
2. 玛琳退学；凯恩家兑现债务条件；玛琳只留母亲地址与养病口信，不接受原谅。
3. 塞西莉亚在正式判决后提出婚约，使用赔偿、法杖、师长复核和斯托克顿家已签婚约施压。
4. 莉莉安问对方是否自愿、斯托克顿家能否撤回；塞西莉亚只给签字文书。
5. 法杖在赔偿到账后返还；莉莉安回木屋收拾行李，法杖断裂。
6. 断杖后莉莉安跪地失控痛哭；门外人员催促。
7. 秋之精灵抵达首都，当天为第一个秋日；莉莉安登上去往斯托克顿领的马车。
8. 车夫递来写有“卢卡斯·斯托克顿”的行程单。

### 正文不得出现

1. 茉莉无条件代付赔偿的真相；莉莉安不知道，读者可在章末由茉莉短视角隐约知道，但不能让她与莉莉安信息连通。
2. 卢卡斯正面出场或任何斯托克顿家内部视角。
3. 福克斯家吞并斯托克顿领的完整计划。
4. 阿尔维斯的生死与木屋焚毁真相。
5. 玛琳前往海滨后的具体经历。
6. 莉莉安在断杖后“好转”或“释然”的暗示。

## 三、档案题记建议

> 查学生莉莉安，无姓氏。所行：伤害同学。所判：退学，并赔偿受害之人。
> 附注：此判由学院所定。赔偿未清之前，其个人财物暂行扣留。
> ——学院处分决定

使用说明：只作引文。

## 四、分节细纲

### 第一节 认罪与判决（约3200字）

1. **要求认罪**：莉莉安对校务官说，她愿意承认伤害玛琳。
2. **认罪书**：文书逐项列着限制自由、持续伤害、伪造请假。莉莉安知道有些不是真的，仍在“行为由本人实施、师长不知情”处签字。
3. **她不拖人**：她不提凯恩家、塞西莉亚和玛琳的任务。理由不是原谅，而是再查下去，三位师长和玛琳都会被更大的程序吞掉。
4. **判决**：退学、赔偿、内部留下罪名记录。三位师长只以不合规批准请假受轻罚。
5. **财物暂扣**：学院列出并暂扣她的财物，法杖在赔偿结清前不得领回。
6. **节拍落点**：莉莉安签完最后一页，笔尖在纸上停了一下。她问：“师长们不会再被追查了，对吗？”

### 第二节 玛琳退学（约3600字）

1. **玛琳短视角**：凯恩家的条件兑现：大部分债务免除，余款展期，两位姐姐婚约获保障。
2. **取物**：玛琳回木屋附近或原宿舍取个人物。缺口杯和白花已作物证收走；她只能带走获准归还的书和笔记。
3. **退学文书**：玛琳以“家庭与健康”为由退学。她没有见莉莉安。
4. **茉莉与地址**：茉莉告知：正式判决后，赔偿会由学院转付，需要收款地址。玛琳只留母亲地址，并请茉莉转告母亲好好养病、按时吃药。
5. **责任结算**：玛琳确认家里的事已经了结，于是决定不再回费尔德家，也不留自己去向。
6. **没有原谅**：玛琳不接受茉莉的安慰，也不说自己后悔。她只把莉莉安的笔记压进行李最里面。
7. **节拍落点**：列车开动，站台上没有人为她送行。

### 第三节 婚约（约3600字）

1. **塞西莉亚单独出现**：正式判决后，她避开学院记录见莉莉安。
2. **第一项材料**：财物清单。赔偿未清，法杖继续被扣，估价像一把悬着的刀。
3. **第二项材料**：玛琳母亲的收款地址。塞西莉亚把“赔偿需要结清”与“母亲需要医药”并排放在一起。
4. **第三项材料**：斯托克顿男爵已经签字的婚约。她说，一个陌生家庭已经为她承担了名誉风险。
5. **第四项材料**：三位师长的复核申请。塞西莉亚说，若想让他们停手，她需要一个理由，比如“自愿结婚、离校生活”。
6. **莉莉安的问题**：她问卢卡斯是否自愿，斯托克顿家能否撤回。塞西莉亚不答第一问，只把签过字的婚约推近。
7. **签字**：莉莉安先签放弃复核，再签婚约。两次签字，两层代价。
8. **节拍落点**：塞西莉亚收走文书，只留下行程单。

### 第四节 取回法杖（约2600字）

1. **赔偿到账**：茉莉经学院转付赔偿。莉莉安不知道钱的来源，只知道账已经清了。
2. **财物返还**：法杖仍裹着束魔布，被送回湖畔木屋。
3. **空屋**：白花、缺口杯、玛琳的衣物都不在。桌上只有封存后的浅色方印。
4. **触碰法杖**：莉莉安拆开束魔布，轻触杖身。杖身没有声光，安静地断成两截。
5. **节拍落点**：她先看断面里的灰白木粉，又想把两截重新对上。

### 第五节 断杖与痛哭（约3200字）

1. **崩溃**：莉莉安抱着断杖跪倒，先压着声音，后来再也压不住。
2. **不是释放**：这是麻木防线被击穿，不是“终于允许自己脆弱”。呼吸、吞咽和手指失去顺序。
3. **门外催促**：警务人员敲门，要求她尽快收拾。每敲一下，她的呼吸就再乱一次。
4. **保存断杖**：她不是恢复后才收拾，而是在视线模糊中，凭多年习惯把两截断杖用布分开包好，放进旧箱。
5. **旧衣与残页**：破损校服和师傅残页与断杖放在一起。
6. **节拍落点**：她跪在地上，像要把所有力气都哭完，却知道哭不完。

### 第六节 第一个秋日（约2400字）

1. **秋之精灵抵达**：风变凉，学院树叶短时间染上金红。这是首都当年的第一个秋日。
2. **离校路线**：莉莉安沿湖岸、训练场、图书馆外和大礼堂走。每处只用一个画面触发，不展开回忆。
3. **白发不再遮**：她无力再维持兜帽。白发露在秋风里，不是接纳，是力竭。
4. **无人送行**：菲莱尔远远跟到校门，不能现身。师长们没有出现。
5. **登车**：车夫催了两次，莉莉安才抱起旧箱。车夫递来写有“卢卡斯·斯托克顿”的行程单。
6. **节拍落点**：马车驶过第一片落下的秋叶。她把行程单按在断杖上，没有回答。

## 五、人物状态与情绪曲线

- 莉莉安：认罪时还有精确的“保护谁”的意图；断杖后进入急性崩溃，但保存断杖、不拖累他人的本能仍在。
- 玛琳：退学、离校、未获原谅；她的责任在本章被家人结算，却不被自己结算。
- 茉莉：完成父命，也作出补偿；补偿不推翻责任。
- 塞西莉亚：完成婚约入口，不露胜利，不揭福克斯终局。
- 卢卡斯：只有文书和行程单上的名字。
