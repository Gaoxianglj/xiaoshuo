# 第006章 我仍要回灰烬里看一眼故乡 细纲

> 状态：与第001—007细纲同时建立，用于连贯性核对。不是正文。

## 一、写前锁定

- 章名：我仍要回灰烬里看一眼故乡
- 时间：夏末；秘密关押、攻心、越狱、返山、自首，均不进入秋初。秋天的第一天属于第007章。
- 主视角：莉莉安第三人称限知；菲莱尔短视角一次
- 目标字数：1.8万—2.2万字
- 档案题记：内部牢房日志残页，或越狱后封存令

## 二、信息边界

### 正文必须出现

1. 塞西莉亚的攻心建立在可核查事实上：玛琳接近确有任务、费尔德家确有债务、三位师长确在受审；假细节能被莉莉安识破。
2. 莉莉安在长期隔离中仍保持判断，但“玛琳是否完全只是被迫”的解释被逐渐拆开。
3. 菲莱尔从愤怒中清醒，意识到自己违背约定，暗中创造最低限度的越狱机会；推门、选路、离开仍由莉莉安完成。
4. 莉莉安依靠自己的观察、体力与训练越狱，没有法杖。
5. 她返山发现木屋已焚，找不到阿尔维斯的尸体，也无法确认其生死。
6. 莉莉安主动返回学院自首；学院早已发现越狱并秘密搜捕，此时封锁消息，对外维持“从未离开”。
7. 莉莉安被重新关押，最后要求见校务官：“我要认罪。”

### 正文不得出现

1. 木屋焚毁的真相与纵火者。
2. 阿尔维斯是否存活、去向与教廷秘密研究。
3. 塞西莉亚知道越狱；本章明确她不在知情链中。
4. 学院对看守的后续处分、搜捕人员身份与内部高层全貌。
5. 卢卡斯、婚约、斯托克顿领。
6. 精灵长老与执行者的完整争论；只通过菲莱尔的行动和限制状态表现。

## 四、分节细纲

### 第一节 塞西莉亚的攻心（约4400字）

1. **牢房状态**：莉莉安被关在没有窗的牢房，时间感混乱。她仍把食物分成两份。
2. **第一次单独谈话**：塞西莉亚带来一把椅子、一杯水。她先让莉莉安喝水，再开口。
3. **真相层**：玛琳接近她确有任务；费尔德家的债务确实由凯恩家控制；请假和地窖确有人预先安排。
4. **假细节**：塞西莉亚说玛琳每天对镜练习证词、计划成功后庆祝。莉莉安指出木屋没有镜子、时间对不上，证明自己仍有判断。
5. **关键重写**：塞西莉亚承认细节记错，但反问：你能否认“接近的起点带有任务”吗？莉莉安不能。
6. **责任的刀刃**：“没有选择”不能抹掉玛琳亲手制造伤痕、扣锁、作证。塞西莉亚不替玛琳定罪，只把这句话放回莉莉安心里。
7. **留下问题**：塞西莉亚离开前说：“你可以继续相信后来是真的。”莉莉安把杯子转到没有缺口的一侧，发现那不是木屋的杯子。
8. **节拍落点**：她第一次说不出“全部都是他们逼的”。

### 第二节 菲莱尔清醒（约3000字）

1. **菲莱尔短视角**：被限制多日后，愤怒消退。他想起自己曾答应莉莉安：发现证据，先告诉她。
2. **违约的自责**：他差一点杀死玛琳，既制造了不可逆风险，也亲手关上了警告之门。
3. **不能传话**：限制未解除，他无法把真相送到莉莉安耳边。
4. **最低限度帮助**：菲莱尔开始寻找边缘机会：让锁舌没有完全咬合，让辉石灯短暂失效，让巡逻者被别处的水声引开。
5. **边界**：他不规划路线，不屏蔽追兵，也不替莉莉安决定逃跑。门只开一条缝。
6. **节拍落点**：墙外精灵光点暗下去。锁舌轻轻弹开，又合上一半。

### 第三节 越狱（约4000字）

1. **察觉异常**：莉莉安发现门锁、灯光和巡逻的巧合。她没有立刻走，先判断是不是诱捕。
2. **测试**：她用碗边测试锁舌，观察两轮巡逻，确认暂时没有埋伏。
3. **逆行路线**：莉莉安回忆被押送时经过的无标记楼梯、三道门和巡逻间隔。她依靠阿尔维斯的训练，选择通风口、旧工具和门轴间隙。
4. **体力代价**：没有法杖，身体虚弱。每过一道门都像拆自己一次。
5. **出口**：她离开学院，没有惊动任何人。她不确认是否精灵相助，只把异常当作“必须现在走”的信号。
6. **节拍落点**：出城后，她朝北边的山走，一次也没有回头。

### 第四节 灰烬（约5200字）

1. **三日返山**：用短程货车、野外取水和废弃棚屋压缩行程。她仍能辨认水源和旧路，但身体在变慢。
2. **异常**：靠近隐居地时，旧路标被人移除，小径上有车辙和灰烬。她开始跑。
3. **废墟**：木屋只剩焦黑骨架。她先做检查：有没有尸体，有没有打斗痕迹，火从哪里起。
4. **不确定**：她找不到能确认阿尔维斯死亡的证据，也找不到他还活着的证据。她只对读者保留“生死不明”。
5. **三件遗物**：陶碗碎片、垫过的椅腿、带批注的笔记残页。每件都连接一个具体生活动作。
6. **灰中的木屑盒**：制杖时剩下的木屑盒已经空了。她想起自己的法杖还在学院。
7. **旧认知闭合**：她把玛琳、三位师长、养家和木屋连成同一句话——“靠近我的人都会付出代价”。她低声道歉，抹掉自己的脚印。
8. **节拍落点**：清晨，她把陶片放回灰里，决定返回学院。

### 第五节 自首与隐瞒（约3800字）

1. **两日回程**：鞋损、两次日落、最后一次换水。她不再躲城门与巡查，直接回学院。
2. **学院反应**：校务人员认出她后，先封锁校务岗，通知秘密司法负责人，让秘密搜捕停止。
3. **隐瞒口径**：学院不公开越狱，以免“白发魔女逃脱”引发恐慌，也避免秘密监狱和看管失败曝光。他们封存六日记录，对外维持“从未离开”。
4. **塞西莉亚不知**：塞西莉亚因主动数日不探视、不要求每日汇报，且不在搜捕知情链中，不知道越狱。
5. **重新关押**：莉莉安回到牢房，不再争辩，只要求见校务官。
6. **节拍落点**：她说：“我要认罪。”门外传来记录本打开的声音。

## 五、人物状态与情绪曲线

- 莉莉安：从“还能识破谎言”到“无法否认起点是假的”，再到“唯一归处成灰”。她主动自首不是英雄行为，而是绝望中的止损。
- 菲莱尔：从冲动到悔悟，只能撬门，不能代走。
- 学院：因自保而隐瞒，形成新的制度之恶。
- 塞西莉亚：攻心有效，却不知道越狱，为第七章婚约留下信息差。
