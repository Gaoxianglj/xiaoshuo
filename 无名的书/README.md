## 工作顺序

1. 先完成 `篇大纲_学院魔女篇.md`；
2. 再完成 `章大纲/` 下各章大纲；
3. 作者逐章审阅，确认后生成对应 `细纲/`；
4. 全部细纲完成并复核后，再逐章生成正文 Markdown；
5. 正文文件名、章节编号和最终章名以后续确认为准。

## 章大纲统一格式

每章大纲必须单列“信息分层”：

- **正文中应出现**：读者可以在正文中直接看见、听见或推断的内容。
- **背景设定（读者暂不直接知晓）**：只供作者与后续写作使用，不得以旁白、内心独白、对话或题记泄露。
- 判断标准：如果一段信息会让读者提前知道角色不知道的事，就属于背景设定。

## 时代与语感

- 世界参考中世纪晚期至文艺复兴早期的欧洲。
- 宗教、学院、贵族、市镇与乡村的器物、衣饰、饮食、称谓和行政文书均向这一方向靠拢。
- 正文避免现代中文口语、成语套话与网络词。
- 档案题记采用圣经—教会公文的语感，不用文言骈句。
