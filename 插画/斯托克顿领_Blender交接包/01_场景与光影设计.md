# 场景与光影设计

## 1. 镜头目标

观众站在南侧半山的林缘草坡，透过清冷晨光看到山下的湖泊与城镇。一天过去，光线爬过山脊、屋顶和收割后的田地；傍晚，西光擦亮草尖，湖上渔船返航。夜里山体沉下去，南岸的家灯与船灯留下少量温暖亮点。

主角是光照变化中的领地。画面自然、安静、有生活痕迹；优先展现森林体积、远山空气透视、水面反射和旧材质，不做游戏宣传片式飞越镜头。

## 2. 已确认设定：必须保留

| 项目 | 约束 |
|---|---|
| 地理 | 盆地，中心是一整片面积不小的湖；四周环山，森林丰富 |
| 北面 | 山势相对平缓，边界长；有灰石堡垒、砍伐带、木哨塔，不能变成一夫当关的雪峰 |
| 居民 | 主要人口集中在南岸城镇，其余村落散布湖畔 |
| 南岸 | 旧屋顶、教堂尖顶、两座公仓、码头、石路和收割后的田地；主街从码头通向教堂 |
| 经济面貌 | 勤俭的边境农林领地，近年发展狩猎旅游，有湖边度假别墅，但整体不是富庶王都 |
| 机位地点 | 南侧半山，林道通向林地与草坡交界；有风雨磨平的大石，没有围栏或屋舍 |
| 视野 | 从草坡能俯瞰湖、南岸城镇、公仓、田地、码头与返航船灯 |
| 秋景 | 黄草、秋叶与仍深绿的森林并存；避免所有树同时变成纯橙色 |

北境设施可成为极小的远景轮廓。第012章明确深秋落叶后更容易望见，不能为展示堡垒而砍空本片的森林。安娜墓的具体方位未定，本片不安排墓地；精灵光轨不是永久航标，本片不安排魔法光路。

## 3. 制作假设：仅用于本片

以下均非作者确认的地理数值或新增剧情。可在构图不成立时调整，并写入制作记录。

- 时间选择有明显秋色、仍保留较多树叶的一个普通秋日，不指定为某一章发生的那一天。
- 采用自然写实的 3D 材质与克制的电影调色。已有第008章插画是日系插画方案，本片只提取其中的地理和生活意象，不继承描边、动漫人物及高调白金色照明。
- 默认没有莉莉安、卢卡斯或其他前景人物，也不放他们的布包、食物等私人物件。远处居民可以省略。
- 傍晚安排七艘小渔船从湖东分散返回南岸，每艘一盏暖灯，呼应008的场景。七艘是本次动画调度，不代表领地总船数；不要求从早到晚七艘始终可见。
- 晴到少云，破晓湖面有薄雾，中午消散，傍晚少量炊烟；无暴雨或季节转换。
- 夜晚以少量天空散射光保留轮廓，月亮不必入画；不确定天文设定时不添加巨大月亮、双月或醒目的星座。

## 4. 地形与机位草案

采用米制，Z 向上，+Y 为北、+X 为东。中心湖心为 (0,0,0)，湖面高度 Z=0。以下尺寸是工程初值，不是精确地图：

- 湖面东西约 2600 米、南北约 1800 米，岸线不规则，不做完美椭圆。
- 南岸城镇约在 Y=-1000 米附近，随岸线弯曲，地面高于湖面；田地向南侧缓坡延伸。
- 相机初始位置约 (0,-1750,230)，朝向约 (0,150,30)，在局部草地上方约 1.6 米。移动地形使脚下站位成立，不能把它做成悬空无人机。
- 东西远山可比北山更有起伏；高度依据构图微调，山脚与湖岸必须衔接。
- 相机以全画幅 35 mm 焦段开始试拍，可在 28—40 mm 内调到既有空间感又能看清南岸。锁定后全片不移动、不推拉、不换焦。
- 从南向北看：画面左侧是西，右侧是东。日出光从右侧来，日落光从左侧来；太阳圆盘不必入画。不能为同时拍到日出日落，把太阳横穿北天。

构图比例为目标而非机械切割：天空约上方 20%—30%；远山与森林构成中远景；湖面是最大连续留白；南岸城镇落在下方中景；近景草坡、大石和少量枝叶占底部约 10%—20%。不能让近景遮住城镇或让湖缩成小水塘。

先用灰模确认湖泊、城镇、大石三者可辨，再加细节。必要时调整相机与湖岸尺寸，不靠夸大建筑数倍挽救构图。

## 5. 材质与细节优先级

1. **湖水**：安静的淡蓝灰或深青灰水面；细微、连续的波纹打散倒影，远处趋于平滑。岸边可有有限的浅水层次。避免海浪、镜子般无变化的平板、金属水和自发光水。
2. **森林**：针叶深绿与落叶树黄绿、赭黄、少量锈红混合，按树群分布。树冠大小、高度、形状与间距变化；有林缘、坡向和疏密，不能均匀散点铺满整座山。
3. **前景**：干草中留少量青绿，疏落叶，不铺满彩叶地毯；大石有磨圆轮廓、细微裂隙和克制苔痕。优先给这些近景物件真实表面细节。
4. **城镇**：矮层坡屋顶，灰泥、旧木、粗石；模块重复时改变体量、朝向、屋顶颜色与增建轮廓。公仓体量更大，教堂仅适度高出普通房屋。不加入未经设定的巨型主城堡。
5. **田地与道路**：收割后赭金、土褐和低饱和绿分块，有田埂与道路衔接；码头必须连接岸路。避免棋盘格贴图和漂浮建筑。
6. **空气**：近景清楚、远山降对比降饱和，薄雾不能把全片盖灰。晨雾和晚炊烟只作层次，不是主景。

资产细节按最终屏幕大小决定：不要给一两个像素的小屋制作室内，也不要让前景树成为明显的低模圆锥。

## 6. 时间与光影节奏

默认 24 fps，1—720 帧，成片 30 秒。`t=(frame-1)/719` 为全片统一时间参数。表内时刻是艺术节奏节点，变化必须连续，不在节点间切镜头。

| 帧 | 阶段 | 画面目标 |
|---|---|---|
| 1 | 破晓前 | 深灰蓝天空略亮，湖面已有轮廓；镇上少量余灯，晨雾贴水 |
| 97 | 日出后 | 东方右侧低角度暖光首先照到高处树梢与山脊；谷底仍有冷影，晨雾边缘见光 |
| 265 | 近午 | 日光中性偏暖，湖面反映天空，镇与田地清晰；阴影缩短，仍保留材质层次 |
| 433 | 下午 | 光线转向西侧，山坡长影逐渐铺开；云影移动柔和，天空清透 |
| 553 | 日落前后 | 左侧暖金斜光擦亮草尖与屋顶；水面有符合光照方向的碎金反射，七艘船返航，家灯分批亮起 |
| 625 | 蓝调时刻 | 太阳直射退场，天空尚亮；山与屋顶转冷，南岸暖灯及真实倒影逐渐突出 |
| 720 | 夜晚 | 天空、湖、山仍能分开，岸边留稀疏灯点；船已靠岸，最后约两秒变化放缓 |

太阳轨迹用连续向量或稳定插值，避免欧拉角跨越造成翻转。可用艺术性的北半球秋日轨迹：东侧升起，经南侧天空，西侧落下；虚构世界无已确认纬度，不声称是真实天文重建。山体会先遮住太阳，应保留由地形产生的入阴时间差。

日出日落的暖来自照明与空气，不能给整个画面叠同一层橙色。夜晚允许慢速、有限曝光补偿，但仍必须显著暗于白天；不要把日景整体染蓝充当夜景。

云缓慢跨过天空、草叶小幅晃动、水纹连续移动即可产生时间流逝感。风与水不必按太阳相同倍速加速，否则会剧烈跳动；它们采用平滑的艺术时间尺度。窗灯错峰渐亮，不能像电网开关一样全镇同时亮。
