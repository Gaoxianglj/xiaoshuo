# 秋日斯托克顿领 · Blender 动画交接包

编制日期：2026-09-05。用途：把本目录复制到另一台电脑，让该电脑上的 AI 使用 Blender 建模、布光和渲染。本次交付是制作说明，尚未执行建模或渲染。

## 给作者的说明

可以做到。Blender 可以搭建地形、森林、城镇与湖泊，再将太阳方向、天空、雾和窗灯的变化做成动画。你说的“延迟摄影”在这里按“延时摄影 / time-lapse”理解：机位不动，一天的光照被压缩到几十秒。

画面质量取决于场景制作、材质、布光与迭代，也取决于另一台电脑的显卡、显存和可用时间。文档能明确目标，不能保证 AI 一次执行就达到电影品质。先看关键帧与短片预览，可以较早发现问题。

默认方案：30 秒、24 fps、1920×1080、固定南侧半山机位、自然写实的西幻环境；不安排前景人物。时长、精确尺寸和风格细节均为本次制作建议，可修改，不新增小说正史。

## 使用方法

1. 把本目录的三个 Markdown 文件一起复制或上传到另一台电脑的任务工作区。无需复制整部小说。
2. 把下面的启动指令发给那个任务的 AI。若你想测试 Astra，在那个任务的模型选项中自行选定它；文档不依赖特定模型。
3. AI 应在目标电脑检查 Blender 与渲染设备，然后实际生成工程、预览和动画，不能只再交一份方案。
